Занятие 5. Ввод и вывод данных

Цель занятия

Научиться выводить данные с помощью print(), получать данные от пользователя с помощью input() и оформлять текст с помощью f-строк. Написать программу «Паспорт пользователя».

Теория

Вывод данных: команда print()

Для вывода данных на экран используется команда print(). В круглых скобках пишем то, что хотим вывести. Если это текст, его нужно взять в кавычки, одинарные или двойные. Кавычки в начале и в конце текста должны быть одинаковыми. В VS Code результат появляется в окне TERMINAL.

print('Мы изучаем Python')
print("Мы изучаем Python")

Обе строки делают одно и то же: Python не различает одинарные и двойные кавычки.

То, что мы пишем в скобках у print(), называется аргументами. Аргументы – это значения, которые передаются функции при вызове. Если аргументов несколько, их разделяют запятыми, а при выводе между ними автоматически ставится пробел.

print('Я', 'учусь', 'писать', 'код')
# Я учусь писать код

У команды print() есть несколько особенностей:

  • Название print пишется только строчными буквами, потому что в Python регистр важен.
  • Каждый следующий print() выводит текст с новой строки.
  • print() без аргументов выводит пустую строку.
  • Если в тексте нужны двойные кавычки, весь текст берут в одинарные, и наоборот. В одном print() можно комбинировать оба вида кавычек.
  • Если внутри текста в одинарных кавычках поставить ещё одну одинарную кавычку, Python решит, что текст закончился, и выдаст ошибку SyntaxError.
print('Он сказал: "Привет!"')
print("Это 'одинарные' кавычки")

У print() есть два дополнительных параметра. Параметр sep задаёт разделитель между аргументами, а параметр end задаёт, чем заканчивается вывод. По умолчанию разделитель – пробел, а в конце ставится переход на новую строку.

print('15', '03', '2026', sep='.')  # 15.03.2026
print('Привет,', end=' ')
print('мир!')  # Привет, мир!

Ввод данных: команда input()

Чтобы программа могла получать данные от пользователя, используется команда input(). Когда программа доходит до неё, она останавливается и ждёт, пока пользователь введёт текст и нажмёт Enter. Введённое значение нужно сохранить в переменную, иначе оно потеряется.

name = input()
print('Привет,', name)

Внутри скобок input() можно написать подсказку. Она появится перед местом ввода и подскажет пользователю, что от него требуется.

name = input('Как вас зовут? ')
print('Привет,', name)

У input() есть важная особенность: он всегда возвращает строку (str), даже если пользователь ввёл число. Поэтому с введённым числом нельзя сразу выполнять вычисления. Его нужно преобразовать: целое число с помощью int(), дробное с помощью float().

age = input('Сколько вам лет? ')
print(type(age))  # <class 'str'>

age = int(input('Сколько вам лет? '))
print(type(age))  # <class 'int'>

Если пользователь введёт не число, например слово, int() выдаст ошибку ValueError. Как обрабатывать такие ситуации, мы узнаем позже.

f-строки

f-строка позволяет вставить значения переменных прямо в текст. Перед открывающей кавычкой ставится буква f, а имена переменных записываются в фигурных скобках.

name = 'Даша'
age = 25
print(f'Меня зовут {name}, мне {age} лет.')
# Меня зовут Даша, мне 25 лет.

Раньше мы выводили значения через запятую, и Python сам добавлял пробелы. С f-строкой мы сами решаем, как будет выглядеть текст, и можем ставить знаки препинания там, где нужно. Кроме имён переменных, в фигурных скобках можно писать выражения.

print(f'Через 5 лет мне будет {age + 5}.')
# Через 5 лет мне будет 30.

Дробные числа можно округлять прямо в f-строке. После двоеточия указывают формат: .2f означает два знака после запятой.

height = 1.7
print(f'Рост: {height:.2f} м')  # Рост: 1.70 м

Для оформления вывода полезно знать ещё одну особенность: строку можно умножать на число. Это удобно для рамок и разделителей.

print('=' * 20)  # ====================

Символ = здесь повторяется 20 раз.

Практика: «Паспорт пользователя»

Пишем программу вместе. Программа спрашивает имя, год рождения, любимое число и город, а затем выводит персональную карточку.

  1. Создаём в VS Code файл passport.py.
  2. Запрашиваем данные с помощью input() с понятными подсказками. Год рождения и любимое число сразу преобразуем в int.
  3. Вычисляем возраст: из текущего года вычитаем год рождения.
  4. Выводим карточку с помощью f-строк и рамки из символов =.
  5. Запускаем программу с разными данными и проверяем результат.

Пример выполнения:

name = input('Как вас зовут? ')
birth_year = int(input('В каком году вы родились? '))
number = int(input('Ваше любимое число? '))
city = input('В каком городе вы живёте? ')

age = 2026 - birth_year

print('Паспорт пользователя')
print('=' * 30)
print(f'Имя: {name}')
print(f'Возраст: {age}')
print(f'Любимое число: {number}')
print(f'Город: {city}')
print('=' * 30)

Возраст в этой программе приблизительный, потому что мы считаем его только по году рождения.

Дополнительное задание: добавить в паспорт поле «Хобби» и вывести год, в котором пользователю исполнится 30 лет.

Во время практики часто встречаются одни и те же ошибки:

  • Если не преобразовать год рождения в int, вычитание выдаст ошибку TypeError, потому что input() возвращает строку.
  • Если забыть букву f перед кавычкой, вместо значений на экране появятся имена переменных в фигурных скобках.
  • Если использовать внутри f-строки те же кавычки, что и снаружи, программа выдаст ошибку.
  • Если ввести вместо числа слово, int() выдаст ошибку ValueError.

Итоги

  • print() выводит данные на экран: аргументы разделяются запятыми, а параметры sep и end управляют оформлением.
  • input() получает данные от пользователя и всегда возвращает строку, поэтому числа нужно преобразовывать через int() или float().
  • f-строка вставляет значения переменных и выражения в текст с помощью фигурных скобок.
  • С помощью print(), input() и f-строк можно писать простые интерактивные программы.
