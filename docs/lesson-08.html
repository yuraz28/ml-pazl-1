Занятие 8. Типы данных

Цель занятия

Повторить основные типы данных Python (int, float, str, bool), научиться определять тип значения с помощью type(), понять, чем неявные преобразования отличаются от явных, и научиться находить и исправлять типичные ошибки, связанные с типами.

Теория

Основные типы данных

Каждое значение в Python имеет тип. Тип определяет, что с этим значением можно делать. Пока нам нужны четыре типа.

  • int – целые числа: 17, -5, 0. Размер целого числа в Python не ограничен.
  • float – числа с плавающей точкой (дробные): 3.14, -0.5, 2.0. Дробная часть отделяется точкой, а не запятой.
  • str – строки, то есть текст в кавычках: 'Python', "17", ''. Строку можно сцеплять (+), повторять (* на число) и измерять (len()).
  • bool – логический тип с двумя значениями: True и False. Это результат сравнений, например 5 > 3.

Число 17 и строка '17' – это разные значения. С числом можно считать, а со строкой – нет. Поэтому 17 + 3 даёт 20, а '17' + '3' даёт '173'.

Функция type()

Чтобы узнать тип значения, используют встроенную функцию type(). Она особенно полезна, когда программа работает не так, как ожидалось.

print(type(17))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type('17'))     # <class 'str'>
print(type(5 > 3))    # <class 'bool'>
print(type(4 / 2))    # <class 'float'>
print(type(input()))  # <class 'str'>

Неявные преобразования

Иногда Python сам меняет тип значения, чтобы выполнить операцию. Это называется неявным преобразованием. Главное правило: целое число автоматически становится дробным, если оно встречается вместе с float.

print(2 + 1.5)          # 3.5, int стал float
print(type(2 + 1.5))    # <class 'float'>
print(10 / 2)           # 5.0, деление даёт float

А вот строку и число Python сам не объединяет: неизвестно, что вы имели в виду, сложить числа или сцепить строки. Дробное число в целое тоже не превращается само. В таких случаях нужно явное преобразование.

Явные преобразования

Явное преобразование мы выполняем сами с помощью функций int(), float() и str().

print(int('123'))       # 123, строка -> целое
print(float('1.5'))     # 1.5, строка -> дробное
print(float(3))         # 3.0, целое -> дробное
print(str(17))          # '17', число -> строка
print(int(17.89))       # 17, дробная часть отброшена
print(int(-1.7))        # -1, в сторону нуля

Функция int() не округляет число, а отбрасывает дробную часть. Например, int(3.99) равно 3, а не 4.

Если строку нельзя превратить в число, возникает ошибка ValueError. Чтобы получить целое число из строки с дробью, сначала преобразуют её в float:

n = int('2.5')            # ValueError
n = int(float('2.5'))    # 2, так работает

Типичные ошибки с типами

Ошибки типов встречаются очень часто. Вот самые распространённые, с тем, как их исправить.

Сложение строки и числа (TypeError)

print('Мне ' + 15 + ' лет')       # TypeError
print('Мне ' + str(15) + ' лет')  # исправлено
print('Мне', 15, 'лет')           # или через запятую

Забыли преобразовать ввод

age = input()          # age - это строка
print(age + 1)         # TypeError
age = int(input())     # исправлено
print(age + 1)

Неправильная запись числа (ValueError)

x = float('2,5')       # ValueError, нужна точка
x = float('2.5')       # исправлено
n = int('abc')         # ValueError

Умножение строки на строку

print('3' * '4')       # TypeError
print('3' * 4)         # 3333
print(3 * 4)           # 12

Практика

Задача 1. Определи тип

Не запуская программу, определите тип каждого выражения (int, float, str или bool). Затем проверьте себя с помощью type().

7 / 2
7 // 2
'7' * 2
2 + 3.0
len('abc')
4 > 3
int('12') + 1
str(12) + '1'

Ответы: float, int, str ('77'), float (5.0), int (3), bool (True), int (13), str ('121').

Задача 2. Почини код

Каждая из программ ниже работает неправильно или завершается с ошибкой. Найдите проблему и исправьте код.

Программа А

age = input('Сколько вам лет? ')
print('Через год вам будет', age + 1)

Ошибка: TypeError, потому что age – строка. Исправление: age = int(input('Сколько вам лет? ')).

Программа Б

name = 'Аня'
score = 95
print('Результат ' + name + ': ' + score)

Ошибка: TypeError, нельзя сцепить строку и число. Исправление: str(score) вместо score либо вывод через запятую.

Программа В

a = input()
b = input()
print('Сумма:', a + b)

Ошибки нет, но для ввода 3 и 4 выводится 34. Исправление: a = int(input()) и b = int(input()).

Задача 3. Средний балл

Пользователь вводит три оценки. Нужно вывести средний балл (дробное число) и его целую часть.

a = int(input())
b = int(input())
c = int(input())

avg = (a + b + c) / 3
print('Средний балл:', avg)
print('Целая часть:', int(avg))
print(type(avg))

Для оценок 5, 4, 4 программа выведет 4.333333333333333, затем 4 и <class 'float'>. Обратите внимание на скобки: без них 3 применилось бы только к c. Тип avg всегда float, потому что использовано деление /.

Задача 4. Почини калькулятор

Программа должна посчитать стоимость покупки по цене и количеству товара, но выдаёт ошибку. Исправьте её.

price = input('Цена товара: ')
count = input('Количество: ')
print('Итого: ' + price * count)

Подсказка: цена может быть дробной, а количество – целое. Проверьте себя: для цены 12.5 и количества 3 должно получиться 37.5.

Возможное решение:

price = float(input('Цена товара: '))
count = int(input('Количество: '))
print('Итого:', price * count)

Итоги

  • В Python основные простые типы — int, float, str и bool. Тип любого значения можно узнать с помощью type().
  • input() всегда возвращает строку, а результат обычного деления / всегда имеет тип float.
  • Неявно Python превращает int в float, но не объединяет строки и числа. В остальных случаях нужно явное преобразование.
  • Функции int(), float() и str() преобразуют значение к нужному типу. int() отбрасывает дробную часть, а не округляет.
  • Типичные ошибки: TypeError (строка и число вместе) и ValueError (строку нельзя превратить в число). Их исправляют преобразованием типа или правильной записью числа.
