Занятие 19. Вложенные списки

Цель занятия

Начать вторую часть курса Python и разобраться с вложенными списками – списком, внутри которого лежат другие списки. Научиться брать элемент по двум индексам и обходить такую структуру вложенными циклами. Собрать игру «Крестики-нолики», поле которой как раз и есть вложенный список.

Теория

С чего начинается вторая часть

В первой части мы прошли весь базовый набор: переменные, input/print, числа и строки, условия, циклы for и while, списки и функции. Каждая тема теперь будет опираться на предыдущие – новых «с нуля» тем почти не останется.

Вторая часть – про то, как хранить сложные данные. Оценки класса, поле для игры, телефонная книга, содержимое файла: всё это плоским списком не описать. Начнём с самого простого усложнения – списка внутри списка.

Список списков

До сих пор список был «в одну линию»: ['молоко', 'хлеб', 'сыр']. Но таблица в одну линию не помещается. Идея простая: таблица – это список строк, а каждая строка – список клеток.

Поле для крестиков-ноликов 3×3 выглядит так:

board = [
    [' ', ' ', ' '],
    [' ', ' ', ' '],
    [' ', ' ', ' '],
]

Внешний список – это три строки поля. Каждый элемент внешнего списка – сам список из трёх клеток. Пробел означает пустую клетку.

Размеры считаются как обычно:

print(len(board))       # 3 - сколько строк
print(len(board[0]))    # 3 - сколько клеток в первой строке

Два индекса вместо одного

board[1] – это вторая строка целиком, то есть список [' ', ' ', ' ']. Чтобы достать одну клетку, нужен второй индекс: board[1][2] – вторая строка, третий элемент.

Читается слева направо: сначала выбираем строку, потом внутри неё – клетку. Так же устроены адреса в таблице: сначала номер строки, потом номер столбца.

marks = [
    ['Аня', 5, 4, 5],
    ['Марк', 4, 4, 3],
]

print(marks[0][0])      # Аня
print(marks[1][2])      # 4
print(marks[0])         # ['Аня', 5, 4, 5] - вся строка
print(marks[1][1:])     # [4, 3] - срез внутри строки

Вложенность не ограничена двумя уровнями: внутрь клетки можно положить ещё список. Но на практике больше двух-трёх уровней читать уже тяжело, и в таких местах лучше заводить словари (занятие 21).

Запись board[1][2] – это два отдельных действия. Можно разложить по переменным, и иногда так понятнее:

row = 1
col = 2
board[row][col] = 'X'

Вложенные циклы

Чтобы пройти по всем клеткам, нужны два цикла: внешний перебирает строки, внутренний – клетки внутри строки.

for row in board:
    for cell in row:
        print(cell)

Если нужны не сами значения, а индексы (например, чтобы задать координаты), перебираем по номерам:

for i in range(len(board)):
    for j in range(len(board[i])):
        print(i, j, board[i][j])

Аналогия – обход зала: сначала перебираем ряды, внутри каждого ряда – места. Ряд и место вместе задают одно конкретное кресло.

Внутренний цикл создаётся заново для каждой строки. Поэтому len(board[i]) – правильнее, чем len(board[0]): строки теоретически могут быть разной длины.

Ловушка: как НЕ надо создавать поле

Хочется написать коротко – «сделай три одинаковые строки»:

board = [[' '] * 3] * 3

Код запускается без ошибки, но работает неправильно. Умножение списка не копирует содержимое, а повторяет ссылку на один и тот же список. В итоге все три строки – это одна и та же строка в памяти. Меняем одну клетку – меняются три:

board = [[' '] * 3] * 3
board[0][0] = 'X'
print(board)
# [['X', ' ', ' '], ['X', ' ', ' '], ['X', ' ', ' ']]

Правильно – создать каждую строку отдельно, в цикле:

board = []
for i in range(3):
    row = [' ', ' ', ' ']
    board.append(row)

Внутри одной строки умножение [' '] * 3 безопасно: строки из пробелов – обычные текстовые значения, их копирование ничего не ломает. Опасность только когда повторяют список внутри списка.

Практика

Задача. Игра «Крестики-нолики»

Собираем игру для двух игроков за одним компьютером. Поле – вложенный список. Игроки ходят по очереди, вводя номер клетки от 1 до 9. Нумерация как на телефоне:

 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9

Создайте файл lesson19.py в папке занятия.

Шаг 1. Поле и его показ

board = [
    [' ', ' ', ' '],
    [' ', ' ', ' '],
    [' ', ' ', ' '],
]


def show_board():
    print()
    for i in range(3):
        print(' ' + ' | '.join(board[i]))
        if i < 2:
            print('---+---+---')

' | '.join(board[i]) склеивает три клетки строки через разделитель | (метод join из занятия 11). Разделительную линию печатаем после первой и второй строки, но не после третьей – для этого проверка if i < 2.

Проверим:

show_board()

#    |   |  
# ---+---+---
#    |   |  
# ---+---+---
#    |   |

Шаг 2. Ход игрока

Пользователь вводит номер клетки от 1 до 9, а нам нужны два индекса. Номер 5 – это вторая строка (индекс 1) и вторая клетка (индекс 1). Номер 8 – третья строка (индекс 2), вторая клетка (индекс 1).

Такое преобразование делается двумя операциями из занятия 6: целочисленным делением // и остатком %.

def make_move(number, symbol):
    row = (number - 1) // 3
    col = (number - 1) % 3
    if board[row][col] != ' ':
        print('Клетка уже занята')
        return False
    board[row][col] = symbol
    return True

Почему number - 1: номера начинаются с 1, а индексы с 0. Дальше // 3 даёт номер строки (номера 1–3 → строка 0, 4–6 → строка 1, 7–9 → строка 2), а % 3 – позицию внутри строки.

Функция возвращает True, если ход сделан, и False, если клетка занята. Это пригодится в главном цикле: неудачный ход не должен передавать очередь другому игроку.

Шаг 3. Проверка победы

Выиграть можно восемью способами: три строки, три столбца, две диагонали. Строки и столбцы проверяем в одном цикле, диагонали – отдельно.

def check_win(symbol):
    for i in range(3):
        if board[i][0] == board[i][1] == board[i][2] == symbol:
            return True
        if board[0][i] == board[1][i] == board[2][i] == symbol:
            return True
    if board[0][0] == board[1][1] == board[2][2] == symbol:
        return True
    if board[0][2] == board[1][1] == board[2][0] == symbol:
        return True
    return False

Двойное равенство в Python читается как «и то, и другое»: a == b == c == symbol истинно, когда все четыре значения совпадают. Отдельно проверяем, что это именно символ игрока, иначе три пустые клетки тоже считались бы победой.

Обратите внимание: board[i][0] – клетка в строке i и столбце 0. Когда i меняется от 0 до 2, это перебор одного столбца сверху вниз.

Шаг 4. Ничья и главный цикл

Ничья – когда поле заполнено, а победителя нет. Проверить просто: ищем хотя бы один пробел.

def is_full():
    for row in board:
        if ' ' in row:
            return False
    return True

Теперь сам игровой цикл. Игроки ходят, пока кто-то не победит или поле не заполнится. Символ меняется после каждого успешного хода.

print('Клетки нумеруются так:')
print(' 1 | 2 | 3')
print('---+---+---')
print(' 4 | 5 | 6')
print('---+---+---')
print(' 7 | 8 | 9')

symbol = 'X'
while True:
    show_board()
    number = int(input('Ход ' + symbol + ', номер клетки: '))
    if number < 1 or number > 9:
        print('Номер должен быть от 1 до 9')
        continue
    if not make_move(number, symbol):
        continue
    if check_win(symbol):
        show_board()
        print('Победили', symbol)
        break
    if is_full():
        show_board()
        print('Ничья')
        break
    symbol = 'O' if symbol == 'X' else 'X'

Разберём ключевые места:

  • while True и break – уже знакомый каркас из занятия 10: играем, пока не случится выход.
  • continue при ошибке ввода и при занятой клетке возвращает нас к началу цикла. Ход при этом не переходит к другому игроку – очередь остаётся у того же.
  • if not make_move(...) читается как «если ход не удался».
  • symbol = 'O' if symbol == 'X' else 'X' – короткая запись смены игрока. Обратите внимание на вторую часть: там именно 'X', а не 'O'. Если перепутать, второй игрок будет ходить бесконечно, а первый – один раз. Проверяйте такие строки запуском, а не глазами.

Запустите игру и сыграйте партию до победы одной из сторон.

Шаг 5. Доработки на выбор

  • Сделать поле 4×4 (победа – четыре в ряд). Что придётся поменять в check_win?
  • Не давать ходить в занятую клетку без подсказки – печатать, какие номера ещё свободны.
  • Считать счёт партий: после победы спрашивать «ещё раз?» и обнулять поле.
  • Подсвечивать выигрышную линию, выводя вместо разделителей ***.

Частые ошибки

  • board[1, 2] вместо board[1][2]. Питон воспримет 1, 2 как кортеж и выдаст TypeError: list indices must be integers or slices, not tuple. Скобки – отдельные, для каждого индекса.
  • Путаница «номер клетки» и «индексы». Номер от 1 до 9 – для человека, индексы от 0 до 2 – для программы. Пересчёт делает make_move.
  • Поле создано умножением [[' '] * 3] * 3 – все строки оказываются одной и той же. Симптом: один ход ставит три крестика.
  • В check_win сравнивают только две клетки (board[i][0] == board[i][1]), и победа засчитывается на двух символах.
  • Забыли return False в конце check_win – функция вернёт None, и if check_win(...) сработает неправильно.
  • Убрали continue после занятой клетки – игрок теряет ход из-за собственной опечатки.

Итоги

  • Вложенный список – список, элементами которого являются списки. Таблицу удобно хранить именно так: внешний список – строки, внутренние – клетки строки.
  • Один элемент достаётся двумя индексами по очереди: board[строка][столбец]. Срезы и len работают на каждом уровне отдельно.
  • Обход вложенного списка делают вложенными циклами: внешний по строкам, внутренний по клеткам.
  • [[' '] * 3] * 3 создаёт три ссылки на одну строку. Строки нужно создавать по отдельности, в цикле.
  • В игре номер клетки 1–9 превращается в индексы через (number - 1) // 3 и (number - 1) % 3, а победа проверяется по строкам, столбцам и диагоналям.
