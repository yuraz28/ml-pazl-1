Занятие 1. Знакомство, структура курса, установка VS Code и Python

Цель занятия

Познакомиться с преподавателями и группой, понять, чему и как мы будем учиться на курсе, и подготовить рабочее окружение: установить VS Code и Python и запустить первую программу.

Теория

1. Знакомство

  • Преподаватели: имя, чем занимается, какой опыт в IT и ML.
  • Ученики: имя, чем интересуется, что ожидает от курса (по возможности голосом).
  • Правила курса: как проходят занятия, как сдаётся ДЗ, где задавать вопросы, как устроены код-ревью и ретро.

2. О чём курс

Курс — введение в программирование и машинное обучение. Мы начинаем с основ Python и дальше постепенными шагами движемся к собственным AI-приложениям.

Как устроен курс

Модуль О чём
Введение в профессию Кто такой разработчик, направления в IT, инструменты
Python, часть 1 Переменные, ввод/вывод, условия, циклы, строки, списки, функции
Введение в LLM Что такое ML и LLM, промпт-инжиниринг, применение нейросетей
Python, часть 2 Вложенные списки, словари, множества, файлы, CSV и JSON
Работа с API HTTP-запросы, библиотека requests, работа с JSON
Работа с LLM Продвинутые промпты, LangChain, chains, память

Отдельный небольшой модуль — «Безопасность LLM»: галлюцинации, конфиденциальность, промпт-инъекции.

3. Проекты

На каждом занятии есть практическое задание.

Во второй половине курса мы делаем два проекта в командах:

  1. Проект 1: программа, которая через API отправляет запросы языковой модели.
  2. Проект 2: чат-бот на основе языковой модели через API.

4. Инструменты курса

  • Python — язык, на котором мы пишем. Он простой и читаемый, его используют в веб-разработке, анализе данных и ML.
  • VS Code — редактор, в котором мы пишем и запускаем код.

Практика: установка и первый запуск

  1. Скачать и установить VS Code с code.visualstudio.com.

    В параметрах установки отметить пункты:

    • «Open with Code» (для файлов и папок)
    • «Add to PATH»

  2. Скачать и установить Python с python.org.

    На первом шаге отметить галочку Add python.exe to PATH.

  3. Проверить установку: в командной строке ввести:

    python --version

  4. В VS Code открыть Extensions (Ctrl+Shift+X) и установить расширения:

    • Python
    • Russian Language Pack

  5. Создать файл hello.py, написать:

    print("Hello World")

    и запустить программу.

Если не работает: установщик запустить от имени администратора, после установки перезагрузить компьютер.
