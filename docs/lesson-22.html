Занятие 22. Работа с файлами txt

Цель занятия

Научиться сохранять данные между запусками программы: открывать файл, читать его и записывать в него результат. Разобрать конструкцию with open(...), режимы работы и кодировку. Собрать программу, которая читает текст, считает статистику слов и сохраняет отчёт в отдельный файл.

Теория

Зачем нужны файлы

До этого занятия все данные жили только в памяти: пока программа работала – они были, закрыли программу – исчезли. Список задач из занятия 13, телефонная книга из занятия 21 – после перезапуска пусто.

Файл – это данные на диске. Они никуда не деваются, и их можно открыть другой программой: в блокноте, в Excel, отправить в чат.

Два направления работы:

  • Чтение – взяли текст из файла, обработали (посчитали, разобрали на слова, превратили в список), вывели результат.
  • Запись – взяли данные из программы и сохранили их, чтобы они жили дальше.

Открытие файла

Файл открывают функцией open. Она получает имя файла и режим, а возвращает объект файла – через него и идёт работа.

f = open('text.txt', 'r', encoding='utf-8')
text = f.read()
f.close()

Три параметра, каждый важен:

  • Имя файла. 'text.txt' – файл в той же папке, что и программа. Файл ищется относительно папки, из которой запущен Python: в VS Code – это папка открытого проекта. Если файл лежит не там, будет ошибка FileNotFoundError.
  • Режим. 'r' – читать (read). Ещё будут 'w' и 'a'.
  • Кодировка. encoding='utf-8' – способ превращения байтов в буквы. Русский текст без него на части систем читается «кракозябрами» или выдаёт UnicodeDecodeError. Правило простое: всегда указывайте encoding='utf-8'.

Метод close() закрывает файл: сообщает системе «я закончил, можно сохранять». Забыли закрыть – данные могут не записаться.

Конструкция with open

Чтобы не забывать про close, используют with. Он закрывает файл автоматически – и когда всё прошло хорошо, и когда внутри случилась ошибка.

with open('text.txt', 'r', encoding='utf-8') as f:
    text = f.read()

print(text)

Читается так: «открой файл, пока мы внутри блока называй его f, когда блок закончится – закрой». Всё, что делаем с файлом, пишем с отступом. После блока переменная f уже закрыта.

Дальше в курсе мы будем пользоваться только этой конструкцией.

Режимы работы

Режим Что делает Если файла нет
'r' Читает Ошибка FileNotFoundError
'w' Пишет, стирая старое содержимое Файл создаётся
'a' Дописывает в конец Файл создаётся

Главная ловушка – 'w'. Он не «дописывает», а начинает файл заново. Открыли на запись файл с важными данными – данные стёрлись ещё до того, как вы что-то записали.

Если нужно добавить строку в конец – режим 'a':

with open('log.txt', 'a', encoding='utf-8') as f:
    f.write('Программа запущена\n')

Каждый запуск добавляет одну строку. С 'w' в файле всегда оставалась бы только последняя.

Чтение: три способа

with open('text.txt', 'r', encoding='utf-8') as f:
    text = f.read()          # весь файл одной строкой

with open('text.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()    # список строк

with open('text.txt', 'r', encoding='utf-8') as f:
    for line in f:           # по одной строке, экономно по памяти
        print(line)

readlines() и перебор в цикле оставляют в конце каждой строки символ перевода строки \n. Убрать его можно методом strip() (занятие 11):

with open('text.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line.strip())

Запись

Метод write() записывает строку. Символ перевода строки \n он не добавляет – это ваша забота:

with open('report.txt', 'w', encoding='utf-8') as f:
    f.write('Отчёт\n')
    f.write('Строк: 3\n')

Без \n всё склеится в одну длинную строку. Внутри текста \n – это просто два символа-обозначения, которые Python превращает в перевод строки.

write() принимает только строку. Числа нужно превращать: str(count) (занятие 8).

Что делать с прочитанным

Файл отдаёт строку. Дальше работаем с ней обычными инструментами: split() разбивает на слова, словарь считает частоты (занятие 21), множество убирает повторы (занятие 20). Именно поэтому файлы идут после коллекций: без них читать нечего было бы обрабатывать.

Практика

Задача. Статистика слов в тексте

Программа читает текстовый файл, считает, сколько раз встречается каждое слово, находит топ-5 и сохраняет отчёт в отдельный файл.

Шаг 1. Создать файл с текстом

В папке занятия создайте файл text.txt и вставьте:

Летом мы ездили на озеро. Озеро было тихое, вода тёплая.
Вечером на озере ловили рыбу. Рыба клевала плохо, но мы не расстроились.
Утром туман, тишина, только птицы. Летом на озере хорошо.

Программу пишем в lesson22.py в той же папке.

Шаг 2. Прочитать файл

with open('text.txt', 'r', encoding='utf-8') as f:
    text = f.read()

print(text)
print('Символов:', len(text))

Запустите и проверьте, что текст вывелся целиком, а не «кракозябрами». Если вместо букв мусор – проверьте encoding. Если FileNotFoundError – файл лежит в другой папке или в имени опечатка.

Шаг 3. Посчитать слова

Слово с большой буквы и с маленькой – для нас одно и то же, поэтому приводим к нижнему регистру. Знаки препинания по краям слова убираем методом strip(): он срезает указанные символы с начала и конца строки.

WORDS_STRIP = '.,!?;:«»—"()'

words = {}
unique = set()
total = 0

for raw in text.split():
    word = raw.lower().strip(WORDS_STRIP)
    if word == '':
        continue
    total += 1
    unique.add(word)
    words[word] = words.get(word, 0) + 1

За один проход мы получили три вещи: общее число слов, множество уникальных и словарь частот. Проверка if word == '' нужна на случай, когда слово состояло только из знаков препинания.

Шаг 4. Топ-5 слов

Нужно отсортировать словарь по частоте. Сортировать словарь напрямую нельзя, зато можно собрать список пар и отсортировать его.

Здесь пригодятся кортежи (занятие 20): пары (частота, слово) сортируются сначала по частоте, а при равенстве – по слову. Метод sort(reverse=True) ставит большие значения вперёд (занятие 12).

pairs = []
for word, count in words.items():
    pairs.append((count, word))

pairs.sort(reverse=True)
top = pairs[:5]

print('Всего слов:', total)
print('Уникальных:', len(unique))
print('Топ-5:')
for count, word in top:
    print(' ', word, '-', count)

Порядок в кортеже (count, word) важен: сортировка смотрит сначала на первый элемент. Напишем (word, count) – список отсортируется по алфавиту, а не по частоте. Частая ошибка, проверяйте вывод.

Шаг 5. Сохранить отчёт в файл

with open('report.txt', 'w', encoding='utf-8') as f:
    f.write('Отчёт по файлу text.txt\n')
    f.write('Всего слов: ' + str(total) + '\n')
    f.write('Уникальных слов: ' + str(len(unique)) + '\n')
    f.write('Топ-5 слов:\n')
    for count, word in top:
        f.write(word + ' - ' + str(count) + '\n')

print('Готово, отчёт в report.txt')

Обратите внимание на str(): write не умеет писать числа. И на \n в конце каждой строки – без него весь отчёт был бы одной строкой.

Шаг 6. Прочитать отчёт обратно

with open('report.txt', 'r', encoding='utf-8') as f:
    print(f.read())

Программа прочитала свой же результат. Так проверяют, что запись прошла правильно, – глазами по файлу, а не по сообщению «Готово».

Ожидаемый результат для текста из шага 1:

Отчёт по файлу text.txt
Всего слов: 31
Уникальных слов: 25
Топ-5 слов:
на - 3
озеро - 2
озере - 2
мы - 2
летом - 2

Шаг 7. Доработки на выбор

  • Добавить в отчёт самое длинное слово файла.
  • Исключить из подсчёта короткие слова (предлоги «на», «мы») – сравнение len(word) > 2.
  • Записывать в log.txt через режим 'a' дату и время каждого запуска.
  • Считать статистику сразу для двух файлов и сохранять два отчёта.
  • Попробовать readlines() вместо read() и посчитать количество строк в файле.

Частые ошибки

  • Нет encoding='utf-8' – вместо русского текста мусор или UnicodeDecodeError: 'charmap' codec can't decode....
  • 'w' вместо 'a' – файл стёрся и в нём осталась только последняя запись.
  • FileNotFoundError – файл лежит в другой папке, неверное имя или расширение (text.txt.txt, если Windows дописал его сам). Проверьте, что text.txt виден в панели файлов VS Code рядом с lesson22.py.
  • print(f) вместо print(f.read()) – выводится служебная информация об объекте файла, а не текст.
  • Забыли \n в write – все строки склеились в одну.
  • f.write(count) с числом – TypeError: write() argument must be str. Нужен str(count).
  • Работа с файлом после блока with – файл уже закрыт, будет ValueError: I/O operation on closed file.
  • Читают файл в цикле несколько раз: после read() файл стоит в конце, повторный read() вернёт пустую строку.

Итоги

  • Файл хранит данные на диске, поэтому они не исчезают после закрытия программы.
  • with open(имя, режим, encoding='utf-8') as f: – основной способ работы: файл закроется сам, даже при ошибке.
  • Режимы: 'r' – читать, 'w' – писать (стирает старое содержимое), 'a' – дописывать в конец.
  • Читать можно целиком (read()), списком строк (readlines()) или построчно в цикле for. Строки приходят с \n, его убирает strip().
  • write() пишет только строки и не добавляет перевод строки – \n и str() на вашей ответственности.
  • Прочитанный текст обрабатывают теми же инструментами, что и обычную строку: split, множество для уникальных, словарь для частот.
