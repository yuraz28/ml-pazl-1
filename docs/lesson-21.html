Занятие 21. Словари

Цель занятия

Разобраться со словарём – коллекцией пар «ключ → значение». Научиться добавлять, менять и удалять пары, перебирать словарь и проверять наличие ключа. Применить это в четырёх типовых задачах: подсчёт частот, телефонная книга, группировка по признаку и объединение двух словарей.

Теория

Проблема, которую решает словарь

У нас уже есть список, кортеж и множество (занятия 12 и 20). Все три хранят значения. Но часто нужно хранить связь: имя → телефон, слово → сколько раз встретилось, товар → цена.

Списком это делается неудобно. Пришлось бы держать две строки рядом или вложенные списки ['Аня', '+7 900 111-22-33'] – и каждый раз помнить, что [0] это имя, а [1] телефон. Добавили третий столбец – вся логика поехала.

Словарь хранит пары: по ключу сразу получаем значение, без перебора и без знания индекса.

phonebook = {
    'Аня': '+7 900 111-22-33',
    'Марк': '+7 900 444-55-66',
    'Лиза': '+7 900 777-88-99',
}

print(phonebook['Марк'])     # +7 900 444-55-66

Запись похожа на множество – тоже фигурные скобки, – но элементы идут парами через двоеточие. Отличие в главном: множество отвечает на вопрос «есть ли такое?», а словарь – «что соответствует этому?».

Ключи и значения

  • Ключ – то, по чему ищем. В телефонной книге это имя.
  • Значение – то, что хранится. Здесь – номер телефона.

Три правила, которые надо запомнить сразу:

  1. Ключи уникальны. Двух одинаковых ключей в словаре быть не может.
  2. Ключ – неизменяемый тип. Строка, число или кортеж (занятие 20). Список или множество ключом быть не может.
  3. Порядок – это порядок добавления. Словарь помнит, в каком порядке ключи появились, но не сортирует их сам.
mixed = {
    'имя': 'Аня',        # ключ-строка
    42: 'ответ',          # ключ-число
    (3, 5): 'точка',      # ключ-кортеж
}
print(mixed['имя'])       # Аня
print(mixed[(3, 5)])      # точка

bad = {['Аня']: 'имя'}    # TypeError: unhashable type: 'list'

На практике ключами почти всегда бывают строки или числа. Кортеж-ключ нужен, когда ключ составной – например, пара «ряд и место».

Добавление, изменение, удаление

Обращение по ключу работает на чтение и на запись:

phonebook = {'Аня': '+7 900 111-22-33'}

phonebook['Марк'] = '+7 900 444-55-66'    # ключа не было - пара добавилась
phonebook['Аня'] = '+7 900 000-00-00'     # ключ был - значение заменилось

print(phonebook)
# {'Аня': '+7 900 000-00-00', 'Марк': '+7 900 444-55-66'}

Запись d[key] = value никогда не выдаёт ошибку: если ключ есть – перезаписывает, если нет – создаёт. Это же и опасность: опечатка в имени ключа создаст новую пару вместо исправления старой.

Удаление:

del phonebook['Аня']          # удалить пару по ключу
number = phonebook.pop('Марк')  # удалить и забрать значение в переменную

Если такого ключа нет, del и pop выдают KeyError.

Безопасное чтение и get()

Чтение несуществующего ключа – ошибка:

phonebook = {'Аня': '+7 900 111-22-33'}
print(phonebook['Петя'])
# KeyError: 'Петя'

Поэтому сначала проверяют наличие ключа оператором in. Важно: in для словаря проверяет ключи, а не значения.

if 'Петя' in phonebook:
    print(phonebook['Петя'])
else:
    print('Нет такого контакта')

Второй способ – метод get(ключ, значение_по_умолчанию). Он не падает, а возвращает «заглушку»:

print(phonebook.get('Аня'))          # +7 900 111-22-33
print(phonebook.get('Петя'))         # None
print(phonebook.get('Петя', 'нет'))  # нет

get особенно удобен, когда значение надо не просто прочитать, а прибавить к нему что-то – увидим это в подсчёте частот.

Методы и перебор

Что нужно Как
Все ключи d.keys() или просто for key in d
Все значения d.values()
Все пары d.items() – пары в виде кортежей
Сколько пар len(d)
Значение по ключу d[key] или d.get(key)
Есть ли ключ key in d
Удалить пару del d[key], d.pop(key)
Скопировать d.copy()

Перебор по умолчанию идёт по ключам:

marks = {'Аня': 5, 'Марк': 4, 'Лиза': 5}

for name in marks:
    print(name, marks[name])

А если нужны ключ и значение сразу, берут items() и распаковку (занятие 20 – там же и кортежи):

for name, mark in marks.items():
    print(name, '-', mark)

Вложенные структуры

Значением может быть что угодно: список, другой словарь, вложенный список из занятия 19.

student = {
    'имя': 'Аня',
    'класс': 10,
    'оценки': {'математика': 5, 'русский': 4, 'информатика': 5},
    'кружки': ['шахматы', 'робототехника'],
}

print(student['оценки']['математика'])    # 5
print(student['кружки'][0])               # шахматы

Двойная индексация читается слева направо: сначала словарь оценок, потом оценка по предмету. Такую структуру – «список словарей» – мы будем использовать в проектах: одна запись о книге, ученике или товаре почти всегда описывается словарём.

Практика

Задачи пишем в файле lesson21.py. Первые две – короткие, их удобно проверять сразу после написания.

Задача 1. Частота слов

Дан текст. Нужно посчитать, сколько раз встречается каждое слово. Это классическая задача, и словарь – её родной инструмент.

text = 'мама мыла раму мама мыла пол'

counts = {}
for word in text.split():
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1

print(counts)
# {'мама': 2, 'мыла': 2, 'раму': 1, 'пол': 1}

Логика: слова в словаре пока нет – создаём пару со значением 1. Слово уже есть – увеличиваем счётчик на единицу. split() из занятия 11 разбивает строку по пробелам.

Тот же результат короче, через get:

counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1

print(counts)

counts.get(word, 0) читается так: «дай значение по ключу word, а если ключа нет – считай, что там 0». Дальше прибавляем единицу и записываем обратно. На занятии 22 мы применим это к целому текстовому файлу.

Задача 2. Телефонная книга

phonebook = {
    'Аня': '+7 900 111-22-33',
    'Марк': '+7 900 444-55-66',
    'Лиза': '+7 900 777-88-99',
}

name = input('Кого ищем? ')

if name in phonebook:
    print(name, '-', phonebook[name])
else:
    print('Нет такого контакта')

phonebook['Тимур'] = '+7 900 000-11-22'
phonebook['Марк'] = '+7 900 000-00-00'

print('Контактов в книге:', len(phonebook))

Обратите внимание: input возвращает строку, и ключи у нас строки – преобразование не нужно. Если бы ключами были числа, пришлось бы писать int(input(...)), иначе '5' и 5 – разные ключи.

Дополнительно: добавьте вывод всех контактов по алфавиту. Подсказка – sorted(phonebook) даёт отсортированный список ключей.

Задача 3. Группировка по оценке

Есть словарь «ученик → оценка». Нужно собрать обратный: «оценка → список учеников». Это первая задача, где значением становится список.

marks = {'Аня': 5, 'Марк': 4, 'Лиза': 5, 'Тимур': 3, 'Стас': 4}

by_mark = {}
for name, mark in marks.items():
    if mark not in by_mark:
        by_mark[mark] = []
    by_mark[mark].append(name)

print(by_mark)
# {5: ['Аня', 'Лиза'], 4: ['Марк', 'Стас'], 3: ['Тимур']}

Схема «проверил ключ – создал пустой список – добавил в список» повторяется в самых разных задачах: группировка товаров по категориям, писем по отправителям, слов по первой букве.

Выведем результат по порядку оценок:

for mark, names in by_mark.items():
    print(mark, '-', ', '.join(names))

Задача 4. Объединение с суммированием

Два словаря описывают остатки товара на складе в понедельник и в пятницу. Нужно получить общий итог: по одинаковым товарам количество складывается.

monday = {'яблоки': 3, 'бананы': 2, 'груши': 1}
friday = {'яблоки': 5, 'груши': 4, 'киви': 6}

total = {}
for key, value in monday.items():
    total[key] = value
for key, value in friday.items():
    total[key] = total.get(key, 0) + value

print(total)
# {'яблоки': 8, 'бананы': 2, 'груши': 5, 'киви': 6}

Первый цикл переносит все пары как есть, второй добавляет к ним пятницу. Здесь снова работает get(key, 0): для «яблок» в total уже лежит 3, для «киви» – ничего, поэтому берётся 0.

Тот же трюк позволяет сложить любые два словаря с числовыми значениями: суммы покупок за два месяца, часы по предметам, очки в игре.

Частые ошибки

  • print(counts['слово']) для нового слова – KeyError. Новый ключ появляется только при записи counts['слово'] = 1.
  • counts[word] += 1 без предварительной проверки – тоже KeyError на первом вхождении. Нужен if ... in или get.
  • if 'Аня' in phonebook.values() – так ищут значение, а in phonebook ищет ключ. Для «есть ли такой человек» правильнее второй вариант.
  • Опечатка в ключе при записи (phonebook['Аня '] = ...) молча создаёт новую пару. Проверяйте, что ключ совпадает посимвольно.
  • Список в качестве ключа – TypeError: unhashable type. Ключи должны быть неизменяемыми: строка, число, кортеж.
  • for value in marks перебирает ключи, а не значения. Нужны значения – marks.values().
  • Попытка «починить» двойной индекс: student['оценки', 'математика'] вместо student['оценки']['математика'].

Итоги

  • Словарь хранит пары «ключ → значение». Обращение по ключу мгновенное – не нужно перебирать элементы, как в списке.
  • Ключи уникальны и неизменяемы: строка, число или кортеж. Порядок пар – порядок добавления.
  • d[key] = value добавляет пару или перезаписывает значение. del и pop удаляют, in проверяет наличие ключа, get читает без риска ошибки.
  • keys(), values(), items() дают ключи, значения и пары; for key, value in d.items() – обычный способ перебрать словарь с распаковкой.
  • Значением может быть список или другой словарь – так описывают одну запись о человеке, товаре или книге.
  • Схема d[key] = d.get(key, 0) + 1 считает частоты, а d[key] = d.get(key, 0) + value суммирует значения при объединении словарей.
