Занятие 12. Списки

Цель занятия

Понять, что такое список и зачем он нужен, научиться создавать списки, брать элементы по индексу, добавлять, удалять и сортировать их, а также перебирать список в цикле. Решить задачи: найти наибольшее и наименьшее число, отсортировать числа и оставить только чётные.

Теория

Что такое список

До сих пор мы работали с числами по одному: прочитали, обработали и удалили из памяти. Но иногда нужно помнить сразу все значения. Например, чтобы найти самое большое число или отсортировать числа, их надо где-то хранить. Для этого в Python есть списки.

Список похож на полку с пронумерованными ячейками: в каждой ячейке лежит значение. Нумерация начинается с 0, как у символов строки. Список записывают в квадратных скобках, элементы разделяют запятыми.

numbers = [2, 4, 6, 8, 10]
names = ['Аня', 'Боря', 'Вика']
empty = []              # пустой список

numbers = [2, 4, 6, 8, 10]

print(numbers[0])      # 2, первый элемент
print(numbers[2])      # 6
print(numbers[-1])     # 10, последний элемент
print(len(numbers))    # 5, сколько элементов
print(numbers)         # [2, 4, 6, 8, 10]

Если обратиться к индексу, которого нет (например, numbers[5]), Python выдаст ошибку IndexError. Последний индекс равен len(numbers) - 1.

Срезы у списков работают так же, как у строк: от первого индекса включительно до второго не включительно.

print(numbers[1:3])    # [4, 6]
print(numbers[:2])     # [2, 4]
print(numbers[-2:])    # [8, 10]

Чтобы проверить, есть ли значение в списке, используют оператор in: if 4 in numbers.

В отличие от строки, список можно изменять: элемент заменяют по индексу.

numbers[1] = 100
print(numbers)         # [2, 100, 6, 8, 10]

Добавление, удаление и сортировка

Метод append() добавляет новый элемент в конец списка. Обычно список начинают с пустого и по мере чтения данных добавляют в него элементы.

numbers = []
numbers.append(5)
numbers.append(7)
print(numbers)         # [5, 7]

Метод remove(значение) удаляет первый элемент с таким значением. Если такого значения в списке нет, будет ошибка, поэтому сначала можно проверить его наличие через in.

fruits = ['яблоко', 'банан', 'яблоко']
fruits.remove('яблоко')
print(fruits)          # ['банан', 'яблоко']

Метод sort() упорядочивает список по возрастанию. Если добавить reverse=True, порядок будет по убыванию. Строки сортируются по алфавиту.

a = [5, 1, 8, 2, 4]
a.sort()
print(a)               # [1, 2, 4, 5, 8]
a.sort(reverse=True)
print(a)               # [8, 5, 4, 2, 1]

Методы append(), remove() и sort() меняют сам список. Поэтому просто вызываем их, а результат никуда не записываем. Запись a = a.sort() — ошибка: в переменной a окажется пустое значение None.

Перебор списка в цикле

Все элементы списка можно обработать циклом for. Переменная цикла по очереди получает каждый элемент.

numbers = [2, 4, 6]
for x in numbers:
    print(x * 10)      # 20, 40, 60

Чтобы вывести элементы в одну строку, добавим end=' ':

for x in numbers:
    print(x, end=' ')  # 2 4 6

Если нужны ещё и индексы, перебирают range(len(numbers)): переменная i получает номера 0, 1, 2 и т.д., а сам элемент — numbers[i].

for i in range(len(numbers)):
    print(i, numbers[i])

Проверь себя

Что выведет программа?

a = [10, 20, 30, 40]
print(a[1])
print(a[-1])
print(a[1:3])
a.append(50)
print(len(a))

Ответ: 20, 40, [20, 30], 5.

Практика

Задача 1. Максимум и минимум

Пользователь вводит количество чисел, а затем сами числа. Нужно найти наибольшее и наименьшее из них.

Идея решения: сначала записываем все числа в список. Потом берём первое число и считаем его «пока что самым большим» и «пока что самым маленьким». Проходим по списку: если встретилось число больше, запоминаем его как новый максимум, если меньше — как новый минимум.

n = int(input('Сколько чисел? '))
numbers = []
for i in range(n):
    numbers.append(int(input()))

maximum = numbers[0]
minimum = numbers[0]
for x in numbers:
    if x > maximum:
        maximum = x
    if x < minimum:
        minimum = x

print('Максимум:', maximum)
print('Минимум:', minimum)

Посмотрим, как это работает для чисел 4, 9, 2, 7:

#  x   maximum  minimum
#  4      4        4
#  9      9        4
#  2      9        2
#  7      9        2

Ответ: максимум 9, минимум 2. Начинать нужно с первого элемента списка, а не с нуля: если все числа отрицательные, то ноль был бы ответом, которого нет в списке. Проверить себя можно с помощью готовых функций max(numbers) и min(numbers).

Дополнительное задание: выведите номер (индекс) максимального элемента. Подсказка: numbers.index(maximum).

Задача 2. Сортировка

Пользователь вводит количество чисел и сами числа. Нужно вывести их по возрастанию, а затем по убыванию.

n = int(input('Сколько чисел? '))
numbers = []
for i in range(n):
    numbers.append(int(input()))

numbers.sort()
print('По возрастанию:', numbers)

numbers.sort(reverse=True)
print('По убыванию:', numbers)

Для чисел 5, 1, 8, 2, 4 программа выведет [1, 2, 4, 5, 8] и [8, 5, 4, 2, 1].

Дополнительное задание: выведите три самых больших числа. Подсказка: после сортировки по убыванию возьмите срез numbers[:3].

Задача 3. Фильтрация: только чётные числа

Пользователь вводит количество чисел и сами числа. Нужно вывести только чётные.

Идея решения: создаём новый пустой список evens. Проходим по всем числам, и если число чётное (остаток от деления на 2 равен 0), добавляем его в evens.

n = int(input('Сколько чисел? '))
numbers = []
for i in range(n):
    numbers.append(int(input()))

evens = []
for x in numbers:
    if x % 2 == 0:
        evens.append(x)

print('Чётные числа:', evens)

Для чисел 7, 2, 9, 4, 10, 3 программа выведет: Чётные числа: [2, 4, 10]. Если чётных чисел нет, будет выведен пустой список [].

Дополнительное задание: оставьте только числа, которые больше 10 и делятся на 3. Подсказка: в условии используйте and.

Во время практики часто встречаются одни и те же ошибки.

  • Если обратиться к несуществующему индексу (например, numbers[len(numbers)]), возникнет ошибка IndexError. Последний индекс равен len(numbers) - 1.
  • Если написать a = a.sort(), в переменной a окажется None. Метод sort() нужно просто вызывать: a.sort().
  • Если начинать поиск максимума с нуля, а все числа отрицательные, ответ будет неверным. Начинайте с первого элемента списка.
  • Если забыть int() при чтении числа, в списке окажутся строки, и сортировка и сравнения дадут неверный результат.

Итоги

  • Список хранит несколько значений в квадратных скобках. Элементы нумеруются с 0, последний имеет индекс -1. Длину списка даёт len().
  • Список можно изменять: numbers[i] = значение, а также append() (добавить в конец), remove() (удалить значение) и sort() (отсортировать).
  • Методы списков меняют сам список, поэтому результат не нужно присваивать: a = a.sort() — ошибка.
  • Список перебирают циклом for x in numbers или for i in range(len(numbers)).
  • Мы решили три типовые задачи: найти максимум и минимум, отсортировать числа, отфильтровать чётные.
