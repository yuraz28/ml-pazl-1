Теория · Повторение

Цикл вместо пяти строк

Руками — пять строк

print('Шаг 1')
print('Шаг 2')
print('Шаг 3')
print('Шаг 4')
print('Шаг 5')

Циклом — две

for i in range(1, 6):
    print('Шаг', i)
Строк стало две, а повторов можно заказать хоть сто: меняется только число в range().

Теория · Цикл for

Первый цикл for

n = int(input('Сколько строк напечатать? '))for i in range(n):    print(i)
range(n) даёт числа от 0 до n − 1: range(3) — это 0, 1, 2. Само число n в счёт не попадает.

Теория · Границы счёта

range: начало и конец

n = int(input('До какого числа считать? '))for i in range(1, n + 1):    print(i)
Верхняя граница в счёт не входит. Чтобы пройти от 1 до n включительно, пишут range(1, n + 1).

Теория · Границы счёта

Шаг счёта

n = int(input('Считаем до какого числа? '))for i in range(2, n + 1, 2):    print(i)
Третий аргумент — шаг. range(2, 11, 2) берёт каждое второе число: 2, 4, 6, 8, 10.

Теория · Границы счёта

Обратный отсчёт

start = int(input('С какого числа начать? '))for i in range(start, 0, -1):    print(i)
Шаг бывает отрицательным: range(5, 0, -1) идёт назад — 5, 4, 3, 2, 1. Ноль в счёт не входит.

Теория · Цикл for

Как работает цикл

Python берёт из range(3) первое число и кладёт его в i.

Выполняется тело цикла — строки с отступом под for.

Python берёт следующее число, и тело повторяется.

Числа в range(3) закончились — цикл останавливается.

Теория · Цикл for

Тело цикла и отступ

Двоеточие после range() открывает тело цикла.

Тело — все строки с отступом под for. Отступ в 4 пробела, как в if.

Первая строка без отступа уже вне цикла: она выполнится один раз.

VS Code ставит отступ сам — после двоеточия и Enter.

Теория · Результат в цикле

Накопитель суммы

n = int(input('Сколько чисел сложить? '))total = 0for i in range(1, n + 1):    total += iprint(total)
Перед циклом заводим total = 0. На каждом повторе прибавляем к нему число — после цикла в total лежит вся сумма.

Теория · Результат в цикле

Счётчик: сколько раз сработало

n = int(input('До какого числа считаем? '))count = 0for i in range(1, n + 1):    if i % 2 == 0:        count += 1print('Чётных:', count)
Проверку кладут прямо в тело цикла — она выполняется на каждом повторе. Подошло число — увеличиваем счётчик на 1.

Теория · Цикл for

for идёт по буквам

word = input('Введите слово: ')for letter in word:    print(letter)
range() — не единственный вариант. Со строкой цикл берёт по одной букве слева направо: сколько букв, столько и повторов.

Теория · Частые ошибки

Чего цикл не любит

ошибка 1

Забыли отступ

Без отступа Python не понимает, что входит в тело. Строки тела сдвигают на 4 пробела.

ошибка 2

Ждали 1…5

range(5) начинает с нуля и до пятёрки не доходит: 0, 1, 2, 3, 4. Для 1…5 нужен range(1, 6).

ошибка 3

Забыли total = 0

Накопитель заводим до цикла. Без этого складывать будет не с чем.

Тело цикла отбивают от строки for — иначе Python остановит программу на первом же запуске.

Задача 1

Дневник оценок

Четыре оценки вводим по одной в цикле: считаем средний балл и число пятёрок.

Доп. задание

Таблица умножения

Печатаем таблицу умножения на выбранное число и сумму всех строк.

Работаем в VS Code: файл lesson8.py.

Практика · Задача 1

Условие задания

Что на вход

Четыре оценки из дневника — каждая с новой строки. Оценки превращаем в целые числа через int().

Что на выход

Две строки: средний балл (дробное число) и сколько в дневнике пятёрок.

Тесты
5 · 4 · 5 · 4→Средний балл: 4.5, Пятёрок: 2
3 · 3 · 4 · 4→Средний балл: 3.5, Пятёрок: 0
5 · 5 · 3 · 3→Средний балл: 4.0, Пятёрок: 2

Практика · Задача 1 · Шаг 1

Считаем оценки и сумму

Ввод стоит внутри цикла: программа спросит оценку четыре раза. Проверка пятёрки и печать итогов — на следующем шаге — тут только сумма и накопители.
total = 0fives = 0for i in range(4):    mark = int(input('Оценка: '))    total += mark

Практика · Задача 1 · Шаг 2

Пятёрки и средний балл

Тот же цикл: внутри него проверяем каждую оценку, а печать итогов стоит после цикла — там сумма и счётчик уже готовы.
for i in range(4):    mark = int(input('Оценка: '))    total += mark    if mark == 5:        fives += 1print('Средний балл:', total / 4)print('Пятёрок:', fives)

Практика · Доп. задание · Шаг 2

Печатаем таблицу и сумму

Внутри цикла печатается строка таблицы и копится сумма, а итог печатается один раз — после цикла.
for i in range(1, 11):    total += k * i    print(f'{k} × {i} = {k * i}')print('Сумма:', total)
