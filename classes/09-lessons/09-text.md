# Занятие 9. Цикл for

## Цель занятия

Изучить синтаксис цикла `for`, работу переменной цикла и функции `range()` с одним, двумя и тремя аргументами. Научиться перебирать символы строки и решать с помощью циклов задачи: таблица умножения, сумма чисел от 1 до N и «ёлочка» из звёздочек.

---

## Теория

### Цикл for: повторяем действия

Одно из главных преимуществ компьютера – он может повторять одни и те же действия многократно, быстро и не уставая. Для этого в Python есть **циклы**. Цикл `for` подходит, когда мы заранее знаем, сколько повторений (**итераций**) нужно сделать. Другой вид цикла, `while`, повторяется до наступления события, его мы изучим позже.

```python
for i in range(3):
    print('Привет')
```

Слово `for` пишется строчными буквами, а в конце строки ставится двоеточие. Строки с отступом под `for` образуют **тело цикла**: именно они повторяются. Одно выполнение тела цикла называется **итерацией**. Строки без отступа в цикл не входят.

```python
print('Начало')
for i in range(3):
    print('Привет')
    print('Пока')
print('Конец')
```

Эта программа выведет слово «Начало», затем три раза пару строк «Привет» и «Пока» и один раз «Конец».

---

### Переменная цикла

В строке `for i in range(5)` буква `i` – это **переменная цикла**. Когда цикл начинает работу, Python записывает в неё `0`, а после каждой итерации увеличивает на 1. Так переменная показывает номер текущей итерации.

```python
for i in range(5):
    print(i)      # 0 1 2 3 4 (каждое число с новой строки)
```

Правая граница в `range()` **не включается**: `range(5)` даёт числа от 0 до 4, то есть ровно 5 значений.

Чтобы нумерация начиналась с единицы, можно вывести `i + 1`:

```python
for i in range(3):
    print(i + 1, '-- Привет')
```

Переменную цикла можно назвать как угодно, но чаще всего используют буквы `i`, `j`, `k`.

---

### Функция range(): три формы

У функции `range()` может быть один, два или три аргумента.

- `range(stop)` – числа от 0 до `stop - 1`. Например, `range(4)` даёт 0, 1, 2, 3.
- `range(start, stop)` – числа от `start` до `stop - 1`. Например, `range(1, 5)` даёт 1, 2, 3, 4.
- `range(start, stop, step)` – числа от `start` с шагом `step`, пока не дойдём до `stop` (сам `stop` не включается).

```python
for i in range(1, 6):
    print(i, end=' ')     # 1 2 3 4 5

for i in range(0, 10, 2):
    print(i, end=' ')     # 0 2 4 6 8

for i in range(5, 0, -1):
    print(i, end=' ')     # 5 4 3 2 1
```

Шаг может быть отрицательным, тогда числа убывают. Параметр `end=' '` в `print()` говорит, что после вывода нужно поставить пробел, а не переходить на новую строку. Чтобы дойти до числа `n` включительно, пишут `range(1, n + 1)`.

---

### Перебор символов строки

Цикл `for` умеет перебирать не только числа, но и любые последовательности. Строка – это последовательность символов, поэтому переменная цикла по очереди принимает значение каждого символа:

```python
for ch in 'Python':
    print(ch)
```

Этот код выведет буквы P, y, t, h, o, n, каждую с новой строки. Такой перебор удобно сочетать с условием, например чтобы посчитать, сколько раз буква встречается в слове:

```python
text = input('Введите слово: ')
count = 0
for ch in text:
    if ch == 'а':
        count += 1
print('Букв а:', count)
```

Для слова «банан» программа выведет 2. Позже мы узнаем, что таким же образом можно перебирать и другие последовательности, например списки.

## Практика

### Задача 1. Таблица умножения

Пользователь вводит число. Нужно вывести таблицу умножения этого числа на числа от 1 до 10.

**Идея решения:** переменная цикла `i` должна пробежать значения от 1 до 10. Поэтому используем `range(1, 11)`: правая граница не включается.

```python
n = int(input('Введите число: '))

for i in range(1, 11):
    print(n, '*', i, '=', n * i)
```

Для числа 7 программа выведет строки от `7 * 1 = 7` до `7 * 10 = 70`.

**Дополнительное задание:** выведите таблицу умножения для всех чисел от 2 до 9. Подсказка: поместите один цикл `for` внутрь другого.

```python
for n in range(2, 10):
    for i in range(1, 11):
        print(n, '*', i, '=', n * i)
    print()
```

### Задача 2. Сумма чисел от 1 до N

Пользователь вводит натуральное число N. Нужно найти сумму всех целых чисел от 1 до N.

**Идея решения:** заведём переменную `total`, в которой будем накапливать сумму. Перед циклом она равна 0. На каждой итерации прибавляем к ней текущее число `i`.

```python
n = int(input('Введите N: '))

total = 0
for i in range(1, n + 1):
    total += i

print('Сумма:', total)
```

Для N = 5 значение `total` меняется так: 1, 3, 6, 10, 15. Последнее значение и есть ответ. Переменную мы назвали `total`, а не `sum`, потому что `sum` – имя встроенной функции Python. Проверить результат можно по формуле `n * (n + 1) // 2`.

### Задача 3. «Ёлочка» из звёздочек

Пользователь вводит высоту `n`. Нужно вывести «ёлочку» из `n` строк.

Сначала решим более простую задачу: треугольник, в котором в `i`-й строке стоит `i` звёздочек. Вспомним, что строку можно умножать на число: `'*' * 3` даёт `'***'`.

```python
n = int(input('Введите высоту: '))

for i in range(1, n + 1):
    print('*' * i)
```

Для `n = 4` получится:

```
*
**
***
****
```

Чтобы получилась настоящая ёлочка, нужно сдвигать каждую строку вправо пробелами и увеличивать количество звёздочек на 2. В `i`-й строке будет `2 * i - 1` звёздочек и `n - i` пробелов перед ними.

```python
n = int(input('Введите высоту: '))

for i in range(1, n + 1):
    print(' ' * (n - i) + '*' * (2 * i - 1))
```

Для `n = 4` программа выведет:

```
   *
  ***
 *****
*******
```

Во время практики часто встречаются одни и те же ошибки.

- Если забыть двоеточие после `for` или отступ у тела цикла, Python сообщит об ошибке. Строка без отступа в цикл не входит.
- Если написать `range(n)`, числа пойдут от 0 до `n - 1`. Для чисел от 1 до `n` нужно `range(1, n + 1)`.
- Если поставить `total = 0` внутри цикла, сумма будет обнуляться на каждой итерации.
- Если передать в `range()` строку, например `range(input())`, возникнет ошибка `TypeError`. Сначала нужно преобразовать ввод с помощью `int()`.

---

## Итоги

- Цикл `for` повторяет тело цикла заданное число раз. После `for` ставится двоеточие, а тело цикла выделяется отступом.
- Переменная цикла по очереди принимает значения из `range()`. Если она не нужна, её называют `_`.
- `range(stop)`, `range(start, stop)` и `range(start, stop, step)` задают числа для перебора. Правая граница не включается, а шаг может быть отрицательным.
- Цикл `for` перебирает не только числа, но и символы строки.
- С помощью цикла можно накапливать результат (сумма), печатать таблицы и рисовать фигуры из символов, используя умножение строки на число.
