Занятие 9

Цикл while

Часть 1

Теория

Блок 1

Цикл вместо копирования

Повторяем действие, не выписывая одну и ту же строку пять раз.

Блок 2

Как устроен while

Условие сверху, тело цикла с отступом, возврат к проверке.

Блок 3

Счётчик и шаг

Переменная, которая на каждой итерации растёт или уменьшается.

Блок 4

Бесконечный цикл

Если счётчик не менять, условие не станет ложным никогда.

Блок 5

Накопитель

Переменная, которая собирает сумму по частям: total += i.

Блок 6

Ввод в цикле

Спрашиваем числа, пока не введут 0.

Теория · Повторение

Цикл вместо пяти строк

без цикла

print(1)
print(2)
print(3)
print(4)
print(5)

с циклом

n = 1
while n <= 5:
    print(n)
    n += 1
Строк меньше, а чисел может быть не пять, а сто пятьдесят: меняем одно условие — меняется вся программа.

Теория · Устройство

Как работает while

Проверить условие — строка с while и двоеточием.

Выполнить тело — строки с отступом под while.

Вернуться к условию — один повтор называют итерацией.

Выйти из цикла — когда условие стало ложным.

Условие проверяется перед каждым повтором: если оно ложно уже в первый раз, тело не выполнится ни разу.

Двоеточие и отступ работают так же, как в if: тело цикла — это строки с отступом.

Теория · Итерации

Обратный отсчёт: считаем итерации

n = int(input('Старт с какого числа? '))while n > 0:    print(n)    n -= 1print('Поехали!')
Каждый повтор — итерация. Условие проверяется перед каждой, а счётчик уменьшается внутри тела цикла.

Теория · Осторожно

Бесконечный цикл

n = 1while n <= 5:    print(n)
Счётчик не меняется — условие вечно истинно: это бесконечный цикл. Такую программу прерывают вручную — в терминале это Ctrl+C.

Теория · Накопитель

Собираем сумму по частям

n = int(input('Сколько чисел сложить? '))total = 0i = 1while i <= n:    total += i    i += 1print('Сумма:', total)
Здесь в цикле живут две переменные: i считает шаги, а total копит результат. К концу цикла в total лежит 15.

Теория · Ввод

Спрашиваем, пока не введут 0

total = 0x = int(input('Число (0 — стоп): '))while x != 0:    total += x    x = int(input('Число (0 — стоп): '))print('Итог:', total)
Сколько чисел придёт — заранее неизвестно, поэтому while. Ввели 0 — условие стало ложным, цикл закончился.

Часть 2

Практика

Задача 1

Обратный отсчёт

Выводим числа от N до 1, а в конце — «Поехали!».

Задача 2

Сумма чисел

Складываем все числа от 1 до N через накопитель total.

Задача 3

Копилка

Считаем недели, пока в копилке не наберётся нужная сумма.

Доп. задание

Нулевой взнос

Проверка перед циклом: при взносе 0 копилка не растёт никогда.

Работаем в VS Code: файл lesson9.py.

Практика · Задача 1

Условие задания

Что на вход

Одно целое число — с какого числа начинаем отсчёт.

Что на выход

Числа по убыванию, каждое на своей строке, и последняя строка Поехали!.

Тесты
Старт 3→3, 2, 1, Поехали!
Старт 5→5, 4, 3, 2, 1, Поехали!
Старт 1→1, Поехали!

Практика · Задача 1 · Шаг 1

Цикл идёт вниз

Счётчик n уменьшается на 1 на каждом проходе: n -= 1. Как только n станет 0, условие n > 0 окажется ложным — и цикл закончится.
n = 3while n > 0:    print(n)    n -= 1

Практика · Задача 1 · Полное решение

Отсчёт стартует с введённого числа

Число читаем через int(input()), а строка Поехали! стоит без отступа — она выполняется один раз, уже после выхода из цикла.
n = int(input('Старт с какого числа? '))while n > 0:    print(n)    n -= 1print('Поехали!')

Практика · Задача 2

Условие задания

Что на вход

Одно целое число N — сколько чисел складываем.

Что на выход

Одна строка: сумма всех чисел от 1 до N.

Тесты
Чисел: 5→Сумма: 15
Чисел: 3→Сумма: 6
Чисел: 1→Сумма: 1

Практика · Задача 2 · Шаг 1

Накопитель работает

total копит сумму, i идёт от 1 до 5. На каждом проходе прибавляем i к total — и увеличиваем i, иначе условие i <= 5 не станет ложным.
total = 0i = 1while i <= 5:    total += i    i += 1print('Сумма:', total)

Практика · Задача 2 · Полное решение

Сколько чисел — решает пользователь

Меняется только граница цикла: вместо пятёрки стоит переменная n, которую мы прочитали с клавиатуры. Печать — одна строка после цикла.
n = int(input('Сколько чисел сложить? '))total = 0i = 1while i <= n:    total += i    i += 1print('Сумма:', total)

Практика · Задача 3

Условие задания

Что на вход

Два числа: сколько нужно накопить (goal) и сколько откладываем за неделю (per_week).

Что на выход

Сколько недель понадобилось — или сообщение, что за 3 недели цель не достигнута.

Тесты
Цель 10000 · по 5000→Недель понадобилось: 2
Цель 10000 · по 3000→Цель не достигнута за 3 недели
Цель 10000 · по 10000→Недель понадобилось: 1

Практика · Задача 3 · Шаг 1

Копилка и счётчик недель

Условие проверяется перед каждой неделей. Как только в копилке достаточно — выходим из цикла.
saved = 0week = 0goal = int(input('Сколько нужно накопить? '))per_week = int(input('Сколько откладываем за неделю? '))while saved < goal:    saved += per_week    week += 1print('Недель понадобилось:', week)

Практика · Задача 3 · Шаг 2

Добавляем итоговые строки

Обе строки стоят без отступа и выполняются один раз — уже после выхода из цикла. Недели считает week, сумма лежит в saved: копим по 4000 — за третью неделю в копилке окажется 12000.
saved = 0week = 0goal = int(input('Сколько нужно накопить? '))per_week = int(input('Сколько откладываем за неделю? '))while saved < goal:    saved += per_week    week += 1print('Недель понадобилось:', week)print('В копилке:', saved)

Практика · Задача 3 · Полное решение

Копилка с предохранителем

В условии цикла появилась вторая часть: week < 3. Она останавливает цикл, даже если цель не достигнута, — и тогда сработает ветка else.
saved = 0week = 0goal = int(input('Сколько нужно накопить? '))per_week = int(input('Сколько откладываем за неделю? '))while saved < goal and week < 3:    saved += per_week    week += 1if saved >= goal:    print('Недель понадобилось:', week)else:    print('Цель не достигнута за 3 недели')

Практика · Дополнительное задание

Условие задания

Что на вход

Два числа: цель и недельный взнос. Взнос может быть нулевым или отрицательным.

Что на выход

Либо сколько недель понадобилось, либо подсказка Взнос должен быть больше нуля.

Тесты
Цель 10000 · по 0→Взнос должен быть больше нуля
Цель 10000 · по 5000→Недель понадобилось: 2
Цель 10000 · по -500→Взнос должен быть больше нуля

Практика · Дополнительное задание · Шаг 1

Проверка перед циклом

Сначала проверяем взнос, и только потом считаем недели. Это тот самый случай, который спасает от бесконечного цикла из начала занятия.
goal = int(input('Сколько нужно накопить? '))per_week = int(input('Сколько откладываем за неделю? '))if per_week <= 0:    print('Взнос должен быть больше нуля')

Практика · Дополнительное задание · Полное решение

Ветка else с циклом

Взнос больше нуля — считаем недели, как в задаче 3. Взнос 0 или меньше — печатаем подсказку и цикл не запускаем совсем.
saved = 0week = 0goal = int(input('Сколько нужно накопить? '))per_week = int(input('Сколько откладываем за неделю? '))if per_week <= 0:    print('Взнос должен быть больше нуля')else:    while saved < goal:        saved += per_week        week += 1    print('Недель понадобилось:', week)

Итоги

Что изучили

while повторяет тело цикла, пока условие истинно; проверка идёт перед каждым повтором.
Тело цикла выделяют двоеточие и отступ в 4 пробела — как в блоке if.
Счётчик меняется внутри цикла, иначе условие не станет ложным и программа не остановится.
Накопитель собирает результат по частям: total += i.
Цикл умеет читать числа, пока не введут 0, и выходить по составному условию saved < goal and week < 3.
Копилка показала: одна и та же программа даёт разный результат при разных взносах.
