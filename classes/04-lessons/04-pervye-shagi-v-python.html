Теория · Программа

Программа — это список команд

Компьютерная программа — это список команд для компьютера.

Команды бывают разными

Считать данные с клавиатуры, выполнить вычисления, вывести результат на экран.

Программа — это не только код

Браузер, мессенджер и сама операционная система тоже программы.

Язык программирования

Набор правил, по которым компьютер понимает команды. Текст программы называется программным кодом.

Правила записи команд у каждого языка свои. Дальше — про то, как программа превращается в работу компьютера.

Теория · Языки

Два вида языков

Компилируемые: C, C++, Pascal

Программу сначала целиком проверяют на ошибки и переводят в машинный код специальной программой — компилятором. И только потом запускают.

Интерпретируемые: Python, PHP, Ruby

Программу целиком в машинный код не переводят. Вместо этого интерпретатор идёт по коду и выполняет команды одну за другой.

Python — интерпретируемый язык. Именно интерпретатор выполняет наши команды, когда мы нажимаем «Запустить».

Теория · Python

Откуда взялся Python

Python разработал голландский программист Гвидо ван Россум, первая версия вышла в 1991 году.

Запомнить легко: язык назван в честь шоу, а не в честь змеи.

Теория · Версии

Python 2 и Python 3

Python 2 — устарел

Поддержку второй версии прекратили в 2020 году.

Python 3 — современный

Он не совместим со второй версией полностью, а на Python 2 написано много программ, которые непросто переписать.

Полностью отказаться от Python 2 не получилось — поэтому у языка две версии. В нашем курсе мы работаем только с Python 3.

Теория · Плюсы

Почему Python выбирают

Интерпретируемый

Программа запускается прямо из исходного кода, отдельная компиляция не нужна.

Высокоуровневый

Код близок к человеческому языку, а многие технические детали скрыты.

Платформонезависимый

Программы пишут и запускают в Windows, macOS и Linux.

Открытый исходный код

Распространяется бесплатно.

Простой в изучении

Поэтому его часто выбирают первым языком.

Динамический

Тип переменной определяется автоматически по значению.

Много библиотек

Готовые библиотеки на любые задачи — их огромное количество.

Теория · Минусы

И два недостатка

Работает медленнее

Программа на Python выполняется медленнее, чем программа на C или C++.

Динамическая типизация

В небольших программах помогает, а в сложных проектах становится проблемой: ошибки с типами проявляются только при запуске.

Для учебных программ и небольших проектов оба минуса незаметны.

Теория · Первый файл

Первый файл: hello.py

# Первая программаprint("Привет, мир!")print('Привет, мир!')
Программы на Python хранятся в файлах с расширением .py: создаём hello.py в VS Code. Запускаем кнопкой запуска или командой python hello.py в терминале.

Теория · Синтаксис

Особенности синтаксиса

Одна команда — одна строка

Точка с запятой в конце не нужна.

Кавычки

Текст в программе (строки) записываем в кавычках — одинарных или двойных.

Комментарий

Начинается с символа #. Интерпретатор его не выполняет.

Регистр важен

name и Name — это разные имена.

Блоки кода выделяются отступами, а не фигурными скобками. Обычно используют 4 пробела — это понадобится нам в условиях и циклах.

Теория · Переменные

Переменная — это имя для значения

Переменная — это имя, под которым в памяти компьютера хранится значение.
Её можно сравнить с подписанной коробкой: на коробке написано имя, а внутри лежит значение.
Переменную создают с помощью присваивания. Знак = в Python означает «положить значение в переменную», а не равенство, как в математике. Тип значения указывать не нужно — Python определяет его сам.

Теория · Присваивание

Создаём переменную

name = "Даша"age = 25print(name, age)print("Возраст:", age)
Функция print() умеет выводить несколько значений сразу, если перечислить их через запятую.

Теория · Присваивание

Значение можно менять

age = 25print(age)age = 26print(age)
Если написать age = 26, в переменной будет храниться уже новое значение, а старое исчезнет.

Теория · Имена

Правила имён переменных

Буквы, цифры, подчёркивание

Имя может содержать только эти символы.

Не начинается с цифры

2name — ошибка.

Без пробелов

Вместо пробела ставят подчёркивание: user_age.

Нельзя занятые слова

if, for, while, True — Python уже занял их для себя.

Регистр важен

age и Age — две разные переменные.

Кроме правил есть договорённости, которых придерживаются программисты (стандарт PEP 8): имена пишут строчными буквами, слова разделяют подчёркиванием, а сами имена делают понятными — user_age лучше, чем x.

Теория · Типы данных

Четыре основных типа

int

Целые числа

Например, 25, 0 или -3.

float

Дробные числа

Например, 1.75. Разделитель — точка, а не запятая.

str

Строки

Текст в кавычках, например "Мира".

bool

Логический тип

Только True (истина) и False (ложь), с заглавной буквы.

Тип определяется значением: 25 — это число, а "25" в кавычках — уже строка. Подробнее о типах и о преобразовании между ними поговорим на следующих занятиях.

Теория · type()

Тип значения показывает type()

age = 25height = 1.75name = "Мира"is_online = Trueprint(type(age))print(type(height))print(type(name))print(type(is_online))
Узнать тип значения можно с помощью функции type(): в скобках пишем имя переменной. Тип определяется значением, а не именем.

Практика · Ошибки

Четыре частые ошибки

city = Москваheight = 1,68user age = 25Name = "Мира"print(name)
Каждая строка в примере сломана по-своему: выбирайте ошибку чипом. Python останавливается на первой ошибке и сам пишет её название и номер строки.

Практика · Задача 1

Условие задания

Что на вход

Четыре значения для персонажа: имя, возраст, рост и статус «в сети» — True или False. Ввод с клавиатуры не нужен: значения задаём прямо в коде.

Что на выход

Четыре строки карточки, затем типы имени и возраста, а в конце — обновлённый возраст после смены значения.

Тесты
Даша · 25 · 1.68 · в сети→Имя: Даша, Возраст: 25, Рост: 1.68, Жив: True, <class 'str'>, <class 'int'>, Новый возраст: 26
Тимур · 31 · 1.82 · не в сети→Имя: Тимур, Возраст: 31, Рост: 1.82, Жив: False, <class 'str'>, <class 'int'>, Новый возраст: 32
Аня · 8 · 2.0 · не в сети→Имя: Аня, Возраст: 8, Рост: 2.0, Жив: False, <class 'str'>, <class 'int'>, Новый возраст: 9

Практика · Задача 1 · Шаг 1

Создаём четыре переменные

Каждое значение кладём в свою переменную. Запустите программу и убедитесь, что кавычки стоят только у имени.
name = "Даша"age = 25height = 1.68is_online = True

Практика · Задача 1 · Шаг 2

Печатаем карточку

print() с двумя аргументами печатает подпись и значение через пробел. Карточка — четыре таких строки.
print("Имя:", name)print("Возраст:", age)print("Рост:", height)print("Жив:", is_online)

Практика · Задача 1 · Шаг 3

Меняем значения

Переменная помнит последнее значение: после присваивания печать покажет новое.
age = 26is_online = Falseprint("Возраст:", age)print("Жив:", is_online)

Практика · Задача 1 · Шаг 4

Проверяем типы

type() показывает тип значения. Сравните, что выйдет для имени, возраста, роста и статуса.
print(type(name))print(type(age))print(type(height))print(type(is_online))

Практика · Задача 1

Полное решение

Та же программа целиком: четыре переменные, карточка, смена возраста и проверка типов.
name = "Даша"age = 25height = 1.68is_online = Trueprint("Имя:", name)print("Возраст:", age)print("Рост:", height)print("Жив:", is_online)print(type(name))print(type(age))age = age + 1print("Новый возраст:", age)

Практика · Дополнительное задание

Условие задания

Что на вход

Число 25 и такая же запись в кавычках — "25". Значения задаём прямо в коде.

Что на выход

Три строки: тип первого значения, тип второго и оба значения, напечатанные через запятую.

Тесты
Число 25→<class 'int'>, <class 'str'>, 25 25
Число 31→<class 'int'>, <class 'str'>, 31 31
Число 8→<class 'int'>, <class 'str'>, 8 8
