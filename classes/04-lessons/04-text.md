## Теория

### Что такое программа и язык программирования

**Компьютерная программа** — это список команд (инструкций) для компьютера. Команды могут быть разными: считать данные с клавиатуры, выполнить вычисления, вывести результат на экран. Программами являются браузер, мессенджер и даже сама операционная система.

Чтобы написать программу, используют **язык программирования**. Это набор правил, по которым компьютер понимает команды и выполняет их. Текст программы на любом языке называется **программным кодом**.

Языки программирования делят на **компилируемые** и **интерпретируемые**. Программу на компилируемом языке (C, C++, Pascal) сначала целиком проверяют на ошибки и переводят в машинный код специальной программой — **компилятором**, и только потом запускают. Программу на интерпретируемом языке (Python, PHP, Ruby) целиком в машинный код не переводят. Вместо этого специальная программа — **интерпретатор** — идёт по коду и выполняет команды одну за другой.

### Язык Python

Python разработал голландский программист **Гвидо ван Россум**, первая версия вышла в 1991 году. Название языка пришло от британского комедийного шоу «Монти Пайтон», которое Гвидо любил, а не от змеи.

У Python есть две основные версии: **Python 2** и **Python 3**. Вторая версия устарела, и её поддержку прекратили в 2020 году. Полностью отказаться от неё не получилось, потому что Python 3 не совместим с ней полностью, а на Python 2 написано много программ, которые непросто переписать. В нашем курсе мы работаем только с **Python 3**.

### Сильные и слабые стороны Python

У Python много преимуществ:

- Python **интерпретируемый**: программа запускается прямо из исходного кода, отдельная компиляция не нужна.
- Python **высокоуровневый**: код близок к человеческому языку, а многие технические детали работы компьютера скрыты.
- Python **платформонезависимый**: программы можно писать и запускать в Windows, macOS и Linux.
- Python имеет **открытый исходный код** и распространяется бесплатно.
- Python **простой в изучении**, поэтому его часто выбирают первым языком.
- Python **динамический**: тип переменной определяется автоматически по значению, что упрощает написание небольших программ.
- Для Python существует огромное количество готовых **библиотек** на любые задачи.

Есть и недостатки. Python работает **медленнее**, чем C и C++. Динамическая типизация, которая помогает в небольших программах, в сложных проектах может стать проблемой, потому что ошибки с типами проявляются только при запуске.

Python подходит для очень разных задач:

- **Системное программирование и администрирование**: скрипты, которые работают с файлами и операционной системой.

- **Анализ данных, машинное обучение и AI**: сегодня это одно из главных направлений, и для него Python основной язык.

Python используют технологические компании, банки, научные организации. На нём работают части поисковых систем и видеосервисов, тестируют оборудование, прогнозируют финансовые рынки и делают научные расчёты. ### Первый файл и особенности синтаксиса

Программы на Python хранятся в файлах с расширением `.py`. Мы создаём файл в VS Code, например `hello.py`, пишем в нём код и запускаем его кнопкой запуска или командой `python hello.py` в терминале.

Простейшая программа выводит текст на экран с помощью функции `print()`:

```python
# Первая программа
print("Привет, мир!")
```

У Python есть несколько важных особенностей синтаксиса:

- Каждая команда обычно пишется на отдельной строке, а точка с запятой в конце не нужна.
- Текст в программе (строки) записывается в кавычках, одинарных или двойных.
- Комментарий начинается с символа `#`. Интерпретатор его не выполняет, комментарии нужны для пояснений.
- Регистр букв важен: `name` и `Name` — это разные имена.
- Блоки кода выделяются **отступами**, а не фигурными скобками. Обычно используют 4 пробела. Эта особенность понадобится нам в условиях и циклах.

### Переменные

**Переменная** – это имя, под которым в памяти компьютера хранится значение. Её можно сравнить с подписанной коробкой: на коробке написано имя, а внутри лежит значение.

Переменную создают с помощью **присваивания**. Знак `=` в Python означает «положить значение в переменную», а не равенство, как в математике. Тип значения указывать не нужно, Python определяет его сам.

```python
name = "Даша"
age = 25
print(name, age)
```

Значение переменной можно менять. Если написать `age = 26`, то в переменной `age` будет храниться уже новое значение, а старое исчезнет. Функция `print()` умеет выводить несколько значений сразу, если перечислить их через запятую.

У имён переменных есть правила:

- Имя может содержать только буквы, цифры и символ подчёркивания.
- Имя не может начинаться с цифры. Например, `2name` — ошибка.
- В имени нельзя использовать пробелы. Вместо пробела ставят подчёркивание: `user_age`.
- Нельзя использовать слова, которые Python уже занял для себя, например `if`, `for`, `while`, `True`.
- Регистр важен: `age` и `Age` – две разные переменные.

Кроме правил есть договорённости, которых придерживаются программисты (**стандарт PEP 8**). Имена пишут строчными буквами, слова разделяют подчёркиванием, а сами имена делают понятными: `user_age` лучше, чем `x`.

### Типы данных (обзор)

Каждое значение в Python имеет **тип**. Пока познакомимся с четырьмя основными:

- `int` – целые числа, например `25`, `0`, `-3`.
- `float` – дробные числа, например `1.75`. В качестве разделителя используется точка, а не запятая.
- `str` – строки, то есть текст в кавычках, например `"Мира"`.
- `bool` – логический тип. Он принимает только два значения: `True` (истина) и `False` (ложь). Писать их нужно с заглавной буквы.

Узнать тип значения можно с помощью функции `type()`:

```python
age = 25
print(type(age))  # <class 'int'>
```

Тип определяется значением. Например, `25` – это число, а `"25"` в кавычках – уже строка. Подробнее о типах и о преобразовании между ними мы поговорим на одном из следующих занятий.

## Практика: программа «Карточка персонажа»

Пишем программу вместе, а затем каждый создаёт своего персонажа.

1. Создаём в VS Code файл `character.py`.
2. Объявляем четыре переменные: `name` (имя, строка), `age` (возраст, целое число), `height` (рост в метрах, дробное число) и `is_online` (статус, логическое значение).
3. Выводим карточку персонажа на экран с помощью `print()`.
4. Меняем значения переменных, например возраст и статус, и выводим карточку ещё раз.
5. Определяем тип каждой переменной с помощью `type()` и проверяем, что он соответствует ожиданиям.

**Пример выполнения:**

```python
name = "Даша"
age = 25
height = 1.68
is_online = True

print("Имя:", name)
print("Возраст:", age)
print("Рост:", height)
print("Жив:", is_online)

age = 26
is_online = False
print("Возраст:", age)
print("Жив:", is_online)

print(type(name))
print(type(age))
print(type(height))
print(type(is_online))
```

Во время практики часто встречаются одни и те же ошибки:

- Если забыть кавычки у строки, Python решит, что это имя переменной, и выдаст ошибку `NameError`.
- Если записать рост через запятую (`1,68`), получится не число, а два разных значения.
- Если в имени переменной поставить пробел или начать его с цифры, программа не запустится.
- Если перепутать регистр (`Name` вместо `name`), Python не найдёт переменную.

## Итоги

- Программа – это список команд для компьютера, а язык программирования – правила, по которым он их понимает.
- Python – простой интерпретируемый язык, которым пользуются в вебе, анализе данных и машинном обучении.
- Программы хранятся в файлах `.py`, а блоки кода выделяются отступами.
- Переменная хранит значение, создаётся присваиванием, и её значение можно менять.
- Основные типы данных: `int`, `float`, `str` и `bool`. Тип значения показывает функция `type()`.
