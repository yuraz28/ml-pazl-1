Теория · Блок 1

Зачем нужны функции

Код короче

Повторяющийся кусок записан один раз, а не скопирован пять раз.

Понятнее

По имени сразу видно, что делает эта часть программы.

Правки в одном месте

Поменяли размер — обновилось везде, где функция вызывается.

Готовыми функциями пользуемся с четвёртого занятия: print(), input(), int(), len(). Теперь пишем свои.

Теория · Блок 1

Функция вместо копий

def draw_box():    for _ in range(5):        print('*' * 7)draw_box()print()draw_box()
Прямоугольники одинаковые, а код написан один раз — внутри функции. Понадобится другой размер — правим только строки 2 и 3.

Теория · Блок 2

Объявление и вызов

Функцию создают словом def: дальше имя, круглые скобки и двоеточие.

Тело функции пишут с отступом в 4 пробела — как блок у if.

Объявление функцию не запускает. Нужен вызов: имя и скобки.

Пока вызова нет, внутри функции не выполнится ни одна строка.

Теория · Блок 2

Имя функции и её вызовы

def say_hello():
    print('Привет!')
    print('Как дела?')

say_hello()      # первый вызов
say_hello()      # второй вызов

Имя функции — как имя переменной: латинские буквы, цифры и знак _, регистр важен.

Принято писать маленькими буквами с подчёркиваниями и начинать с глагола: draw_box, show_tasks, add_task.

Функцию объявляют раньше, чем вызывают. Если меню стоит выше функции, Python ответит NameError.

Два вызова — приветствие напечатается дважды. Тело функции выполняется заново каждый раз.

Теория · Блок 3

Параметры и аргументы

Параметры — переменные в скобках при объявлении. Функция получает в них значения.

Аргументы — то, что мы передаём при вызове: draw_box(3, 5).

Аргументы встают в параметры по порядку: первый — в height, второй — в width.

Сколько параметров, столько и аргументов: draw_box(3) даст TypeError.

Теория · Блок 3

Размеры задаёт вызов

def draw_box(height, width):    for _ in range(height):        print('*' * width)draw_box(3, 5)draw_box(2, 10)
Одна функция — два разных прямоугольника. Меняются только аргументы в вызове.

Теория · Блок 4

Что возвращает функция

return отдаёт результат

def square(x):
    return x * x

result = square(5)
print(result)          # 25
print(square(3) + 1)   # 10

print только печатает

def show_sum(a, b):
    print(a + b)       # печатает 5

x = show_sum(2, 3)
print(x)               # None
return сразу завершает работу функции. Если return нет, функция возвращает None — «ничего».

Теория · Блок 5

Локальные переменные

def show_age():    age = 15    print(age)show_age()print(age)
age существует только внутри функции. Снаружи такого имени нет — и программа останавливается с ошибкой.

Теория · Блок 5

Общий список и функция

Список меняется

numbers = []          # глобальный список

def add_number(x):
    numbers.append(x)

add_number(5)
print(numbers)        # [5]

Так список не меняется

numbers = [1, 2]

def clear_numbers():
    numbers = []      # новая локальная

clear_numbers()
print(numbers)        # [1, 2]
Список, созданный вне функций, — глобальный. Функция может его читать, а менять — методами append() и pop(). Так и будет работать список задач.

Теория · Частые ошибки

Частые ошибки

ошибка 1

Скобки забыли

show_tasks без скобок — это просто имя. Ничего не вызовется.

ошибка 2

Функция ниже вызова

Вызвали раньше, чем объявили, — получите NameError.

ошибка 3

Забыли аргумент

add_task() без текста — TypeError: не хватает одного аргумента.

ошибка 4

tasks = [] внутри функции

Появится новая локальная переменная, а общий список не изменится.

ошибка 5

Номер и индекс

Задачи считаем с 1, элементы списка с 0 — внутри функций пишем number - 1.

Сообщение об ошибке называет строку. Читаем её и правим ровно это место.

Практика · Задача 1

Условие задания

Задание

Создадим программу для списка дел. Она умеет добавлять задачу, показывать все задачи, отмечать задачу выполненной и удалять её по номеру. Каждое действие оформим отдельной функцией, а выбирать действие будем через меню. Список задач будет храниться в переменной tasks.

Что на вход

Список задач tasks — сначала он пустой, а задачи в него добавляет функция.

Что на выход

Нумерованный список задач — каждая на своей строке. Если задач нет, печатается «Список пуст».

Тесты
добавили две задачи→Задача добавлена, 1 - Сделать уроки, 2 - Купить хлеб
список пуст — ничего не добавляли→Список пуст

Практика · Задача 1

add_task(text)

tasks = []

def add_task(text):
    tasks.append(text)
    print('Задача добавлена')

show_tasks()

def show_tasks():
    if len(tasks) == 0:
        print('Список пуст')
    else:
        for i in range(len(tasks)):
            print(i + 1, '-', tasks[i])
Задачи — обычные строки. show_tasks() печатает номер i + 1: детям и взрослым привычнее считать с единицы.

def complete_task(number):
    if 1 <= number <= len(tasks):
        tasks[number - 1] += ' (выполнено)'
        print('Задача отмечена')
    else:
        print('Нет задачи с таким номером')

remove_task(number)

def remove_task(number):
    if 1 <= number <= len(tasks):
        tasks.pop(number - 1)
        print('Задача удалена')
    else:
        print('Нет задачи с таким номером')
Пользователь считает задачи с 1, а в списке они лежат с 0: поэтому внутри функций пишем number - 1. Сначала проверяем, что задача есть.

Итоги

Что изучили

Функция — именованный блок кода: пишем один раз, вызываем сколько нужно.
Функцию объявляют словом def, вызывают по имени и со скобками. Объявление само код не запускает.
Параметры — переменные в объявлении, аргументы — значения при вызове; они встают по порядку.
return отдаёт результат и сразу завершает функцию. Без return функция возвращает None.
Переменные внутри функции локальные, снаружи их не видно. Общий список меняем методами append() и pop().
В программе «Список задач» каждая операция — своя функция, а меню на while True выбирает, какую вызвать.
