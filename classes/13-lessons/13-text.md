# Занятие 13. Функции

## Цель занятия

Понять, зачем нужны функции, научиться создавать и вызывать их, передавать в них параметры и получать результат с помощью `return`. Применить это на практике: создать консольную программу «Список задач» с четырьмя функциями и меню.

---

## Теория

### Зачем нужны функции

**Функция** – это отдельная часть программы, которая выполняет определённую задачу. Её описывают один раз, а затем вызывают по имени в любом месте программы столько раз, сколько нужно. Мы уже пользовались готовыми функциями: `print()`, `input()`, `len()`, `int()`. Теперь научимся писать свои.

Допустим, нужно вывести три звёздных прямоугольника. Копировать цикл три раза неудобно: код разрастается, а если размер изменится, править придётся в трёх местах. Функция решает обе проблемы:

```python
def draw_box():
    for _ in range(5):
        print('*' * 7)

draw_box()
print()
draw_box()
```

- Код становится **короче**: повторяющаяся часть записана один раз.
- Код легче **читать**: по имени функции понятно, что она делает.
- **Изменения** вносятся в одном месте, а не во всех копиях.

---

### Создание и вызов функции

Функцию создают (объявляют) с помощью слова `def`. Дальше идут имя функции, круглые скобки и двоеточие. Строки тела функции пишут с отступом в 4 пробела. Чтобы функция выполнилась, её нужно **вызвать**: написать имя и скобки.

```python
def say_hello():
    print('Привет!')
    print('Как дела?')

say_hello()      # вызов функции
say_hello()      # можно вызывать много раз
```

Объявление функции её не запускает. Пока вы не написали `say_hello()` со скобками, ничего не произойдёт. Функцию нужно объявить раньше, чем вызвать, иначе будет ошибка `NameError`.

Имя функции подчиняется тем же правилам, что и имя переменной: латинские буквы, цифры и знак `_`, без цифры в начале, регистр важен. Принято писать маленькими буквами с подчёркиваниями и начинать с глагола: `draw_box`, `show_tasks`, `add_task`.

---

### Параметры и аргументы

Чтобы функция была гибкой, ей передают данные. В скобках при объявлении перечисляют **параметры** – это переменные, которые получают значения при вызове. А значения, которые мы передаём при вызове, называются **аргументами**.

```python
def draw_box(height, width):     # height, width - параметры
    for _ in range(height):
        print('*' * width)

draw_box(3, 5)                  # 3 и 5 - аргументы
draw_box(2, 10)
```

Первый вызов выведет 3 строки по 5 звёздочек, второй – 2 строки по 10. Аргументы подставляются в параметры по порядку: первый в `height`, второй в `width`. Сколько параметров, столько аргументов нужно передать, иначе будет ошибка `TypeError`.

---

### Что возвращает функция

Функция может не только что-то делать, но и **вернуть результат**. Для этого служит слово `return`. Значение после `return` отправляется в то место программы, откуда функцию вызвали, и его можно сохранить в переменную или использовать в выражении.

```python
def square(x):
    return x * x

result = square(5)
print(result)          # 25
print(square(3) + 1)   # 10
```

Инструкция `return` сразу завершает работу функции. Если `return` нет, функция возвращает специальное значение `None` («ничего»). Поэтому `print` внутри функции и `return` – не одно и то же: `print` только выводит на экран, а `return` отдаёт значение программе.

```python
def show_sum(a, b):
    print(a + b)       # только выводит
x = show_sum(2, 3)     # выведет 5
print(x)               # None
```

Функции удобно использовать для проверок: они возвращают `True` или `False`.

```python
def is_even(n):
    return n % 2 == 0

if is_even(4):
    print('Чётное')     # выведется
```

### Локальные и глобальные переменные

Переменные, созданные внутри функции (и её параметры), – **локальные**: они существуют только во время работы функции, а снаружи их не видно.

```python
def show_age():
    age = 15
    print(age)

show_age()             # 15
print(age)             # NameError: age не существует снаружи
```

Переменная, созданная вне функций, называется **глобальной**. Функция может её читать, а списки – ещё и изменять методами `append()`, `pop()` и т.д. Так мы и будем работать со списком задач.

```python
numbers = []            # глобальный список

def add_number(x):
    numbers.append(x)

add_number(5)
print(numbers)         # [5]
```

Если внутри функции написать `numbers = [1, 2]`, то создастся новая локальная переменная, а внешний список не изменится. Чтобы изменить внешний список, используйте его методы.

## Практика

### Задача. Программа «Список задач»

Создадим программу для списка дел. Она умеет добавлять задачу, показывать все задачи, отмечать задачу выполненной и удалять её по номеру. Каждое действие оформим отдельной функцией, а выбирать действие будем через меню. Список задач будет храниться в переменной `tasks`.

Все заготовки у нас уже есть: список, цикл `while`, условия `if/elif` и функции. Осталось собрать программу по шагам. Задачи хранятся как строки: в начале стоит метка `[ ]` (не выполнена) или `[x]` (выполнена).

#### Шаг 1. Список и функции add_task() и show_tasks()

```python
tasks = []

def add_task(text):
    tasks.append(text)
    print('Задача добавлена')

def show_tasks():
    if len(tasks) == 0:
        print('Список пуст')
    else:
        for i in range(len(tasks)):
            print(i + 1, '-', tasks[i])
```

Функция `add_task` получает текст задачи (параметр `text`) и добавляет её в конец списка. Функция `show_tasks` выводит задачи с номерами, начиная с 1: привычнее видеть номер `i + 1`, чем индекс `i`. Проверим:

```python
add_task('Сделать уроки')
add_task('Купить хлеб')
show_tasks()

# 1 [ ] Сделать уроки
# 2 [ ] Купить хлеб
```

#### Шаг 2. Функции complete_task() и remove_task()

```python
def complete_task(number):
    if 1 <= number <= len(tasks):
        tasks[number - 1] = tasks[number - 1] + ' (выполнено)'
        print('Задача отмечена')
    else:
        print('Нет задачи с таким номером')

def remove_task(number):
    if 1 <= number <= len(tasks):
        tasks.pop(number - 1)
        print('Задача удалена')
    else:
        print('Нет задачи с таким номером')
```

Пользователь называет номер задачи, как он видит его на экране (с 1). В списке эта задача лежит под индексом на 1 меньше, поэтому пишем `number - 1`. Сначала проверяем, что такая задача вообще есть: номер должен быть от 1 до `len(tasks)`. Иначе сообщаем об ошибке. Метод `pop(индекс)` удаляет элемент списка по индексу.

Проверьте функции, добавив вызовы (после проверки лишние строки можно удалить):

```python
print(complete_task(1))    # True
print(remove_task(5))      # False, такой задачи нет
show_tasks()               # 1 [x] Сделать уроки, 2 [ ] Купить хлеб
```

#### Шаг 3. Меню на while True

Программа должна работать, пока пользователь не выберет выход. Сколько раз это будет, заранее неизвестно, поэтому берём `while True`, а когда введён «0», выходим из цикла оператором `break`. Этот код пишем после функций.

```python
while True:
    print()
    print('1 - Добавить задачу')
    print('2 - Показать задачи')
    print('3 - Отметить выполненной')
    print('4 - Удалить задачу')
    print('0 - Выход')
    choice = input('Выберите действие: ')

    if choice == '1':
        text = input('Введите задачу: ')
        add_task(text)
    elif choice == '2':
        show_tasks()
    elif choice == '3':
        number = int(input('Номер задачи: '))
        complete_task(number)
    elif choice == '4':
        number = int(input('Номер задачи: '))
        remove_task(number)
    elif choice == '0':
        print('До свидания!')
        break
    else:
        print('Такого пункта нет')
```

Меню похоже на пульт: на каждую кнопку (пункт 1, 2, 3, 4) приходится своя функция. Программа спрашивает пункт, а условия `if/elif` выбирают, какую функцию вызвать. Сами действия спрятаны внутри функций, поэтому меню короткое и понятное.

Во время практики часто встречаются одни и те же ошибки.

- Если написать `show_tasks` без скобок, функция не вызовется и ничего не произойдёт. Вызов всегда пишется со скобками: `show_tasks()`.
- Если вызвать функцию раньше, чем она объявлена (например, меню стоит выше `def`), возникнет ошибка `NameError`.
- Если не передать аргумент (`add_task()`), возникнет ошибка `TypeError`: у функции есть параметр `text`.
- Если внутри функции написать `tasks = []`, создастся новая локальная переменная, а глобальный список не изменится.
- Если путать номер задачи и индекс, будет удалена не та задача. Номер пользователя всегда на 1 больше индекса.

## Итоги

- Функция – именованный блок кода. Она делает программу короче, понятнее и позволяет менять код в одном месте.
- Функцию объявляют с помощью `def`, а вызывают по имени со скобками. Объявление функции само её не запускает.
- Параметры – переменные в объявлении функции, аргументы — значения, которые передают при вызове.
- Инструкция `return` возвращает результат и завершает функцию. Без `return` функция возвращает `None`.
- Переменные внутри функции локальные. Глобальный список можно изменять методами (`append`, `pop`). Мы создали программу «Список задач» с меню на `while True`.
