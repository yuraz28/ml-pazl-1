Часть 1

Теория

Блок 1

Ветвление

if и else решают, какие строки выполнить. Блок задают двоеточие и отступ в 4 пробела.

Блок 2

Сравнения

Шесть операторов сравнения дают True или False, а сравнения объединяются в цепочки.

Блок 3

Логика

and, or, not соединяют условия. Приоритет: not, затем and, затем or.

Блок 4

Вложенность

Условие внутри условия. Два вложенных if без else — то же самое, что одно условие с and.

Блок 5

Каскад

if — elif — else выбирает один вариант из многих: сработает первая истинная ветка.

Теория · Ветвление

Программа выбирает путь

age = int(input('Сколько вам лет? '))if age >= 18:    print('Доступ разрешён')    print('Добро пожаловать!')
Раньше код выполнялся строго сверху вниз. Ветвление — это проверка условия и выбор: выполнить блок или пропустить его.

Теория · Ветвление

Блок задают отступы

Двоеточие в конце строки с if говорит Python: дальше идёт блок команд.

В блок входят все строки с отступом под if — до первой строки без отступа.

PEP 8 советует отступ в 4 пробела. VS Code ставит их сам после двоеточия и Enter.

Строка без отступа уже вне блока. Она выполнится в любом случае.

Теория · Ветвление

if-else: два пути

age = int(input('Сколько вам лет? '))if age >= 18:    print('Доступ разрешён')else:    print('Доступ запрещён')
else описывает, что делать, когда условие ложно. Выполняется всегда ровно одна из двух веток.

Теория · Сравнения

Шесть операторов сравнения

больше

>

x > 7

меньше

<

x < 7

больше либо равно

>=

x >= 7

меньше либо равно

<=

x <= 7

равно

==

x == 7

не равно

!=

x != 7

Условие строится из этих знаков, а результатом сравнения всегда будет True или False.

Теория · Сравнения

= присваивает, == сравнивает

price = int(input())if price == 500:    print('Ровно 500')
Один знак = кладёт значение в переменную, два знака == задают вопрос «равно?». Путаница между ними — одна из самых частых ошибок. Строки сравниваются с учётом регистра: 'Да' и 'да' — разные значения.

Теория · Сравнения

Цепочки сравнений

age = int(input())if 3 <= age <= 6:    print('Дошкольник')
Сравнения объединяются в цепочку, как в математике: 1 <= x <= 10. С цепочкой != так не получится: a != b != c не значит, что все числа различны (проверьте на 1, 2 и 1).

Теория · Логика

Логические операторы

and

«И»: истина, только если истинны оба условия.

amount >= 1000 and card == 'да'

or

«Или»: истина, если истинно хотя бы одно условие.

day == 6 or day == 7

not

«Не»: меняет True на False и наоборот.

not (amount < 1000)
Эти два условия равносильны: not (amount < 1000) и amount >= 1000. not берут, когда проще сформулировать противоположное.

Теория · Логика

Таблицы истинности

and

True and TrueTrue
True and FalseFalse
False and TrueFalse
False and FalseFalse

or

True or TrueTrue
True or FalseTrue
False or TrueTrue
False or FalseFalse
not True → False not False → True

Теория · Логика

Приоритет и скобки

сначала not потом and в последнюю очередь or скобки меняют порядок 
print(True or False and False)print((True or False) and False)
Одинаковые строки дают разный результат: True or False and False — это True, а (True or False) and False — False. Скобки читаются первыми.

Теория · Логика

Укороченная схема

print(5 > 100 and 10 > 0)print(10 > 0 or 5 > 100)
Так защищаются от ошибок: b != 0 and a // b > 2 — деление выполнится, только если делитель не ноль.

Теория · Вложенные условия

Четверти на координатной плоскости

Номер четверти задают знаки x и y.
Программа сначала смотрит на x, а внутри ветки — на y. Точка (5; 3) лежит в первой четверти, (−2; 4) — во второй, (1; −3) — в четвёртой.

Теория · Вложенность

Вложенные условия

x = int(input())y = int(input())if x > 0:    if y > 0:        print('Первая четверть')    else:        print('Четвёртая четверть')else:    if y > 0:        print('Вторая четверть')    else:        print('Третья четверть')

Теория · Вложенность

Вложенные if или and?

amount = int(input())card = input()if amount >= 1000:    if card == 'да':        print('Скидка 10%')    else:        print('Скидка 5%')else:    print('Скидки нет')# то же самое через and:if amount >= 1000 and card == 'да':    print('Скидка 10%')
Два вложенных if без ветки else у внешнего условия — это одно условие с and. На двух уровнях код читается в любом виде; когда вложений становится больше, берут каскад.

Теория · Каскад

Каскад if-elif-else

hour = int(input('Который час (0-23)? '))if hour < 6:    print('Ночь')elif hour < 12:    print('Утро')elif hour < 18:    print('День')else:    print('Вечер')
Условия проверяются сверху вниз: срабатывает первая истинная ветка, остальную часть каскада Python пропускает. if, elif и else выравниваются по одному уровню, а заключительный else необязателен.

Теория · Каскад

Отметка по 100-балльной шкале

grade = int(input('Введите отметку по 100-балльной системе: '))if grade >= 90:    print(5)elif grade >= 80:    print(4)elif grade >= 70:    print(3)elif grade >= 60:    print(2)else:    print(1)

Теория · Каскад

Светофор

Сигнал — это значение переменной

Выберите чип — загорится лампа, а программа напечатает, что делать.
signal = input('Введите сигнал светофора: ')if signal == 'красный':    print('Стой!')elif signal == 'жёлтый':    print('Приготовься...')elif signal == 'зелёный':    print('Иди!')
Тут блока else нет. Если ни одно условие не подошло, программа просто ничего не выведет и продолжит работу без ошибок.

Часть 2

Практика

задача 1

Калькулятор скидок

Скидка по сумме покупки, по выходным и по карте клиента. Печатаем процент скидки и цену к оплате.

доп. задание

Среда и проверка дня

Скидка 2% по средам и сообщение об ошибке, если введён день вне диапазона 1–7.

Работаем в VS Code: файл lesson6.py.

Практика · Задача 1

Условие задания

Что на вход

Три значения: сумма покупки в рублях, день недели числом от 1 до 7 и ответ про карту — да или нет.

Что на выход

Две строки: сколько процентов скидки набралось и сколько рублей осталось заплатить.

Тесты
6000 · сб · карта→Скидка: 20%, К оплате: 4800 руб.
3000 · ср · без карты→Скидка: 5%, К оплате: 2850 руб.
800 · вс · карта→Скидка: 5%, К оплате: 760 руб.

Практика · Задача 1 · Шаг 1

Считаем данные с экрана

input() всегда отдаёт строку, поэтому сумму и день превращаем в числа через int(). Ответ про карту оставляем строкой — её будем сравнивать с 'да'.
amount = int(input('Введите сумму покупки в рублях: '))day = int(input('Введите день недели (1-7): '))card = input('Есть карта? (да/нет): ')

Практика · Задача 1 · Шаг 2

Скидка по сумме покупки

Подходит ровно один вариант из трёх — значит каскад if — elif — else. Условия идут от большей суммы к меньшей, иначе порядок сломает логику.
amount = int(input('Введите сумму покупки в рублях: '))if amount >= 5000:    discount = 10elif amount >= 1000:    discount = 5else:    discount = 0

Практика · Задача 1 · Шаг 3

День недели и карта

Выходные ловит or: день равен 6 или 7. Скидка по карте работает, только если выполнены оба условия — карта есть и сумма не меньше 1000, поэтому and. Запись discount += 5 увеличивает скидку на 5.
if day == 6 or day == 7:    discount += 5if card == 'да' and amount >= 1000:    discount += 5

Практика · Задача 1 · Шаг 4

Считаем цену

Скидка — целые проценты, поэтому amount * discount // 100 даёт целые рубли без остатка. Цену считаем от первоначальной суммы покупки.
price = amount - amount * discount // 100print(f'Скидка: {discount}%')print(f'К оплате: {price} руб.')

Практика · Дополнительное задание

Условие задания

Что на вход

День недели числом. Первое задание добавляет скидку 2% по средам, второе проверяет, что день лежит в диапазоне от 1 до 7.

Что на выход

Базовая скидка за день — 5% (среда и выходные), для среды она растёт ещё на 2%, а для дня вне диапазона вместо расчёта печатается предупреждение Такого дня нет.

Тесты
среда · 3→скидка за день была 5%, стала 7%
суббота · 6→скидка за день 5%: условие среды ложно
день 9→Такого дня нет

Практика · Доп. задание · Шаг 1

Скидка по средам

Условие короткое, поэтому хватает обычного if без else: если день равен 3, скидка увеличивается на 2.
if day == 3:    discount += 2

Практика · Доп. задание · Шаг 2

Проверка дня недели

Цепочку сравнений 1 <= day <= 7 оборачиваем в not: получаем «день лежит вне диапазона» и печатаем сообщение об ошибке.
if not (1 <= day <= 7):    print('Такого дня нет')

Практика · Дополнительное задание

Полное решение
