# Занятие 7. Условный оператор

## Цель занятия

Изучить условный оператор Python: конструкции `if`, `else` и `elif`, операторы сравнения, логические операторы `and`, `or`, `not` и вложенные условия. Применить их на практике и создать «Калькулятор скидок в магазине», который по сумме покупки, дню недели и наличию карты постоянного клиента рассчитывает скидку и итоговую цену.

## Теория

### Ветвление: условный оператор if-else

До сих пор наши программы выполнялись строго сверху вниз: ввод, вычисления, вывод. Теперь научимся управлять ходом выполнения. Для этого программа проверяет **условие**, которое может быть истинным (`True`) или ложным (`False`), и в зависимости от результата выбирает, какие действия выполнить. Такая проверка и выбор пути называются **ветвлением**.

```python
age = int(input('Сколько вам лет? '))
if age >= 18:
    print('Доступ разрешён')
    print('Добро пожаловать!')
```

Двоеточие в конце строки с `if` сообщает Python, что дальше идёт **блок команд**. В блок входят все строки с отступом под `if`, вплоть до первой строки без отступа. Если условие истинно, блок выполняется, если ложно – пропускается.

Чтобы задать действия на случай, когда условие ложно, используют ключевое слово `else`:

```python
age = int(input('Сколько вам лет? '))
if age >= 18:
    print('Доступ разрешён')
else:
    print('Доступ запрещён')
```

В Python отступы – важная часть кода: именно они показывают, где блок начинается и где заканчивается. По соглашению **PEP 8** для отступа используют 4 пробела. Среды разработки (например, VS Code) обычно ставят их автоматически после двоеточия и нажатия Enter.

### Операторы сравнения

Условие обычно строится с помощью операторов сравнения. В Python их шесть.

- `>` – больше: `x > 7`.
- `<` – меньше: `x < 7`.
- `>=` – больше либо равно: `x >= 7`.
- `<=` – меньше либо равно: `x <= 7`.
- `==` – равно: `x == 7`.
- `!=` – не равно: `x != 7`.

Знак `=` присваивает значение переменной, а знак `==` проверяет равенство. Путаница между ними – одна из самых распространённых ошибок в программировании.

```python
price = 500         # присваивание
if price == 500:    # сравнение
    print('Ровно 500')
```

Сравнивать можно не только числа, но и строки: `if card == 'да'`. Строки сравниваются с учётом регистра, поэтому `'Да'` и `'да'` – разные значения.

Операторы сравнения можно объединять в цепочки, например `1 <= x <= 10` или `a == b == c`. Так удобно проверять, что значение попадает в диапазон:

```python
age = int(input())
if 3 <= age <= 6:
    print('Дошкольник')
```

Равенство транзитивно: если `a == b` и `b == c`, то `a == c`. Поэтому цепочка `a == b == c` действительно проверяет, что все три числа равны. Неравенство `!=` так не работает: из `a != b` и `b != c` не следует, что `a != c` (например, 1, 2 и 1). Поэтому условие `a != b != c` не проверяет, что все три числа различны.

### Логические операторы and, or, not

Когда нужно проверить сразу несколько условий, используют логические операторы. Их три.

- `and` – логическое умножение («и»): результат истинен, только если истинны оба условия.
- `or` – логическое сложение («или»): результат истинен, если истинно хотя бы одно условие.
- `not` – логическое отрицание («не»): меняет `True` на `False` и наоборот.

Все возможные комбинации для `and` и `or` (таблицы истинности):

```python
True and True    # True
True and False   # False
False and True   # False
False and False  # False

True or True     # True
True or False    # True
False or True    # True
False or False   # False

not True         # False
not False        # True
```

```python
if amount >= 1000 and card == 'да':
    print('Скидка по карте')
if day == 6 or day == 7:
    print('Сегодня выходной')
```

Оператор `not` применяют, когда удобнее сформулировать противоположное условие. Выражение в скобках после `not` показывает, к чему именно применяется отрицание. Эти два условия равносильны:

```python
if not (amount < 1000):
if amount >= 1000:
```

Логические операторы имеют приоритет, как и арифметические. Сначала выполняется `not`, затем `and`, и в последнюю очередь `or`. Порядок можно изменить скобками.

```python
print(True or False and False)    # True, сначала False and False
print((True or False) and False)  # False, скобки изменили порядок
```

Операторы `and` и `or` вычисляются по **укороченной схеме**: если результат понятен уже по левой части, правая часть не проверяется. В выражении `5 > 100 and 10 > 0` вторая часть не вычисляется, потому что первая ложна и результат точно `False`. В выражении `10 > 0 or 5 > 100` вторая часть тоже не вычисляется, потому что первая истинна и результат точно `True`. Это можно использовать для защиты от ошибок:

```python
if b != 0 and a // b > 2:
    print('Частное больше 2')
```

### Вложенные условия

Внутри блока `if` или `else` можно писать любые инструкции, в том числе другой условный оператор. Получается **вложенное ветвление**. Вложенные блоки сдвигаются ещё на 4 пробела на каждом уровне.

```python
if amount >= 1000:
    if card == 'да':
        print('Скидка 10%')
    else:
        print('Скидка 5%')
else:
    print('Скидки нет')
```

Два вложенных `if` подряд без ветки `else` у внешнего условия – это то же самое, что одно условие с `and`. Например, программа определения координатной четверти точки может быть записана и через вложенные условия, и через `and`:

```python
x = int(input())
y = int(input())

if x > 0:
    if y > 0:
        print('Первая четверть')
    else:
        print('Четвёртая четверть')
else:
    if y > 0:
        print('Вторая четверть')
    else:
        print('Третья четверть')
```

При двух уровнях вложенности программа хорошо читается в любом виде. Но когда уровней становится больше, код быстро превращается в лесенку, которую трудно понять.

---

### Каскадный оператор if-elif-else

Если нужно выбрать один вариант из нескольких, вместо глубокой вложенности используют **каскадный условный оператор**. Его запись:

```python
if условие1:
    блок кода
elif условие2:
    блок кода
elif условие3:
    блок кода
else:
    блок кода
```

Условия проверяются сверху вниз. Как только найдено первое истинное условие, выполняется его блок, а вся остальная часть конструкции пропускается. Если ни одно условие не истинно, выполняется блок `else`. Слова `if`, `elif` и `else` выравниваются по одному уровню, поэтому код короче по ширине и читается проще, чем вложенные `if-else`.

```python
grade = int(input('Введите отметку по 100-балльной системе: '))

if grade >= 90:
    print(5)
elif grade >= 80:
    print(4)
elif grade >= 70:
    print(3)
elif grade >= 60:
    print(2)
else:
    print(1)
```

Заключительный блок `else` необязателен. Если его нет и ни одно условие не подошло, программа просто ничего не выполнит и продолжит работу без ошибок.

```python
signal = input('Введите сигнал светофора: ')
if signal == 'красный':
    print('Стой!')
elif signal == 'жёлтый':
    print('Приготовься...')
elif signal == 'зелёный':
    print('Иди!')
```

## Практика

### Задача 1. Калькулятор скидок в магазине

Создадим программу, которая по сумме покупки, дню недели и наличию карты постоянного клиента считает скидку и итоговую цену. Правила скидок такие:

- **Скидка по сумме покупки:** до 1000 руб. — 0%, от 1000 до 4999 руб. — 5%, от 5000 руб. — 10%.
- В выходные (суббота и воскресенье) добавляется ещё 5%.
- Карта постоянного клиента даёт ещё 5%, но только если сумма покупки не меньше 1000 руб.

Скидку считаем в целых процентах, а цену — в целых рублях с помощью целочисленного деления из прошлого занятия: цена со скидкой равна `amount - amount * discount // 100`. Программу будем строить по шагам.

#### Шаг 1. Скидка по сумме покупки

Вариантов несколько, и подходит ровно один, поэтому используем каскад `if-elif-else`. Условия идут от большей суммы к меньшей.

```python
amount = int(input('Введите сумму покупки в рублях: '))

if amount >= 5000:
    discount = 10
elif amount >= 1000:
    discount = 5
else:
    discount = 0
```

#### Шаг 2. День недели

День недели вводим числом от 1 (понедельник) до 7 (воскресенье). Выходные – это 6 и 7, поэтому нужен оператор `or`. Скидку увеличиваем записью `+=`.

```python
day = int(input('Введите день недели (1-7): '))

if day == 6 or day == 7:
    discount += 5
```

#### Шаг 3. Карта постоянного клиента

Скидка по карте действует, только если выполняются оба условия: карта есть и сумма не меньше 1000. Для этого подходит оператор `and`.

```python
card = input('Есть карта? (да/нет): ')

if card == 'да' and amount >= 1000:
    discount += 5
```

То же самое можно записать вложенными условиями. Результат одинаковый, но запись с `and` короче:

```python
if card == 'да':
    if amount >= 1000:
        discount += 5
```

#### Полная программа

```python
amount = int(input('Введите сумму покупки в рублях: '))
day = int(input('Введите день недели (1-7): '))
card = input('Есть карта? (да/нет): ')

if amount >= 5000:
    discount = 10
elif amount >= 1000:
    discount = 5
else:
    discount = 0

if day == 6 or day == 7:
    discount += 5
if card == 'да' and amount >= 1000:
    discount += 5

price = amount - amount * discount // 100

print(f'Скидка: {discount}%')
print(f'К оплате: {price} руб.')
```

Проверим программу на нескольких наборах данных.

- 6000 руб., суббота (6), карта есть: 10% + 5% + 5% = 20%. К оплате 4800 руб.
- 3000 руб., среда (3), карты нет: скидка 5%. К оплате 2850 руб.
- 800 руб., воскресенье (7), карта есть: по сумме скидки нет, за выходной 5%, а по карте скидки нет, так как сумма меньше 1000. К оплате 760 руб.

**Дополнительное задание:** добавьте скидку 2% по средам (`day == 3`). Затем сделайте так, чтобы при вводе дня недели не от 1 до 7 программа выводила сообщение об ошибке (подсказка: оператор `not` и цепочка сравнений).

## Итоги

- Условный оператор `if-else` позволяет программе выбирать, какие действия выполнять. Блок кода задаётся двоеточием и отступом в 4 пробела.
- Операторы сравнения `> < >= <= == !=` дают результат `True` или `False`. Знак `=` присваивает, а `==` сравнивает. Сравнения можно объединять в цепочки, например `1 <= x <= 10`.
- Логические операторы `and`, `or`, `not` объединяют условия. Приоритет: сначала `not`, затем `and`, затем `or`; порядок меняют скобками. `and` и `or` вычисляются по укороченной схеме.
- Вложенные условия удобны при небольшой глубине, а для выбора из нескольких вариантов лучше использовать каскад `if-elif-else`. Порядок условий в каскаде важен, а блок `else` необязателен.
- В калькуляторе скидок мы объединили эти конструкции с целочисленной арифметикой: программа считает скидку по сумме, дню недели и карте клиента.
