# Занятие 10. Цикл while

## Цель занятия

Изучить синтаксис цикла `while` и понять, чем он отличается от `for`. Узнать, почему бесконечный цикл опасен, и научиться использовать операторы `break` и `continue`. Применить цикл `while` в задачах: сумма вводимых чисел до стоп-слова и игра «Угадай число».

---

## Теория

### Цикл while: повторяем, пока условие истинно

Слово `while` по-английски означает «пока». Цикл `while` повторяет тело цикла до тех пор, пока условие остаётся истинным. Запись похожа на `if`, но тело `if` выполняется один раз, а тело `while` – многократно.

```python
while условие:
    тело цикла
```

```python
i = 0
while i < 5:
    print('Привет')
    i += 1
```

Как и в `for`, после условия ставится двоеточие, а тело цикла выделяется отступом. Но есть два важных отличия: переменную `i` мы создаём сами (начальное значение), и сами же меняем её внутри цикла. В `for` это делалось автоматически.

Условие проверяется **до** выполнения тела. Поэтому, если условие ложно с самого начала, тело цикла не выполнится ни разу:

```python
i = -1
while i > 0:
    print('Привет')    # не выполнится ни разу
```

---

### Чем while отличается от for

Цикл `for` подходит, когда число повторений известно заранее. Цикл `while` нужен, когда заранее неизвестно, сколько повторений понадобится: цикл работает до наступления события. Например, программа должна считывать числа и выводить их квадраты, пока не введено число `-1`. Сколько чисел будет введено, мы не знаем, поэтому `for` здесь не подходит.

```python
num = int(input())
while num != -1:
    print('Квадрат:', num * num)
    num = int(input())
```

В этом примере важны два момента: переменная `num` получает начальное значение до цикла, и в теле цикла она изменяется (считывается следующее число). Тогда рано или поздно условие станет ложным и цикл завершится.

---

### Бесконечный цикл

Если внутри цикла ничто не делает условие ложным, цикл никогда не закончится. Такой цикл называется **бесконечным**. Обычно это ошибка: программа «зависает» и не реагирует, пока её не прервут.

```python
i = 0
while i < 10:
    print(i)      # забыли i += 1: цикл бесконечный
```

Остановить зависшую программу можно сочетанием клавиш **Ctrl + C** или кнопкой остановки в среде программирования. Если такая программа отправлена в проверяющую систему, вы увидите сообщение **Time limit exceeded** (превышен лимит времени).

---

### Операторы break и continue

Оператор `break` немедленно прерывает ближайший цикл, после чего выполняется код, следующий за циклом. Оператор `continue` пропускает остаток тела цикла и переходит к следующей итерации.

Часто `break` используют вместе с «намеренно бесконечным» циклом `while True`. Условие `True` всегда истинно, а выход из цикла делается внутри тела:

```python
while True:
    text = input()
    if text == 'stop':
        break
    print('Вы ввели:', text)
```

Оператор `continue` удобен, когда нужно пропустить отдельные значения. Например, выведем числа от 1 до 10, кроме кратных 3:

```python
for i in range(1, 11):
    if i % 3 == 0:
        continue
    print(i, end=' ')     # 1 2 4 5 7 8 10
```

В цикле `while` с `continue` нужно быть осторожным: изменение переменной должно стоять **до** `continue`. Иначе для пропускаемых значений переменная не изменится, и цикл станет бесконечным.

```python
i = 0
while i < 10:
    i += 1               # изменяем до continue
    if i % 2 == 0:
        continue
    print(i)             # 1 3 5 7 9
```

## Практика

### Задача 1. Сумма чисел до стоп-слова

Пользователь вводит числа по одному. Когда он вводит слово `stop`, нужно вывести сумму введённых чисел.

**Идея решения:** количество чисел заранее неизвестно, поэтому нужен `while`. Условием служит проверка `text != 'stop'`. Сначала считываем первое значение, а в конце тела цикла – следующее. Число мы преобразуем в `int` только внутри цикла, потому что слово `stop` в число превратить нельзя.

```python
text = input('Введите число или stop: ')
total = 0

while text != 'stop':
    total += int(text)
    text = input('Введите число или stop: ')

print('Сумма чисел равна', total)
```

Для ввода 5, 10, 3, stop значение `total` меняется так: 5, 15, 18. Программа выведет: `Сумма чисел равна 18`.

То же самое можно записать с `while True` и `break`. Так удобно, когда не хочется дважды писать `input()`:

```python
total = 0

while True:
    text = input('Введите число или stop: ')
    if text == 'stop':
        break
    total += int(text)

print('Сумма чисел равна', total)
```

**Дополнительное задание:** пусть программа игнорирует отрицательные числа (подсказка: `continue`).

### Задача 2. Игра «Угадай число»

Компьютер загадывает число от 1 до 100, а игрок пытается его угадать. После каждой попытки программа подсказывает, больше или меньше загаданное число. Сколько попыток понадобится, заранее неизвестно, поэтому используем `while`.

**Решение**

```python
secret = 42
guess = int(input('Угадайте число от 1 до 100: '))

while guess != secret:
    if guess < secret:
        print('Загаданное число больше')
    else:
        print('Загаданное число меньше')
    guess = int(input('Попробуйте ещё раз: '))

print('Вы угадали!')
```

Цикл работает, пока введённое число не равно загаданному. Внутри цикла мы даём подсказку с помощью `if-else` и считываем новую попытку. Когда игрок угадает, условие станет ложным и цикл закончится.

**Дополнительное задание:** если игрок ввёл число не из диапазона 1–100, сообщите об этом и не засчитывайте попытку. Подсказка: добавьте перед `attempts += 1` условие с `or` и оператор `continue`.

```python
    if guess < 1 or guess > 100:
        print('Число должно быть от 1 до 100')
        continue
```

Во время практики часто встречаются одни и те же ошибки.

- Если забыть изменить переменную в теле цикла (например, не считать новое число), цикл станет бесконечным. Остановить программу можно клавишами **Ctrl + C**.
- Если поставить `i += 1` после `continue`, для пропускаемых значений переменная не изменится, и цикл зациклится.
- Если преобразовать введённое значение в `int` до проверки на `'stop'`, программа завершится с ошибкой `ValueError`: слово `stop` числом не является.
- Если написать `=` вместо `==` в условии, Python выдаст ошибку. Помните: `=` присваивает, `==` сравнивает.

## Итоги

- Цикл `while` повторяет тело, пока условие истинно. Условие проверяется до выполнения тела, поэтому цикл может не выполниться ни разу.
- Цикл `for` нужен, когда число повторений известно заранее, а `while` — когда неизвестно. В `while` начальное значение и его изменение нужно писать самому.
- Если внутри цикла условие не становится ложным, цикл получается бесконечным, и программа зависает. Остановить её можно клавишами **Ctrl + C**.
- `break` прерывает ближайший цикл, а `continue` переходит к следующей итерации. Вместе с `while True` они удобны для выхода по условию внутри тела цикла.
- Мы написали программу для суммы чисел до стоп-слова и игру «Угадай число» с подсказками и счётчиком попыток.
