Сегодня новых тем нет – только сборка. Это нормальный этап: умение соединять знакомые части в работающую программу ценится выше, чем знание редких конструкций.

### Из чего состоит любое приложение

Почти всякая программа с данными устроена одинаково:

1. **Загрузить данные** из файла (JSON – занятие 24).
2. **Показать меню** и спросить, что делать (цикл `while True`, `if/elif` – занятия 10, 7).
3. **Выполнить действие**: добавить, показать, найти, изменить. Каждое действие – отдельная функция (занятие 13).
4. **Сохранить данные** обратно в файл, чтобы изменения не потерялись.

Так устроены заметки в телефоне, список книг, трекер привычек. Разница только в том, какие поля хранятся.

### Данные: список словарей

Одна книга – это словарь (занятие 21):

```python
{'title': 'Дюна', 'author': 'Герберт', 'year': 1965, 'read': False}
```

Библиотека – список таких словарей. Файл `library.json` содержит массив верхнего уровня:

```json
[
  {"title": "Дюна", "author": "Герберт", "year": 1965, "read": false}
]
```

Поле `read` – логическое значение, а не строка: `True`/`False` в Python, `true`/`false` в JSON. Сравнивать его надо с `if book['read']:`, а не с `'True'`.

## Практика

### Задача. Программа «Библиотека»

Приложение хранит список книг между запусками: можно добавить книгу, посмотреть все, найти по названию или автору, отметить прочитанной и посмотреть статистику.

#### Шаг 1. Файл данных и загрузка

В папке занятия создайте `library.json` с содержимым `[]` (пустой список). Программа – `lesson25.py`.

```python
import json

FILE = 'library.json'


def load_books():
    with open(FILE, 'r', encoding='utf-8') as f:
        return json.load(f)


def save_books(books):
    with open(FILE, 'w', encoding='utf-8') as f:
        json.dump(books, f, ensure_ascii=False, indent=2)
```

Имя файла вынесено в константу `FILE`: если понадобится поменять, правим в одном месте, а не в трёх.

Функция `save_books` каждый раз перезаписывает файл целиком. Для библиотеки из сотни книг это мгновенно, а код получается простым: не нужно думать, что именно изменилось.

#### Шаг 2. Добавление книги

```python
def add_book(books):
    title = input('Название: ')
    author = input('Автор: ')
    year = int(input('Год: '))
    books.append({'title': title, 'author': author, 'year': year, 'read': False})
    save_books(books)
    print('Книга добавлена')
```

Словарь собирается сразу с четырьмя полями. Новая книга по умолчанию не прочитана – `read: False`. Сохраняем сразу после изменения: если программа закроется аварийно, данные уже на диске.

#### Шаг 3. Показ списка

```python
def show_books(books):
    if len(books) == 0:
        print('Библиотека пуста')
        return
    for i in range(len(books)):
        book = books[i]
        mark = '[x]' if book['read'] else '[ ]'
        print(i + 1, mark, book['author'], '-', book['title'], '(' + str(book['year']) + ')')
```

`return` без значения выходит из функции, если показывать нечего. Метка `[x]`/`[ ]` – знакомая запись из «Списка задач» (занятие 13).

Нумерация с единицы: пользователь видит `i + 1`, а в списке книга лежит под индексом `i`. Это же соответствие понадобится в шаге 5.

#### Шаг 4. Поиск

```python
def find_book(books):
    text = input('Что искать? ').lower()
    found = 0
    for book in books:
        if text in book['title'].lower() or text in book['author'].lower():
            mark = '[x]' if book['read'] else '[ ]'
            print(mark, book['author'], '-', book['title'])
            found += 1
    if found == 0:
        print('Ничего не найдено')
```

Поиск идёт по двум полям сразу, поэтому в условии `or`. `lower()` нужен, чтобы «дюна» находила «Дюну». Счётчик `found` отличает «ничего не нашлось» от «нашлось, но поиск отработал».

#### Шаг 5. Отметка «прочитано»

```python
def mark_read(books):
    number = int(input('Номер книги: '))
    if 1 <= number <= len(books):
        books[number - 1]['read'] = True
        save_books(books)
        print('Отмечено')
    else:
        print('Нет книги с таким номером')
```

Здесь сразу три приёма из курса: проверка номера двойным сравнением (занятие 7), пересчёт «номер → индекс» (13) и обращение к полю словаря внутри списка (19, 21).

#### Шаг 6. Статистика

```python
def show_stats(books):
    read = 0
    for book in books:
        if book['read']:
            read += 1
    print('Всего книг:', len(books))
    print('Прочитано:', read)
```

`if book['read']:` короче, чем `if book['read'] == True:`. Значение уже логическое, сравнивать его с `True` не нужно.

Дополнительно: выведите процент прочитанного – `round(read / len(books) * 100, 1)`. Не забудьте про пустую библиотеку: делить на ноль нельзя, нужна проверка.

#### Шаг 7. Меню

```python
books = load_books()

while True:
    print()
    print('1 - Добавить книгу')
    print('2 - Показать все')
    print('3 - Найти книгу')
    print('4 - Отметить прочитанной')
    print('5 - Статистика')
    print('0 - Выход')
    choice = input('Выберите действие: ')

    if choice == '1':
        add_book(books)
    elif choice == '2':
        show_books(books)
    elif choice == '3':
        find_book(books)
    elif choice == '4':
        mark_read(books)
    elif choice == '5':
        show_stats(books)
    elif choice == '0':
        save_books(books)
        print('До свидания!')
        break
    else:
        print('Такого пункта нет')
```

Сравнение `choice == '1'` идёт со строкой, потому что `input` возвращает строку. Числа не нужны: пунктов немного, а строковое сравнение не требует `int()` и не падает, если ввели букву.

Проверка работы:

1. Запустите, добавьте две книги, выйдите через `0`.
2. Запустите снова и выберите «2 – Показать все». Книги на месте – значит, сохранение работает.
3. Отметьте одну прочитанной, перезапустите, проверьте, что метка `[x]` осталась.

#### Шаг 8. Доработки на выбор

- Удаление книги по номеру (`pop`, занятие 12).
- Сортировка по автору или году перед показом (`sort`).
- Поиск по году: «книги, изданные после 2000».
- Поле «оценка» от 1 до 5 и вывод средней оценки прочитанных.
- Список «хочу прочитать» отдельно от прочитанных – второй файл JSON.

### Разбор типичных ошибок

Собрали программу – самое время посмотреть, на чём обычно ломаются. Почти все эти ошибки встречались в домашках.

- **Забыл `int()` или `str()`.** `input` даёт строку, `write` принимает только строку. `'5' + 1` – `TypeError`, `'5' + '1'` – `'51'`.
- **`KeyError`.** Обращение к несуществующему ключу словаря. Проверка `in` или `get()` решает проблему.
- **`IndexError`.** Индекс за границей списка: например, пользователь ввёл номер 7, а книг три. Нужна проверка `1 <= number <= len(books)`.
- **`None` вместо результата.** Функция считает, но забыли `return` – снаружи получаем `None` и непонятную ошибку где-то дальше.
- **Путаница номера и индекса.** Пользователь считает с 1, список – с 0. Пересчёт `number - 1`.
- **Данные не сохранились.** Изменили список, но не вызвали `save_books` – после перезапуска всё как было.
- **Стёрли файл режимом `'w'`.** Перед записью полезно один раз прочитать, что там лежало.
- **`JSONDecodeError`.** В `library.json` сломанная разметка после ручной правки. Проще исправить в редакторе, чем в коде.
- **`UnicodeDecodeError`.** Забыли `encoding='utf-8'` при открытии файла.
- **Отступы.** Python определяет блоки по отступам: лишний пробел перед `else` или строка не в том блоке – `IndentationError` или логика работает не так, как задумано.
- **Функция объявлена после вызова.** Меню стоит выше `def` – `NameError`.
- **Бесконечный цикл.** Забыли `break` в пункте выхода или условие `while` никогда не становится ложным.

Отдельно про отладку: если программа ведёт себя странно, ставьте `print()` в подозрительном месте и смотрите, какие значения туда доходят. Это быстрее, чем читать код глазами.
