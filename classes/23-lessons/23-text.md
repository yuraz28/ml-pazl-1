# Занятие 23. Модуль csv

## Цель занятия

Научиться читать и записывать таблицы в формате CSV – самом распространённом формате табличных данных. Разобрать, чем `csv` удобнее ручного разбора строки через `split`, и почему в CSV все значения приходят строками. Посчитать статистику по таблице оценок и сохранить результат обратно в CSV.

## Теория

### Что такое CSV

**CSV** – *comma separated values*, «значения, разделённые запятой». Это обычный текстовый файл, где каждая строка – одна запись, а поля внутри строки разделены запятой:

```
ученик,математика,русский,информатика
Аня,5,4,5
Марк,4,4,3
```

Первая строка почти всегда – **заголовки**: названия столбцов. Дальше идут данные.

Такие файлы умеет открывать любой Excel, Google Таблицы, LibreOffice. Выгрузка оценок из электронного журнала, список товаров, статистика по городу – всё это обычно CSV.

### Зачем модуль, если есть split

Первая мысль: прочитать файл (занятие 22) и разбить строку через `split(',')`. Для простой таблицы это сработает. Проблемы начинаются, когда:

- внутри значения встречается запятая – например, адрес «Москва, ул. Ленина, 5». CSV оборачивает такое поле в кавычки, а `split` этого не понимает;
- в конце строки стоит перевод строки `\n`, и последнее поле получается с лишним символом;
- файл сохранён Windows-программой с `\r\n` на конце строк.

Модуль `csv` из стандартной библиотеки решает это сам. Подключается как любой другой модуль:

```python
import csv
```

`import` подключает готовый набор функций. В стандартной библиотеке Python их очень много: `csv`, `json` (следующее занятие), `random`, `math`. Ставить ничего не нужно – они идут вместе с Python. Установка сторонних библиотек будет на занятии 27.

### Чтение таблицы

```python
import csv

with open('marks.csv', 'r', newline='', encoding='utf-8') as f:
    rows = list(csv.reader(f))

print(rows)
# [['ученик', 'математика', 'русский', 'информатика'],
#  ['Аня', '5', '4', '5'], ['Марк', '4', '4', '3'], ...]
```

`csv.reader(f)` – это «читалка»: она отдаёт по одному списку на каждую строку файла. `list(...)` собирает все строки в список списков – та самая вложенная структура из занятия 19.

Три детали, которые надо соблюдать всегда:

- **`newline=''`** при открытии. Без него на Windows и macOS может появиться лишняя пустая строка между записями, потому что Python и `csv` по-своему обрабатывают переводы строк.
- **`encoding='utf-8'`** – как и в обычных файлах, иначе русские заголовки превратятся в мусор.
- **Все значения – строки.** Даже оценки: `'5'`, а не `5`. CSV не хранит типы, он хранит текст.

### Преобразование значений

Раз всё строки, числа придётся превращать явно – знакомым `int()` (занятие 8):

```python
row = ['Аня', '5', '4', '5']
print(row[0])              # Аня
print(row[1] + row[2])     # 54 - склеились строки!
print(int(row[1]) + int(row[2]))   # 9 - сложились числа
```

Это самая частая ошибка при работе с CSV: `'5' + '4'` даёт `'54'`, а не `9`. И `sum(row[1:])` выдаст `TypeError`, потому что `sum` не умеет складывать строки.

### Запись таблицы

```python
import csv

with open('result.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['ученик', 'средний балл'])
    writer.writerow(['Аня', 4.67])
```

`writerow(список)` записывает одну строку, сам расставляя запятые и кавычки там, где нужно. `newline=''` обязателен и здесь, иначе между строками появятся пустые.

Метод `writerows(список_строк)` записывает сразу много строк. Режим `'a'` – чтобы не стереть то, что уже лежит в файле:

```python
with open('result.csv', 'a', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerows([['Аня', 4.67], ['Марк', 3.67]])
```

Режимы `'w'` и `'a'` работают так же, как у текстовых файлов: `'w'` перезаписывает файл, `'a'` дописывает в конец.

### Разделитель: запятая или точка с запятой

Русская версия Excel часто сохраняет CSV не с запятой, а с **точкой с запятой** – потому что запятая в русской локали используется как десятичный разделитель.

```
ученик;математика;русский
Аня;5;4
```

Пусть такой файл из Excel лежит рядом как `marks_excel.csv`. При чтении обычным `csv.reader` он придёт одной колонкой. Разделитель указывают параметром `delimiter`:

```python
with open('marks_excel.csv', 'r', newline='', encoding='utf-8') as f:
    rows = list(csv.reader(f, delimiter=';'))
```

Если таблица разобралась неправильно – первым делом посмотрите файл в текстовом редакторе (в VS Code) и проверьте, чем разделены поля.

### Связь со следующим занятием

CSV – плоская таблица: строки и столбцы, без вложенности. Если данные сложнее (ученик, у которого оценки по предметам, а у каждого предмета ещё и дата), CSV становится неудобным. Для таких случаев есть JSON – о нём на занятии 24.

## Практика

### Задача. Статистика по таблице оценок

Есть таблица оценок класса. Нужно посчитать средний балл каждого ученика, найти лучшего и вывести средние баллы по предметам. Результат сохранить в новый CSV.

#### Шаг 1. Создать таблицу

В папке занятия создайте файл `marks.csv`:

```
ученик,математика,русский,информатика
Аня,5,4,5
Марк,4,4,3
Лиза,5,5,5
Тимур,3,4,3
```

Программа – `lesson23.py` в той же папке.

#### Шаг 2. Прочитать таблицу

```python
import csv

with open('marks.csv', 'r', newline='', encoding='utf-8') as f:
    rows = list(csv.reader(f))

header = rows[0]
students = rows[1:]

print('Предметы:', header[1:])
print('Учеников:', len(students))
```

Заголовок отделяем от данных срезом `rows[1:]`. Дальше работаем только со `students`, иначе первая строка попадёт в расчёты и `int('математика')` выдаст ошибку.

Ожидаемый вывод:

```
Предметы: ['математика', 'русский', 'информатика']
Учеников: 4
```

#### Шаг 3. Средний балл каждого ученика

```python
averages = []
for row in students:
    name = row[0]
    marks = row[1:]
    total = 0
    for mark in marks:
        total += int(mark)
    average = total / len(marks)
    averages.append((average, name))
    print(name, '- средний балл', round(average, 2))
```

`round(число, 2)` округляет до двух знаков после запятой – встроенная функция, работает как `len`.

Пары собираем в список кортежей «средний балл, имя» (занятие 20) – это заодно подготовит сортировку на следующем шаге.

#### Шаг 4. Лучший ученик

```python
averages.sort(reverse=True)
print('Лучший средний балл:', averages[0][1], '-', round(averages[0][0], 2))
```

Сортировка кортежей идёт по первому элементу, то есть по среднему баллу. `reverse=True` – по убыванию, значит первый в списке и есть лучший. `averages[0][1]` – имя лучшего, `averages[0][0]` – его балл.

Дополнительно: найдите ученика с самым низким баллом – это последний элемент списка.

#### Шаг 5. Средние по предметам

Здесь идём не по строкам, а по столбцам. Заголовок подсказывает, в каком столбце что лежит: `header[i]` – название, `row[i]` – оценка.

```python
for i in range(1, len(header)):
    subject = header[i]
    total = 0
    for row in students:
        total += int(row[i])
    print(subject, '- средний по классу', round(total / len(students), 2))
```

Ожидаемый вывод:

```
математика - средний по классу 4.25
русский - средний по классу 4.25
информатика - средний по классу 4.0
```

#### Шаг 6. Сохранить результат в CSV

```python
with open('marks_report.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['ученик', 'средний балл'])
    for average, name in averages:
        writer.writerow([name, round(average, 2)])

print('Отчёт сохранён в marks_report.csv')
```

Проверьте файл: откройте его в VS Code и в Excel. Обратите внимание, что в списке `averages` порядок уже по убыванию балла – отчёт получится с рейтингом, а не в исходном порядке.

#### Шаг 7. Доработки на выбор

- Добавить в отчёт столбец «лучший предмет» для каждого ученика.
- Прочитать таблицу с разделителем `;` – сохраните копию через Excel как «CSV (разделители – точка с запятой)».
- Посчитать, сколько в классе пятёрок, четвёрок и троек (словарь из занятия 21).
- Добавить нового ученика в конец файла: открыть на запись в режиме `'a'` и дописать строку.
- Сделать так, чтобы имя файла спрашивалось через `input()`.

### Частые ошибки

- `int('ученик')` – в расчёт попала строка заголовка. Данные берутся срезом `rows[1:]`.
- `'5' + '4'` вместо `int('5') + int('4')` – получается `'54'`. В CSV всё строки.
- Забыли `newline=''` – в файле появились пустые строки между записями.
- Таблица разобралась в одну колонку – не тот разделитель. Нужен `delimiter=';'` (или наоборот запятая).
- `KeyError`/`IndexError` при `row[i]` – в строке меньше полей, чем в заголовке (лишняя запятая или пустое поле в файле).
- `round(total / 0)` – деление на `len(students)`, когда список пуст (например, в файле только заголовок).
- Открыли CSV в Excel, сохранили – и разделители поехали. Данные правят в VS Code или проверяют настройки импорта в Excel.

## Итоги

- CSV – текстовый формат таблиц: строка файла = запись, поля разделены запятой, первая строка обычно заголовки.
- Модуль `csv` подключается через `import csv`, читает через `csv.reader(f)` и пишет через `csv.writer(f)` и `writerow()`.
- При открытии файла нужны `newline=''` и `encoding='utf-8'`; для русского Excel часто дополнительно `delimiter=';'`.
- Все значения из CSV приходят строками: числа преобразуют через `int()` или `float()`.
- Читая таблицу, держите отдельно заголовок и данные: `header = rows[0]`, `students = rows[1:]`.
- По строкам считают характеристики учеников, по столбцам (`row[i]` для всех строк) – характеристики предметов.
