Теория · Целые числа

Число и строка рядом

num1 = 7num2 = 10num3 = num1 + num2print(num3)s = '7'
Число пишут без кавычек, строку — в кавычках. Слово int — от английского integer, «целый».

Теория · Целые числа

Размер числа не ограничен

другие языки

C#: от -2⁶³ до 2⁶³ - 1

Там целое число жёстко ограничено диапазоном значений.

Python

длинная арифметика

Ограничений практически нет: 2 ** 100 вычисляется без проблем.

Переменную целого типа создаёт значение, записанное без кавычек: num1 = 7.

Теория · Операции

Семь знаков арифметики

сложение

7 + 3

даёт 10

вычитание

7 - 3

даёт 4

умножение

7 * 3

даёт 21

деление

7 / 2

даёт 3.5

целочисленное деление

7 // 2

даёт 3 — дробная часть отброшена

остаток от деления

7 % 2

даёт 1, потому что 7 = 2 * 3 + 1

возведение в степень

2 ** 3

даёт 8

Обычное деление / всегда даёт дробное число: даже 8 / 2 выводится как 4.0.

Теория · Операции

Проверяем на числах

print(7 + 3)print(7 / 2)print(7 // 2)print(7 % 2)print(2 ** 3)
// и % смотрят на одно и то же деление с двух сторон: 2 целиком помещается в 7 три раза, и ещё 1 остаётся.

Теория · Операции

Минус в двух ролях

унарный минус

num1 = -6

Стоит перед одним числом и делает его отрицательным.

бинарный минус

num2 = 17 - 7

Стоит между двумя числами и выполняет вычитание.

деление на ноль

5 / 0

Программа остановится с ошибкой ZeroDivisionError.

Остальные знаки — +, *, /, //, %, ** — всегда стоят между двумя значениями. Для отрицательных // округляет вниз: -7 // 2 даёт -4. На этом занятии считаем положительные числа.

Теория · Порядок действий

Порядок как в математике

print(2 + 3 * 4)print(10 - 4 - 3)print(100 / 10 * 2)print(2 + 3 * 4 ** 2)print((2 + 3) * 4)
Сначала возведение в степень, потом умножение, деление, // и %, в конце сложение и вычитание. Операции одного приоритета идут слева направо.

Теория · Порядок действий

Скобки и короткая запись

забыли скобки

a + b / 2

Это a плюс половина b, а не среднее. Частая ошибка новичков.

среднее арифметическое

(a + b) / 2

Скобки вычисляются первыми и меняют порядок действий.

короче на пять знаков

x += 5

Это то же самое, что x = x + 5. Так же работают -=, *=, //=, %=.

num1 = 2 + 3 * 4 → 14 num2 = (2 + 3) * 4 → 20 скобки ставят и для понятности

Теория · Преобразование типов

int() и str()

s = '1992'year = int(s)print(year)num = 17text = str(num)
int() означает: возьми то, что в скобках, и преврати в целое число. str() делает обратное — из числа получается строка.

Теория · Преобразование типов

Почему input() нужен int()

num1 = input()num2 = input()print(num1 + num2)print(int(num1) + int(num2))
input() всегда возвращает строку. Одно целое число читают так: num = int(input()).

Теория · Деление и остаток

Зачем нужны // и %

чётность

n % 2

У чётных остаток 0, у нечётных 1. Остаток 0 от деления на любое число значит, что делится нацело.

разряды числа

n % 10 и n // 10

Остаток от деления на 10 — последняя цифра, деление на 10 убирает её.

величины по кругу

(20 + 30) % 24

Часы, дни недели, минуты ходят по кругу: получится 2 часа ночи.

разбиение на части

// и %

// показывает, сколько полных групп получится, % — что останется.

При делении a на b: // говорит, сколько раз b целиком помещается в a, а % — что осталось.

Теория · Деление и остаток

Достаём цифры числа

n = 4172print(n % 10)print(n // 10)print(n // 10 % 10)print(n // 100 % 10)print(n // 1000)
// отбрасывает цифры справа, % оставляет последнюю. Так из числа достают любой разряд.

Теория · Деление и остаток

Чётность и часы

print(4172 % 2)print(7 % 2)print((20 + 30) % 24)
Остаток от деления на 2 — самый простой способ проверить чётность.

Практика · Частые ошибки

На чём спотыкаются

ошибка 1

Забыли int()

Вместо сложения получится склейка: '3' + '4' даёт '34'.

ошибка 2

Перепутали / и //

Вместо целого числа выйдет дробное. В этих задачах нужен //.

ошибка 3

Забыли скобки

Порядок действий окажется другим, чем задумано.

ошибка 4

Делитель равен нулю

Программа остановится с ошибкой ZeroDivisionError.

Первые три ошибки видны сразу по результату: он просто не тот, что ожидали.

Считаем секунды с экрана

total = int(input('Введите количество секунд: '))

Практика · Задача 2 · Шаг 2

Считаем целые часы

В одном часе 3600 секунд. Целых часов ровно столько, сколько раз 3600 помещается в total.
hours = total // 3600

Практика · Задача 2 · Шаг 3

Минуты и секунды из остатка

Остаток после часов — это минуты и секунды. Целые минуты даёт total % 3600 // 60, а что меньше минуты — total % 60.
minutes = total % 3600 // 60seconds = total % 60

print(f'{hours:02}:{minutes:02}:{seconds:02}')
