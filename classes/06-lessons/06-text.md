# Занятие 6. Целочисленная арифметика

## Цель занятия

Изучить работу с целыми числами и преобразование строк в числа, арифметические операции Python, порядок вычислений и роль скобок. Понять, для чего нужны целочисленное деление и остаток от деления, и решить с их помощью практические задачи.

---

## Теория

### Целые числа и строки

До сих пор мы в основном работали со строками: команда `input()` считывает именно текст. Но для вычислений нужны числа. Чтобы создать в Python переменную целого типа (`int`), нужно записать значение без кавычек.

```python
num1 = 7            # число
num2 = 10           # число
num3 = num1 + num2  # число
print(num3)         # 17
s = '7'             # строка, а не число
```

Слово `int` происходит от английского **integer** – «целый». Во многих языках программирования целые числа ограничены диапазоном значений (например, в C# это от −2⁶³ до 2⁶³ − 1). В Python реализована **длинная арифметика**, поэтому целое число практически не имеет ограничений: `2 ** 100` вычисляется без проблем.

---

### Арифметические операции

Python умеет выполнять все привычные арифметические действия. Для них используются специальные знаки, которые называются **операторами**.

- `+` – сложение: `7 + 3` даёт `10`.
- `-` – вычитание: `7 - 3` даёт `4`.
- `*` – умножение: `7 * 3` даёт `21`.
- `/` – деление: `7 / 2` даёт `3.5`. Результат обычного деления всегда дробное число (`float`), даже если деление выполнилось без остатка: `8 / 2` даёт `4.0`.
- `//` – целочисленное деление: `7 // 2` даёт `3`. Оно отбрасывает дробную часть и оставляет только целое число.
- `%` – остаток от деления: `7 % 2` даёт `1`, потому что `7 = 2 * 3 + 1`.
- `**` – возведение в степень: `2 ** 3` даёт `8`.

```python
print(7 + 3)   # 10
print(7 / 2)   # 3.5
print(7 // 2)  # 3
print(7 % 2)   # 1
print(2 ** 3)  # 8
```

Знак `-` используется в двух разных ролях. **Унарный минус** стоит перед одним числом и делает его отрицательным: `num1 = -6`. **Бинарный минус** стоит между двумя числами и выполняет вычитание: `num2 = 17 - 7`. Остальные знаки операций (`+`, `*`, `/`, `//`, `%`, `**`) всегда стоят между двумя значениями.

Делить на ноль нельзя. Если написать `5 / 0`, `5 // 0` или `5 % 0`, программа остановится с ошибкой `ZeroDivisionError`.

Для отрицательных чисел целочисленное деление округляет результат вниз. Например, `-7 // 2` даёт `-4`, а не `-3`. На этом занятии мы работаем с положительными числами.

---

### Порядок вычислений и скобки

В Python действует тот же порядок действий, что и в математике. Сначала выполняется возведение в степень, затем умножение, деление, целочисленное деление и остаток, и в последнюю очередь сложение и вычитание. Операции с одинаковым приоритетом выполняются слева направо.

```python
print(2 + 3 * 4)       # 14
print(10 - 4 - 3)      # 3
print(100 / 10 * 2)    # 20.0
print(2 + 3 * 4 ** 2)  # 50
```

Чтобы изменить порядок действий, используют круглые скобки. Выражение в скобках вычисляется первым.

```python
print((2 + 3) * 4)     # 20
```

Скобки полезны и тогда, когда порядок можно не менять, но хочется сделать выражение понятнее. Частая ошибка новичков – забыть скобки при вычислении среднего: `a + b / 2` считает не среднее арифметическое, а `a` плюс половину `b`. Правильно писать `(a + b) / 2`.

Результат вычисления обычно записывают в переменную: `<имя переменной> = <математическая формула>`. Например, `num1 = 2 + 3 * 4` сохранит в переменной `num1` число `14`, а `num2 = (2 + 3) * 4` – число `20`.

Если нужно изменить значение переменной на основе её текущего значения, используют сокращённую запись. Вместо `x = x + 5` можно написать `x += 5`. Так же работают `-=`, `*=`, `//=`, `%=` и другие.

---

### Преобразование типов

Команда `input()` всегда возвращает строку, поэтому перед вычислениями её нужно преобразовать в число. Для этого используется функция `int()`. Она означает: «возьми то, что указано в скобках, и преврати это в целое число».

```python
s = '1992'
year = int(s)
print(year)  # 1992
```

Здесь переменная `s` имеет строковый тип, а `year` – целочисленный. Если преобразование не выполнить, Python будет считать введённые значения текстом и просто склеит их:

```python
num1 = input()
num2 = input()
print(num1 + num2)  # для 3 и 4 выведет 34, а не 7
```

Правильный вариант:

```python
num1 = int(input())
num2 = int(input())
print(num1 + num2)  # для 3 и 4 выведет 7
```

Чтобы считать одно целое число, пишут `num = int(input())`.

Обратное преобразование, из целого числа в строку, выполняет функция `str()`.

```python
num = 17
s = str(num)  # в переменной s теперь строка '17'
```

Переменная `num` по-прежнему имеет целочисленный тип, а `s` – строковый.

### Целочисленное деление и остаток: зачем они нужны

Операции `//` и `%` могут показаться необычными, но на практике они нужны очень часто. При делении `a` на `b` результат `//` показывает, сколько раз `b` целиком помещается в `a`, а результат `%` показывает, что осталось.

- **Чётность числа.** Остаток от деления на 2 у чётных чисел равен 0, а у нечётных равен 1. Поэтому `n % 2` позволяет определить чётность. Остаток от деления на любое число показывает, делится ли `n` на него нацело: если остаток равен 0, то делится.
- **Разряды числа.** Остаток от деления на 10 – это последняя цифра числа, а целочисленное деление на 10 отбрасывает последнюю цифру.

```python
n = 4172
print(n % 10)         # 2, последняя цифра
print(n // 10)        # 417, число без последней цифры
print(n // 10 % 10)   # 7, предпоследняя цифра
print(n // 100 % 10)  # 1, третья цифра с конца
print(n // 1000)      # 4, первая цифра
```

- **Циклические величины.** Остаток помогает считать величины, которые «ходят по кругу»: часы, дни недели, минуты. Например, если сейчас 20 часов, то через 30 часов на часах будет `(20 + 30) % 24`, то есть 2 часа ночи.
- **Разбиение на части.** Целочисленное деление показывает, сколько полных групп получится, а остаток показывает, что останется. Так решаются задачи про купюры и монеты, про перевод секунд в часы и минуты и другие.

## Практика: решаем задачи

### Задача 1. Разбить сумму на купюры и монеты

Пользователь вводит сумму в рублях. Нужно вывести, сколько купюр и монет каждого номинала потребуется, чтобы выдать эту сумму. Используем номиналы 1000, 500, 100, 50, 10 и 1.

**Идея решения:** сначала узнаём, сколько купюр по 1000 помещается в сумму. Это целочисленное деление. Затем оставляем только то, что осталось, то есть остаток от деления, и повторяем те же действия для следующего номинала.

```python
amount = int(input('Введите сумму в рублях: '))

n1000 = amount // 1000
amount = amount % 1000
n500 = amount // 500
amount = amount % 500
n100 = amount // 100
amount = amount % 100
n50 = amount // 50
amount = amount % 50
n10 = amount // 10
n1 = amount % 10

print(f'1000 руб.: {n1000}')
print(f'500 руб.: {n500}')
print(f'100 руб.: {n100}')
print(f'50 руб.: {n50}')
print(f'10 руб.: {n10}')
print(f'1 руб.: {n1}')
```

Для суммы 1787 программа выведет: одна купюра 1000, одна купюра 500, две купюры по 100, одна купюра 50, три монеты по 10 и семь монет по 1.

### Задача 2. Перевести секунды в формат чч:мм:сс

Пользователь вводит количество секунд. Нужно вывести это время в часах, минутах и секундах.

**Идея решения:** в часе 3600 секунд, поэтому часы находим целочисленным делением на 3600. Остаток от этого деления – секунды, которые не вошли в полные часы. Из них таким же образом получаем минуты (делим на 60) и оставшиеся секунды (остаток от деления на 60).

```python
total = int(input('Введите количество секунд: '))

hours = total // 3600
minutes = total % 3600 // 60
seconds = total % 60

print(f'{hours:02}:{minutes:02}:{seconds:02}')
```

Запись `:02` в f-строке означает, что число выводится минимум двумя цифрами, а недостающие заполняются нулём. Для 4000 секунд программа выведет `01:06:40`.

### Задача 3. Определить последнюю цифру числа

Пользователь вводит натуральное число. Нужно вывести его последнюю цифру.

**Идея решения:** остаток от деления на 10 и есть последняя цифра числа.

```python
n = int(input('Введите число: '))
last = n % 10
print(f'Последняя цифра числа {n}: {last}')
```

**Дополнительное задание:** пользователь вводит трёхзначное число. Нужно вывести его цифры по отдельности и их сумму. Например, для числа 574 это цифры 5, 7, 4 и сумма 16. Сотни можно получить как `n // 100`, десятки как `n // 10 % 10`, единицы как `n % 10`.

Во время практики часто встречаются одни и те же ошибки:

- Если не преобразовать введённое значение в `int`, вместо сложения чисел получится склейка строк (`'3' + '4'` даёт `'34'`), а остальные операции вызовут ошибку, потому что `input()` возвращает строку.
- Если перепутать `/` и `//`, вместо целого числа получится дробное. Для нашего типа задач нужен именно `//`.
- Если забыть скобки в выражении, порядок действий окажется другим, чем задумано.
- Если делитель оказался равен нулю, программа остановится с ошибкой `ZeroDivisionError`.

## Итоги

- Целые числа (`int`) записываются без кавычек, строки – с кавычками; размер целого числа в Python не ограничен.
- В Python есть операции `+ - * / // % **`, а результат обычного деления `/` всегда дробное число.
- Порядок вычислений такой же, как в математике, а скобки позволяют его изменить.
- Функция `int()` преобразует строку в целое число, а `str()` — целое число в строку; для чтения числа используют `int(input())`.
- Целочисленное деление `//` показывает, сколько раз число помещается целиком, а остаток `%` показывает, что осталось.
- Остаток и целочисленное деление помогают определять чётность, находить цифры числа, разбивать величины на части и считать циклические значения.
