Теория · Строки

Строка — это цепочка символов

Нумерация начинается с нуля: у «ПАЗЛ» номера 0, 1, 2, 3. Тот же символ можно взять с конца — тогда он называется −1, −2, −3, −4.

Теория · Длина

Сколько символов в строке

word = input('Введите слово: ')print('Букв в слове:', len(word))
len() возвращает число — сколько символов внутри строки. Пробел, точка и запятая тоже считаются за символ.

Теория · Индексы

Символ по номеру

word = input('Введите слово: ')print(word[0])print(word[2])print(word[-1])
Номер пишут в квадратных скобках. word[0] — первый символ, word[-1] — всегда последний, сколько бы букв ни было в слове.

Теория · Срезы

Срез: кусок строки

word = input('Введите слово: ')print(word[1:4])print(word[:3])print(word[3:])
В срезе два номера через двоеточие: с какого начать и до какого дойти. Правый номер в результат не входит. Пустая сторона — значит «от начала» или «до конца».

Теория · Срез наоборот

Срез наоборот

word = input('Введите слово: ')back = word[::-1]print(back)print(back == word)
Третий номер в срезе — шаг. Шаг −1 идёт с конца к началу, поэтому word[::-1] — это то же слово задом наперёд.

Теория · Строка неизменяема

Строку нельзя изменить

word = 'кот'word[0] = 'л'print(word)

Строка неизменяема: подставить символ по номеру нельзя, Python остановит программу.

Вместо этого собирают новую строку: word = word.replace('к', 'л').

Переменная остаётся та же, а строка в ней — уже другая.

Теория · Осторожно

Номер за границей строки

word = 'кот'print(word[3])

В слове «кот» три символа с номерами 0, 1, 2. Номера 3 не существует — программа остановится с ошибкой.

Поэтому и берут word[-1]: он работает для слова любой длины.

А срез за границей ошибки не даёт: word[0:99] спокойно вернёт всё слово.

Теория · Операции

Склеивание и повторение

name = input('Имя: ')surname = input('Фамилия: ')print(name + ' ' + surname)print('-' * 12)
Плюс склеивает строки, звёздочка повторяет: 'да' * 3 — это 'дадада'. Ставить строку рядом с числом без пробела-разделителя нельзя, получится 'ИванПетров'.

Теория · Поиск в строке

Оператор in

word = input('Введите слово: ')print('а' in word)print('ё' in word)
in отвечает True или False: есть ли такая часть внутри строки. Искать можно и целое слово: 'кот' in 'котёнок' — тоже True. Регистр важен: 'Аня' и 'аня' — разные строки.

Теория · Методы

Методы строк

word = input('Введите слово: ')print(word.upper())print(word.count('а'))print(word.replace('а', 'о'))
Метод вызывают через точку: слева строка, справа действие. В скобках — то, что методу нужно для работы. Строка при этом не меняется: метод возвращает новую.

Теория · Методы

Ещё методы

strip

Убирает пробелы по краям — полезно сразу после input().

' Аня '.strip() → 'Аня'

find

Номер, с которого начинается подстрока. Если не нашлось — минус один.

'барабан'.find('раб') → 2

startswith

Проверяет начало строки и отвечает True или False.

'привет'.startswith('при') → True
Все методы возвращают значение, поэтому их пишут либо внутри print(...), либо присваивают переменной: clean = word.strip().

Теория · Строки и числа

Строка или число

age = input('Сколько лет? ')print(age + 1)print(int(age) + 1)

input() всегда возвращает строку, даже если ввели цифры.

Пока не применили int(), в переменной лежит текст, и складывать его с числом нельзя.

А для строки len('123') честно вернёт 3: считаются символы, а не значение числа.

Теория · Сравнения

Как сравниваются строки

print('банан' < 'вишня')print('аня' < 'Аня')

Строки сравниваются по алфавиту: «б» идёт раньше «в», поэтому «банан» меньше.

Заглавные буквы стоят раньше строчных, поэтому 'Аня' < 'аня'.

Значит 'Да' и 'да' — разные строки: в проверках пишите ответ ровно так, как его вводит пользователь.

Практика · Задача 1

Условие задания

Что на вход

Одно слово — его вводит пользователь.

Что на выход

Сколько в слове букв, а ещё первая и последняя буква.

Тесты
Слово: шалаш→Букв: 5, Первая буква: ш, Последняя буква: ш
Слово: кот→Букв: 3, Первая буква: к, Последняя буква: т
Слово: велосипед→Букв: 9, Первая буква: в, Последняя буква: д

Практика · Задача 1 · Шаг 1

Считаем буквы

len(word) даёт количество символов: пробелы и знаки тоже считаются.
word = input('Введите слово: ')print('Букв в слове:', len(word))

Практика · Задача 1 · Шаг 2

Берём буквы по номерам

word[0] — первый символ, word[-1] — последний: минус один всегда означает «с конца».
word = input('Введите слово: ')print('Первая буква:', word[0])print('Последняя буква:', word[-1])

Практика · Задача 1 · Полное решение

Вся программа целиком

Четыре строки: ввод, длина и две буквы. Программа печатает их по порядку — сколько строк, столько и ответов.
word = input('Введите слово: ')print('Букв:', len(word))print('Первая буква:', word[0])print('Последняя буква:', word[-1])

Практика · Задача 2

Условие задания

Что на вход

Одно слово.

Что на выход

То же слово, прочитанное наоборот.

Тесты
Слово: барабан→Наоборот: набараб
Слово: шалаш→Наоборот: шалаш
Слово: кот→Наоборот: ток

Практика · Задача 2 · Шаг 1

Разворачиваем срезом

Срез word[::-1] идёт с конца к началу: получается та же строка задом наперёд.
word = input('Введите слово: ')print(word[-1])print(word[-3:])print(word[::-1])

Практика · Задача 2 · Полное решение

Слово и его перевёртыш

Развёрнутую строку сохраняем в переменную back — её можно напечатать с подписью и сравнить ещё раз.
word = input('Введите слово: ')back = word[::-1]print('Наоборот:', back)

Практика · Задача 3

Условие задания

Что на вход

Одно слово.

Что на выход

Ответ True, если слово читается одинаково в обе стороны, иначе False.

Тесты
Слово: шалаш→Это перевёртыш? True
Слово: барабан→Это перевёртыш? False
Слово: кот→Это перевёртыш? False

Практика · Задача 3 · Шаг 1

Сравниваем две строки

Сравнение строк даёт True или False — это уже готовый ответ программы.
word = input('Введите слово: ')back = word[::-1]print('Это перевёртыш?', back == word)

Практика · Задача 3 · Полное решение

Разбор слова целиком

Знакомая программа: длина, первая и последняя буквы, перевёртыш — и ответ про перевёртыш в последней строке.
word = input('Введите слово: ')print('Букв:', len(word))print('Первая буква:', word[0])print('Последняя буква:', word[-1])print('Наоборот:', word[::-1])print('Это перевёртыш?', word == word[::-1])

Практика · Дополнительное задание

Условие задания

Что на вход

Строка текста — слова разделены пробелами.

Что на выход

Те же слова, но в обратном порядке — одной строкой.

Тесты
Текст: Мама мыла раму→раму мыла Мама
Текст: кот сидел на окне→окне на сидел кот
Текст: привет→привет

Практика · Дополнительное задание · Шаг 1

Разбиваем текст на слова

text.split() режет строку по пробелам и возвращает список слов — работать дальше будем с ним, а не с целым текстом. Печатаем список наглядно: словами через запятую.
text = input('Введите текст: ')words = text.split()print('Слова:', ', '.join(words))

Практика · Дополнительное задание · Шаг 2

Разворачиваем список

Срез [::-1] умеет работать не только с буквами: список слов он тоже разворачивает — последнее слово становится первым.
text = input('Введите текст: ')words = text.split()print('Наоборот:', ', '.join(words[::-1]))

Практика · Дополнительное задание · Полное решение

Собираем строку обратно

' '.join(...) склеивает слова в строку через пробел — ровно тот разделитель, по которому split() её разрезал.
text = input('Введите текст: ')words = text.split()print(' '.join(words[::-1]))

Что изучили

len(word) считает символы, word[0] берёт первый, word[−1] — последний.
Срез word[1:4] вырезает часть строки, а word[::-1] разворачивает её наоборот.
Строку нельзя изменить на месте: правкой занимаются методы, они возвращают новую строку.
Плюс склеивает строки, звёздочка повторяет, оператор in ищет подстроку.
upper, count, replace, strip и find — готовые действия над текстом.
