Применить эти знания в задачах: разворот строки, проверка слова на палиндром и подсчёт слов в тексте.

## Теория

### Индексация строк

Строка – это последовательность символов. К любому символу можно обратиться по **индексу** (номеру) в квадратных скобках. Нумерация начинается с 0. Кроме того, Python позволяет считать с конца: последний символ имеет индекс `-1`.

```python
#  P  y  t  h  o  n
#  0  1  2  3  4  5
# -6 -5 -4 -3 -2 -1

s = 'Python'
print(s[0])     # P
print(s[5])     # n
print(s[-1])    # n, последний символ
print(s[6])     # IndexError
```

Если длина строки равна `len(s)`, то индекс последнего символа равен `len(s) - 1`. Обращение к несуществующему индексу вызывает ошибку `IndexError: string index out of range`.

Строки в Python **неизменяемы**: нельзя заменить символ, присвоив значение `s[0]`. Вместо этого создают новую строку.

```python
s = 'Python'
s[0] = 'J'            # TypeError
s = 'J' + s[1:]       # Jython, новая строка
```

Символы строки можно перебирать циклом `for`: `for ch in s` даёт по очереди каждый символ, а `for i in range(len(s))` – индексы, если они нужны.

---

### Срезы строк

**Срез** позволяет взять не один символ, а целую часть строки. Запись `s[x:y]` означает «от индекса `x` включительно до индекса `y` не включительно». Это похоже на `range()`.

```python
s = 'abcdefghij'
print(s[2:5])     # cde
print(s[:5])      # abcde, первые 5 символов
print(s[5:])      # fghij, начиная с индекса 5
print(s[-2:])     # ij, последние 2 символа
print(s[:])       # abcdefghij, вся строка
print(s[1:7:2])   # bdf, с шагом 2
print(s[::-1])    # jihgfedcba, строка наоборот
```

Третье число в срезе – **шаг**. Если шаг отрицательный, символы идут в обратном порядке. Запись `s[::-1]` – самый короткий способ развернуть строку. Срез никогда не вызывает ошибку выхода за границы: `s[2:100]` просто вернёт всё до конца строки.

---

### Конкатенация и форматирование

Строки можно складывать (**конкатенация**) и умножать на целое число. Но сложить строку с числом нельзя: число сначала нужно превратить в строку с помощью `str()`.

```python
print('Py' + 'thon')          # Python
print('ab' * 3)               # ababab
age = 15
print('Мне ' + str(age))      # Мне 15
```

Собирать строки из нескольких частей удобнее с помощью знакомым нам f-строк.

```python
name = 'Аня'
age = 15
print(f'Меня зовут {name}, мне {age} лет.')
print(f'Через 5 лет мне будет {age + 5}.')
```

### Полезные строковые методы

**Метод** – это функция, которая применяется к объекту. Вызывается он через точку: `строка.метод(параметры)`. Вот самые полезные методы для строк.

- `upper()` и `lower()` – переводят все буквы в верхний или нижний регистр: `'Python'.upper()` даёт `'PYTHON'`. Часто используются, чтобы сравнивать строки без учёта регистра.
- `strip()` – убирает пробелы в начале и в конце строки: `'  привет  '.strip()` даёт `'привет'`.
- `replace(старое, новое)` – заменяет все вхождения одной подстроки на другую: `'a-b-c'.replace('-', ' ')` даёт `'a b c'`. Чтобы удалить символы, заменяют их на пустую строку `''`.
- `split()` – разбивает строку на слова и возвращает список: `'to be or not'.split()` даёт `['to', 'be', 'or', 'not']`. Можно указать разделитель: `'1,2,3'.split(',')`.
- `join()` – собирает строку из списка, вставляя между элементами разделитель: `'-'.join(['1', '2', '3'])` даёт `'1-2-3'`. Разделитель пишут перед точкой.

Методы строк **не изменяют** исходную строку, а возвращают новую. Чтобы сохранить результат, его нужно присвоить переменной.

```python
s = '  Hello  '
s.upper()              # результат потерян, s не изменилась
s = s.strip()          # правильно: сохраняем результат
print(s)               # Hello

word = input().strip().lower()   # методы можно вызывать цепочкой
```

Среди других полезных методов стоит знать `count()` (сколько раз подстрока встречается в строке), `find()` (индекс первого вхождения или -1), `startswith()` и `endswith()` (проверка начала и конца), `isdigit()` (состоит ли строка только из цифр) и `title()` (каждое слово с заглавной буквы).

## Практика

### Задача 1. Разворот строки

Пользователь вводит строку. Нужно вывести её в обратном порядке.

**Идея решения:** используем срез с отрицательным шагом.

```python
s = input('Введите строку: ')
print(s[::-1])
```

Для строки `Python` программа выведет `nohtyP`. Ту же задачу можно решить циклом: каждый новый символ добавляем в начало результата.

```python
s = input('Введите строку: ')
result = ''
for ch in s:
    result = ch + result
print(result)
```

### Задача 2. Палиндром

**Палиндром** – слово или фраза, которые одинаково читаются слева направо и справа налево (например, «топот» или «шалаш»). Нужно проверить, является ли введённое слово палиндромом.

**Идея решения:** слово является палиндромом, если оно равно самому себе, прочитанному наоборот. Развернуть строку мы уже умеем.

```python
word = input('Введите слово: ')

if word == word[::-1]:
    print(f'Слово {word} - палиндром')
else:
    print(f'Слово {word} - не палиндром')
```

Такая программа не считает палиндромом слово «Топот», потому что заглавная `Т` и строчная `т` – разные символы. Исправим это с помощью `lower()`. Заодно научим программу проверять целые фразы: уберём пробелы с помощью `replace()`.

```python
text = input('Введите фразу: ')
clean = text.lower().replace(' ', '')

if clean == clean[::-1]:
    print('Палиндром')
else:
    print('Не палиндром')
```

Фраза «А роза упала на лапу Азора» после обработки превращается в «арозаупаланалапуазора» и оказывается палиндромом.

### Задача 3. Количество слов в тексте

Пользователь вводит текст. Нужно вывести, сколько в нём слов.

**Идея решения:** метод `split()` без аргументов разбивает текст по пробелам и игнорирует лишние пробелы. Количество слов равно длине получившегося списка.

```python
text = input('Введите текст: ')
words = text.split()
print(f'Слов в тексте: {len(words)}')
```

Для текста «Мама мыла   раму» (с несколькими пробелами подряд) программа выведет 3, а для пустой строки – 0. Обратите внимание: `len(text)` считает символы, а `len(words)` – слова.

**Дополнительное задание:** выведите слова текста в обратном порядке. Подсказка: разверните список срезом и соберите строку методом `join()`.

```python
words = text.split()
print(' '.join(words[::-1]))    # раму мыла Мама
```

Во время практики часто встречаются одни и те же ошибки.

- Если обратиться к индексу, которого нет в строке (например, `s[len(s)]`), возникнет ошибка `IndexError`. Последний символ имеет индекс `len(s) - 1` или `-1`.
- Если попытаться изменить символ строки через `s[0] = 'J'`, возникнет ошибка `TypeError`. Строки неизменяемы.
- Если вызвать метод и не присвоить результат (`s.strip()`), строка останется прежней.
- Если забыть букву `f` перед кавычкой, Python выведет фигурные скобки как обычный текст.

## Итоги

- Индекс символа в строке начинается с 0, последний символ имеет индекс `-1`. Строки неизменяемы.
- Срез `s[x:y:step]` возвращает новую строку. Запись `s[::-1]` разворачивает строку.
- Строки можно сцеплять (`+`) и повторять (`*`). Для сборки строки из переменных удобнее f-строки.
- Методы `upper`, `lower`, `strip`, `replace`, `split` и `join` не изменяют строку, а возвращают новую или список.
- Из этих инструментов мы собрали программы: разворот строки, проверка палиндрома и подсчёт слов.
