# Занятие 11. Строки

## Цель занятия

Научиться обращаться к отдельным символам строки по индексу, делать срезы, пользоваться самыми полезными строковыми методами (`upper`, `lower`, `strip`, `replace`, `split`, `join`) и форматировать строки с помощью f-строк. Применить эти знания в задачах: длина и края слова, разворот слова и проверка на перевёртыш.

---

## Теория

### Индексация строк

Строка – это последовательность символов. К любому символу можно обратиться по **индексу** (номеру) в квадратных скобках. Нумерация начинается с 0. Кроме того, Python позволяет считать с конца: последний символ имеет индекс `-1`.

```python
#  P  y  t  h  o  n
#  0  1  2  3  4  5
# -6 -5 -4 -3 -2 -1

s = 'Python'
print(s[0])     # P
print(s[5])     # n
print(s[-1])    # n, последний символ
print(s[6])     # IndexError
```

Если длина строки равна `len(s)`, то индекс последнего символа равен `len(s) - 1`. Обращение к несуществующему индексу вызывает ошибку `IndexError: string index out of range`.

Строки в Python **неизменяемы**: нельзя заменить символ, присвоив значение `s[0]`. Вместо этого создают новую строку.

```python
s = 'Python'
s[0] = 'J'            # TypeError
s = 'J' + s[1:]       # Jython, новая строка
```

Символы строки можно перебирать циклом `for`: `for ch in s` даёт по очереди каждый символ, а `for i in range(len(s))` – индексы, если они нужны.

---

### Срезы строк

**Срез** позволяет взять не один символ, а целую часть строки. Запись `s[x:y]` означает «от индекса `x` включительно до индекса `y` не включительно». Это похоже на `range()`.

```python
s = 'abcdefghij'
print(s[2:5])     # cde
print(s[:5])      # abcde, первые 5 символов
print(s[5:])      # fghij, начиная с индекса 5
print(s[-2:])     # ij, последние 2 символа
print(s[:])       # abcdefghij, вся строка
print(s[1:7:2])   # bdf, с шагом 2
print(s[::-1])    # jihgfedcba, строка наоборот
```

Третье число в срезе – **шаг**. Если шаг отрицательный, символы идут в обратном порядке. Запись `s[::-1]` – самый короткий способ развернуть строку. Срез никогда не вызывает ошибку выхода за границы: `s[2:100]` просто вернёт всё до конца строки.

---

### Конкатенация и форматирование

Строки можно складывать (**конкатенация**) и умножать на целое число. Но сложить строку с числом нельзя: число сначала нужно превратить в строку с помощью `str()`.

```python
print('Py' + 'thon')          # Python
print('ab' * 3)               # ababab
age = 15
print('Мне ' + str(age))      # Мне 15
```

Собирать строки из нескольких частей удобнее с помощью знакомым нам f-строк.

```python
name = 'Аня'
age = 15
print(f'Меня зовут {name}, мне {age} лет.')
print(f'Через 5 лет мне будет {age + 5}.')
```

### Полезные строковые методы

**Метод** – это функция, которая применяется к объекту. Вызывается он через точку: `строка.метод(параметры)`. Вот самые полезные методы для строк.

- `upper()` и `lower()` – переводят все буквы в верхний или нижний регистр: `'Python'.upper()` даёт `'PYTHON'`. Часто используются, чтобы сравнивать строки без учёта регистра.
- `strip()` – убирает пробелы в начале и в конце строки: `'  привет  '.strip()` даёт `'привет'`.
- `replace(старое, новое)` – заменяет все вхождения одной подстроки на другую: `'a-b-c'.replace('-', ' ')` даёт `'a b c'`. Чтобы удалить символы, заменяют их на пустую строку `''`.
- `split()` – разбивает строку на слова и возвращает список: `'to be or not'.split()` даёт `['to', 'be', 'or', 'not']`. Можно указать разделитель: `'1,2,3'.split(',')`.
- `join()` – собирает строку из списка, вставляя между элементами разделитель: `'-'.join(['1', '2', '3'])` даёт `'1-2-3'`. Разделитель пишут перед точкой.

Методы строк **не изменяют** исходную строку, а возвращают новую. Чтобы сохранить результат, его нужно присвоить переменной.

```python
s = '  Hello  '
s.upper()              # результат потерян, s не изменилась
s = s.strip()          # правильно: сохраняем результат
print(s)               # Hello

word = input().strip().lower()   # методы можно вызывать цепочкой
```

Среди других полезных методов стоит знать `count()` (сколько раз подстрока встречается в строке), `find()` (индекс первого вхождения или -1), `startswith()` и `endswith()` (проверка начала и конца), `isdigit()` (состоит ли строка только из цифр) и `title()` (каждое слово с заглавной буквы).

## Практика

Задачи идут друг за другом: каждая следующая добавляет к предыдущей одну новую операцию. Так к концу занятия получается программа, которая разбирает слово целиком.

### Задача 1. Буквы слова

Пользователь вводит одно слово. Нужно вывести, сколько в нём букв, а также первую и последнюю букву.

**Тесты:** `шалаш` → `Букв: 5, Первая буква: ш, Последняя буква: ш`; `кот` → `Букв: 3, Первая буква: к, Последняя буква: т`; `велосипед` → `Букв: 9, Первая буква: в, Последняя буква: д`.

**Идея решения:** длину даёт `len(word)`, первый символ — `word[0]`, последний — `word[-1]`. Минус один всегда означает «с конца», поэтому длину для последней буквы знать не нужно.

```python
word = input('Введите слово: ')
print('Букв:', len(word))
print('Первая буква:', word[0])
print('Последняя буква:', word[-1])
```

Сколько строк с `print`, столько и ответов: программа печатает их по порядку, каждый с новой строки. Пробелы и знаки препинания `len()` тоже считает — он считает символы, а не «буквы» в бытовом смысле.

---

### Задача 2. Слово наоборот

Пользователь вводит слово. Нужно вывести его прочитанным справа налево.

**Тесты:** `барабан` → `Наоборот: набараб`; `шалаш` → `Наоборот: шалаш`; `кот` → `Наоборот: ток`.

**Идея решения:** срез с шагом `-1` идёт с конца к началу и собирает новую строку. Исходная при этом не меняется — строки неизменяемы.

```python
word = input('Введите слово: ')
back = word[::-1]
print('Наоборот:', back)
```

Результат сохраняем в переменную `back`: дальше её можно напечатать с подписью и сравнить. Ту же задачу можно решить циклом — каждый новый символ добавляем в начало результата:

```python
word = input('Введите слово: ')
back = ''
for ch in word:
    back = ch + back
print('Наоборот:', back)
```

Цикл делает то же самое, но длиннее — именно поэтому срез удобнее.

---

### Задача 3. Слово-перевёртыш

Пользователь вводит слово. Нужно ответить `True`, если слово читается одинаково в обе стороны, иначе `False`. Такие слова называют перевёртышами (палиндромами): шалаш, казак, топот.

**Тесты:** `шалаш` → `Это перевёртыш? True`; `барабан` → `Это перевёртыш? False`; `кот` → `Это перевёртыш? False`.

**Идея решения:** сравнить слово с его разворотом. Сравнение строк само даёт `True` или `False` — печатать `if` не нужно, готовый ответ и есть результат сравнения.

```python
word = input('Введите слово: ')
back = word[::-1]
print('Это перевёртыш?', back == word)
```

В конце занятия собираем всё вместе: длина, края слова, разворот и ответ про перевёртыш — пять строк, знакомых по предыдущим задачам.

```python
word = input('Введите слово: ')
print('Букв:', len(word))
print('Первая буква:', word[0])
print('Последняя буква:', word[-1])
print('Наоборот:', word[::-1])
print('Это перевёртыш?', word == word[::-1])
```

Слово «Топот» перевёртышем не считается: заглавная `Т` и строчная `т` — разные символы. Если нужно сравнивать без учёта регистра, приводят строку к нижнему регистру через `lower()`.

### Доп. задание. Слова в обратном порядке

Пользователь вводит текст. Нужно вывести его слова в обратном порядке.

**Идея решения:** `split()` режет текст по пробелам и возвращает список слов, `[::-1]` разворачивает список, `join()` склеивает слова обратно в строку через пробел — ровно тот разделитель, по которому `split()` её разрезал.

```python
text = input('Введите текст: ')
words = text.split()
print(' '.join(words[::-1]))    # Мама мыла раму  →  раму мыла Мама
```

Сначала полезно напечатать промежуточный результат — список слов через запятую: `print(', '.join(words))`. Так видно, что именно разворачивается дальше.

---

### Частые ошибки

- Обращение к индексу, которого нет в строке (`word[len(word)]`), даёт `IndexError`. Последний символ — это `word[-1]` или `word[len(word) - 1]`.
- Попытка изменить символ через `word[0] = 'J'` даёт `TypeError`: строки неизменяемы, любые «правки» — это создание новой строки.
- Если вызвать метод и не присвоить результат (`word.strip()`), строка останется прежней.
- Если забыть букву `f` перед кавычкой, Python напечатает фигурные скобки как обычный текст.
- Строку и число нельзя сложить через `+` — сначала приводят число к строке через `str()`.

---

## Итоги

- Индекс символа в строке начинается с 0, последний символ имеет индекс `-1`. Строки неизменяемы.
- Срез `s[x:y:step]` возвращает новую строку. Запись `s[::-1]` разворачивает строку.
- Строки можно сцеплять (`+`) и повторять (`*`). Для сборки строки из переменных удобнее f-строки.
- Методы `upper`, `lower`, `strip`, `replace`, `split` и `join` не изменяют строку, а возвращают новую строку или список.
- Из этих инструментов мы собрали программы: разбор слова по буквам, разворот слова и проверку на перевёртыш.
