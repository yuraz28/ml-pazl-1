Теория · Что такое список

Список — полка с ячейками

Список хранит несколько значений подряд. Запись — в квадратных скобках, элементы разделяют запятыми.

Нумерация, как у символов строки, начинается с 0. У пяти элементов индексы 0…4.

С конца берут отрицательные номера: −1 — последний элемент, −2 — предпоследний.

Пустой список пишут как [] — с него начинают и наполняют по мере чтения чисел.

Теория · Что такое список

Индекс, −1 и длина

numbers = [2, 4, 6, 8, 10]print(numbers[0])print(numbers[2])print(numbers[-1])print(len(numbers))print(numbers)print(numbers[5])
Запись numbers[i] берёт один элемент. Если указать номер, которого нет, программа остановится с ошибкой IndexError.

Теория · Что такое список

Срез списка и проверка in

Срез берёт кусок списка: границы пишут через двоеточие, правое число в кусок не входит. Оператор in отвечает на вопрос «есть ли такое значение в списке».
numbers = [10, 20, 30, 40, 50]print(numbers[1:4])print(numbers[:3])print(numbers[2:])print(40 in numbers)print(100 in numbers)

Теория · Что такое список

Элемент списка можно заменить

Список — не строка: его элементы можно переписать. Пишем индекс в квадратных скобках и присваиваем новое значение. Индекс −1 — это последний элемент.
numbers = [10, 20, 30]numbers[1] = 99numbers[-1] = 7print(numbers)

Теория · Добавить и удалить

append() и remove()

numbers = []numbers.append(5)numbers.append(7)print(numbers)fruits = ['яблоко', 'банан', 'яблоко']fruits.remove('яблоко')print(fruits)
append() кладёт элемент в конец списка, remove() убирает первое совпадение. Если значения может не быть, сначала проверяют его через in.

Теория · Сортировка

sort(): по возрастанию и убыванию

a = [5, 1, 8, 2, 4]a.sort()print(a)a.sort(reverse=True)print(a)
Метод sort() расставляет элементы по возрастанию. С reverse=True — по убыванию. Строки сортируются по алфавиту.

Теория · Сортировка

Методы меняют список сами

a = [5, 1, 8, 2, 4]a.sort()print(a)a = [5, 1, 8, 2, 4]a = a.sort()print(a)
Запись a = a.sort() теряет список: метод возвращает None. Методы списка просто вызывают — a.sort().

Теория · Перебор

Перебор списка в цикле

numbers = [2, 4, 6]for x in numbers:    print(x * 10)for x in numbers:    print(x, end=' ')print()for i in range(len(numbers)):    print(i, numbers[i])
Переменная цикла x по очереди получает каждый элемент. Нужны номера — перебирают range(len(numbers)) и берут numbers[i].

Теория · Частые ошибки

Частые ошибки

ошибка 1

IndexError

Обратились к numbers[len(numbers)] — такого индекса нет. Последний равен len(numbers) − 1.

numbers[len(numbers)]
ошибка 2

a = a.sort()

Метод вернул None и затёр список. sort() просто вызывают.

a = a.sort() → None
ошибка 3

Максимум с нуля

Если все числа отрицательные, ответом станет 0 — число, которого в списке нет. Начинайте с первого элемента.

maximum = numbers[0]
ошибка 4

Забыли int()

В списке окажутся строки, и сортировка со сравнениями дадут неверный результат.

numbers.append(int(input()))

Практика · Задача 1 · Шаг 1

Считаем числа в список

Сначала спрашиваем, сколько чисел, потом читаем их по одному и складываем в список. Каждый input() превращаем в int(): иначе в списке окажутся строки.
n = int(input('Сколько чисел? '))numbers = []for i in range(n):    numbers.append(int(input('Число: ')))print('Список:', numbers)

Практика · Задача 1 · Шаг 2

Максимум и минимум за один перебор

За первое число принимаем и максимум, и минимум. Дальше идём по списку: если число больше максимума — запоминаем его, если меньше минимума — тоже.
numbers = [4, 9, 2, 7]maximum = numbers[0]minimum = numbers[0]for x in numbers:    if x > maximum:        maximum = x    if x < minimum:        minimum = xprint('Максимум:', maximum)print('Минимум:', minimum)

Практика · Задача 2 · Шаг 2

Сортируем в две стороны

sort() расставляет числа по возрастанию, а sort(reverse=True) — по убыванию. Оба раза список меняется на месте, поэтому печатаем его после каждой сортировки.
numbers = [5, 1, 8, 2, 4]numbers.sort()print('По возрастанию:', numbers)numbers.sort(reverse=True)print('По убыванию:', numbers)

Список хранит несколько значений в квадратных скобках. Нумерация с 0, последний элемент — [-1], длину даёт len().

Срез берёт часть списка, а оператор in проверяет, есть ли значение внутри.
Список перебирают циклом for x in numbers или for i in range(len(numbers)).
