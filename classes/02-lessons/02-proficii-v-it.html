Теория · AI и ML

Как связаны AI, ML и LLM

AI — искусственный интеллект: область, в которой компьютер решает задачи, обычно требующие человеческого мышления.
ML — машинное обучение: часть AI, где разработчик правил не пишет — модель находит закономерности в данных сама.
DL — глубокое обучение: часть ML, нейросети с большим числом слоёв.
LLM — большая языковая модель: нейросеть, обученная на большом объёме текста. Например, GigaChat и YandexGPT.

Теория · Фронтенд

Фронтенд

Фронтенд — часть сервиса, которую видит пользователь: интерфейс, кнопки и формы.
Где работает

В браузере или на устройстве пользователя.

Из чего сделан

HTML — структура страницы, CSS — внешний вид, JavaScript — поведение.

Что видит пользователь

Кнопки, формы, списки и картинки — всё, с чем он взаимодействует.

HTML · CSS

Смотрит, как страница выглядит на разных экранах, и следит за удобством.

JavaScript · React и Vue
Работа фронтенд-разработчика видна сразу: именно её оценивает пользователь, когда открывает сервис.

Теория · Бэкенд

Бэкенд

Что делает бэкенд

Проверяет пароль при входе, считает стоимость заказа, сохраняет и отдаёт данные.

Где он работает

На сервере, которого пользователь не видит. Бэкенд-код пишут на Python, Java и Go, а для данных используют SQL.

Теория · Бэкенд

Что делает бэкенд-разработчик

Проверяет пароль при входе

Сверяет данные пользователя с тем, что хранится в базе.

Считает стоимость заказа

Выполняет логику сервиса: скидки, доставку, оплату.

Сохраняет данные в базу

Например, новый заказ, плейлист или сообщение.

Отдаёт данные по запросу

Например, список треков для плеера или маршрут поездки.

Пользователь бэкенд не видит, но без него сервис не работает: именно там хранятся данные и правила.
