# Занятие 2. Введение в профессию и инструменты

## Цель занятия

Понять, чем занимается разработчик, какие направления и профессии есть в IT, какими инструментами пользуются в работе и как задача проходит путь от идеи до выпуска продукта.

## Теория

### Кто такой разработчик

Разработчик создаёт программы, сайты, приложения и сервисы: превращает требования и идеи в работающий код.

Разработчик получает задачу, пишет код для её решения, проверяет, что код работает, и исправляет найденные ошибки. После выпуска продукта он поддерживает его и добавляет новые функции. По ходу работы решения обсуждаются с командой.

Написание кода — только часть работы. Значительное время занимают чтение чужого кода, обсуждение задач и поиск ошибок.

### Основные направления разработки

| Направление | За что отвечает | Основные технологии |
| --- | --- | --- |
| Фронтенд | Интерфейс: то, что видит и с чем взаимодействует пользователь | HTML, CSS, JavaScript |
| Бэкенд | Серверная часть: логика работы, обработка данных, базы данных | Python, Java, Go, SQL |
| DevOps | Запуск и работа продукта: серверы, автоматизация сборки и выпуска, мониторинг | Linux, Docker, CI/CD |

Другие направления: мобильная разработка, разработка игр, ML и AI.

### Профессии в IT

| Профессия | Чем занимается |
| --- | --- |
| Разработчик (фронтенд, бэкенд, DevOps) | Пишет код продукта: интерфейс, серверную часть, настраивает запуск и работу сервиса |
| Аналитик | Собирает и описывает требования к продукту, анализирует данные |
| Тестировщик (QA) | Проверяет продукт, находит и описывает ошибки |
| Дизайнер (UX/UI) | Проектирует интерфейс и удобство работы с продуктом |
| Менеджер проекта/продукта | Ставит цели, планирует сроки, координирует команду |
| ML-инженер, Data Scientist | Создаёт модели, которые обучаются на данных |

### Чем пользуется разработчик

- Редактор кода или IDE (VS Code).
- Язык программирования и его окружение (Python).
- Терминал (командная строка).
- Git и GitHub: хранение кода и история изменений.
- Трекер задач (Jira, Trello): список задач команды и их статус.
- Документация и ИИ-ассистенты: поиск ответов и разбор кода.

### Путь задачи от идеи до выпуска

1. Идея и цель продукта.
2. Требования: что именно нужно сделать.
3. Дизайн интерфейса.
4. Разработка: фронтенд и бэкенд.
5. Тестирование.
6. Выпуск продукта.
7. Поддержка и обновления.

### Roadmap курса

- Сначала основы Python (части 1 и 2), затем работа с API.
- Далее языковые модели: промпты, LangChain, память.
- Два проекта: ассистент через API и чат-бот с памятью.

### Практика: карта IT-команды

На практике разбираем сервисы: Яндекс Еда, СберБанк Онлайн, GigaChat. Для каждого определяем, какие роли нужны в IT-команде, что делает каждая роль и какими инструментами пользуется.

**Пример заполнения:**

| Роль | Что делает в сервисе | Инструменты |
| --- | --- | --- |
| Менеджер продукта | Решает, какие функции добавить, например отслеживание курьера на карте | Трекер задач, документы |
| Аналитик | Описывает требования к функциям, анализирует данные о заказах | Документы, таблицы, SQL |
| Дизайн | Проектирует экраны каталога, корзины и оплаты | Программы для проектирования интерфейсов |
| Фронтенд-разработчик | Делает интерфейс приложения и сайта | VS Code, JavaScript |
| Бэкенд-разработчик | Обрабатывает заказы, хранит данные о ресторанах и оплате | Языки программирования, базы данных |
| Тестировщик | Проверяет оформление заказа на разных устройствах | Тестовые сценарии, трекер багов |
| DevOps | Следит за работой серверов, в том числе при большой нагрузке | Docker, мониторинг |
| ML-инженер | Создаёт рекомендации блюд, прогнозирует время доставки | Python, модели машинного обучения |

## Итоги

- Разработчик решает задачи с помощью кода и работает в команде.
- Основные направления: фронтенд, бэкенд, DevOps.
- В IT есть и другие профессии: аналитик, тестировщик, дизайнер, менеджер, ML-инженер.
- Задача проходит несколько этапов, на каждом участвуют разные роли и инструменты.
