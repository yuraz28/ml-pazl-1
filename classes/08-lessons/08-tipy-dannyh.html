Теория · Типы

Четыре типа значений

целые числа

int

17, −5, 0. Размер целого числа в Python не ограничен.

дробные числа

float

3.14, −0.5, 2.0. Дробная часть отделяется точкой, а не запятой.

текст

str

'Python', "17", ''. Строку можно сцеплять, повторять и измерять.

логика

bool

True и False. Так выглядит результат сравнения 5 > 3.

Тип решает, что со значением можно делать. Число 17 и строка '17' — разные значения, хотя выглядят почти одинаково.

Теория · Типы

17 и '17' — разные значения

print(17 + 3)print('17' + '3')
С числом считают, а со строкой — нет: знак + у строк означает сцепку. Оба примера выглядят похоже, а делают разное.

Теория · type()

Функция type()

print(type(17))print(type(3.14))print(type('17'))print(type(5 > 3))print(type(4 / 2))print(type(input()))
type() отвечает одну строку: к какому классу относится значение. Видно и скобки, и кавычки — по ним легко найти расхождение.

Теория · Преобразования

Неявные преобразования

print(2 + 1.5)print(type(2 + 1.5))print(10 / 2)
Главное правило: целое число автоматически становится дробным, если рядом с ним оказался float.

Теория · Преобразования

Что Python делает сам

int → float

2 + 1.5 даёт 3.5: рядом float, и целое подтянулось.

деление → float

10 / 2 даёт 5.0. Обычное деление всегда возвращает дробное.

строка + число

Python не угадывает, сложить или сцепить. Здесь он бессилен.

float → int

Дробное число в целое само не превращается — тоже вручную.

Неявное преобразование Python делает за нас. В остальных случаях нужно явное — иначе ошибка.

Теория · Преобразования

Явные преобразования

print(int('123'))print(float('1.5'))print(float(3))print(str(17))
Явное преобразование выполняем сами: int(), float() и str() превращают значение в нужный тип.

Теория · Преобразования

int() не округляет

print(int(17.89))print(int(-1.7))print(int(3.99))
int(3.99) — это 3, а не 4. Функция отбрасывает дробную часть, а не округляет число.

Теория · Преобразования

Строку с точкой — через float

n = int('2.5')n = int(float('2.5'))
Если строку нельзя превратить в число, возникает ValueError. Строку с точкой сначала пропускают через float().

Теория · Ошибки с типами

Строка и число вместе

print('Мне ' + 15 + ' лет')print('Мне ' + str(15) + ' лет')print('Мне', 15, 'лет')
TypeError — самая частая ошибка с типами: строка и число оказались в одной операции «плюс».

Теория · Ошибки с типами

Забыли преобразовать ввод

age = input()print(age + 1)age = int(input())print(age + 1)
input() всегда отдаёт строку, даже если ввели цифры. Целое число из неё делает int().

Теория · Ошибки с типами

Неправильная запись числа

x = float('2,5')x = float('2.5')n = int('abc')
ValueError: строка не похожа на число. Нужна точка вместо запятой — и цифры, а не буквы.

Теория · Ошибки с типами

Умножение строки на строку

print('3' * '4')print('3' * 4)print(3 * 4)
Знак * означает разное в зависимости от типа: строка повторяется, число умножается. Две строки так перемножить нельзя.

Работаем в VS Code: файл lesson7.py.

Практика · Задача 1

Условие задания

Что на вход

Имя и возраст — две строки. Имя читаем как есть, а возраст сразу превращаем в число: age = int(input())

Что на выход

Одна строка: имя и сколько лет будет через год.

Тесты
Аня · 14→Аня, через год тебе будет 15 лет
Тимур · 9→Тимур, через год тебе будет 10 лет
Маша · 99→Маша, через год тебе будет 100 лет

Практика · Задача 1 · Шаг 1

Считаем данные с экрана

input() всегда отдаёт строку, поэтому возраст превращаем в число через int(). Имя оставляем строкой.
name = input('Как тебя зовут? ')age = int(input('Сколько тебе лет? '))

Практика · Задача 1 · Шаг 2

Считаем возраст через год

f-строка подставляет значения переменных прямо в текст: имя и новый возраст.
next_age = age + 1print(f'{name}, через год тебе будет {next_age} лет')

Практика · Задача 1 · Полное решение

Полное решение

name = input('Как тебя зовут? ')age = int(input('Сколько тебе лет? '))next_age = age + 1print(f'{name}, через год тебе будет {next_age} лет')

Практика · Задача 2

Условие задания

Что на вход

Имя и баллы — две строки. Баллы превращаем в число через int(), а в текст они возвращаются через str()

Что на выход

Одна строка: слово «Результат», имя и баллы.

Тесты
Аня · 95→Результат Аня: 95
Тимур · 7→Результат Тимур: 7
Маша · 100→Результат Маша: 100

Практика · Задача 2 · Шаг 1

Считаем данные с экрана

Баллы нужны числом — их превращаем через int(). Имя и так строка.
name = input('Как тебя зовут? ')score = int(input('Сколько баллов? '))

Практика · Задача 2 · Шаг 2

Склеиваем строку и печатаем

Складывать строку с числом нельзя: число сначала превращаем в текст через str(), потом склеиваем через +.
line = 'Результат ' + name + ': ' + str(score)print(line)

Практика · Задача 2 · Полное решение

Полное решение

name = input('Как тебя зовут? ')score = int(input('Сколько баллов? '))line = 'Результат ' + name + ': ' + str(score)print(line)

Практика · Задача 3

Условие задания

Что на вход

Три целых числа — оценки. Каждую читаем через int(input())

Что на выход

Две строки: средний балл (дробное число) и его целая часть.

Тесты
5 · 4 · 4→Средний балл: 4.333333333333333, Целая часть: 4
5 · 5 · 5→Средний балл: 5.0, Целая часть: 5
3 · 4 · 4→Средний балл: 3.6666666666666665, Целая часть: 3

Практика · Задача 3 · Шаг 1

Считаем три оценки

Оценки — целые числа. Заводим три переменные: a, b и c.
a = int(input('Первая оценка: '))b = int(input('Вторая оценка: '))c = int(input('Третья оценка: '))

Практика · Задача 3 · Шаг 2

Средний балл и целая часть

Деление / всегда даёт дробное число — это и есть средний балл. int() отбрасывает дробную часть: получается целая часть балла.
avg = (a + b + c) / 3print('Средний балл:', avg)print('Целая часть:', int(avg))

Практика · Задача 3 · Полное решение

Полное решение

a = int(input('Первая оценка: '))b = int(input('Вторая оценка: '))c = int(input('Третья оценка: '))avg = (a + b + c) / 3print('Средний балл:', avg)print('Целая часть:', int(avg))

Практика · Доп. задание · Шаг 1

Цена и количество

Цена бывает дробной, поэтому её читаем через float(). Количество — целое, ему хватает int().
price = float(input('Цена: '))count = int(input('Сколько штук? '))

Практика · Доп. задание · Шаг 2

Считаем итог

Умножаем число на число — получаем число, а не склейку текста. Печатаем оба значения через запятую.
total = price * countprint('Итого:', total, 'руб.')

Итоги

Что изучили

Простые типы Python — int, float, str и bool. Тип значения показывает type().
input() всегда возвращает строку, а обычное деление / всегда даёт float.
Неявно Python превращает int в float, но строку и число вместе не объединяет.
int(), float() и str() преобразуют значение руками; int() отбрасывает дробную часть, а не округляет.
TypeError — строка и число в одной операции. ValueError — строку не превратить в число.
Ошибки типов лечатся преобразованием: int(input()), str(score), float(price).
